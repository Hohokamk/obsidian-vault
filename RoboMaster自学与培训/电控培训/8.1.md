## 每一步具体做了什么

### 第 1 步：遥控器 → 摇杆值

```
// RC::Decode() 中
rc.ch[0] = ((m_frame[0] | m_frame[1] << 8) & 0x07FF) - 1024;
// 原始值 0~2048 → 减去1024 → -1024~+1024 → 死区处理后 -660~+660
```

### 第 2 步：摇杆值 → 速度/角度

```
// RC::OnRC() 中
ctrl.chassis.speedx = rc.ch[0] * para.max_speed / 660.f;
// -660~+660 → -3000~+3000（rpm）

ctrl.pantile.mark_yaw -= adjangle_rad * ch_yaw;
// 摇杆值累加 → 弧度（-4π~4π）
```

### 第 3 步：速度 → 麦轮解算

```
// CHASSIS::Update() 中
motor[0]->setspeed = speedx - speedy + speedz;  // 四个电机各自的速度
```

### 第 4 步：速度 → 电流（PID 计算）

```
// Motor::Ontimer() SPD模式中
current = pid[speed].Position(setspeed - curspeed, 10000);
// 速度误差 → PID → 电流值（0~16384）
```

### 第 5 步：电流 → CAN 数据

```
// Motor::Ontimer() 最后
odata[0] = (current & 0xff00) >> 8;  // 高8位
odata[1] = current & 0x00ff;          // 低8位
```
