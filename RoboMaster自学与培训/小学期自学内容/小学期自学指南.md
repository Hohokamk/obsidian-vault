# RCS RM 新生小学期自学指南

>   **适用对象：** RCS RoboMaster 战队新生
>   **学习周期：** 小学期第 1—2 周

本指南汇总了小学期前两周的基础学习资料，旨在帮助新生快速了解 RoboMaster 赛事、战队技术方向及常用工具，减少自行检索资料的时间成本，并为后续培训与项目实践打下基础。

学习过程中如遇到难以理解的内容，应及时记录问题，并在QQ群以合理的方式提出。

## 四、视觉组

### 1. 基础工程能力

### 学习目标

掌握基础开发环境的使用方法，能够完成简单的工程浏览、代码阅读和问题描述，为后续视觉项目学习做好准备。

### 需要掌握的内容

-   基本 Linux 命令：`cd`、`ls`、`mkdir`、`cp`、`rm`、`grep`；
-   基本 Git 命令：`clone`、`pull`、`status`、`diff`；
-   使用 VSCode 打开工程、搜索文件、查看函数定义；
-   能够阅读终端报错信息，并较清楚地描述自己遇到的问题。

### 参考资料

-   Git 交互式学习：[Learn Git Branching](https://learngitbranching.js.org/?locale=zh_CN)
-   Linux 命令学习：可在 B 站搜索“Linux 基础命令 入门”。

------

### 2. C++ 基础

### 学习目标

不要求系统掌握完整的 C++ 知识体系，但应具备阅读项目代码、理解基础逻辑的能力。

### 需要掌握的内容

-   函数、`if` 语句、`for` 循环；
-   `struct`、`class`；
-   `std::vector`、`std::string`；
-   引用和指针的基本含义；
-   `.hpp` 与 `.cpp` 文件之间的关系；
-   `namespace` 的基本作用。

### 参考资料

-   [LearnCpp](https://www.learncpp.com/)
-   B 站搜索关键词：`C++ 入门`、`vector`、`class`、`shared_ptr`

### 学习建议

无需从头完整刷完全部教程，应优先学习能够帮助自己阅读项目代码的内容。重点在于理解，而非死记硬背。

------

### 3. ROS 2 基础概念

### 需要掌握的内容

-   **Node（节点）：** ROS 2 中执行具体功能的程序单元；
-   **Topic（话题）：** 节点之间传递数据的通道；
-   **Message（消息）：** Topic 中传输的数据格式；
-   **Launch：** 用于一键启动多个节点的配置方式；
-   **rosbag：** 用于录制和回放机器人数据的工具；
-   与上述内容相关的基础查看和调试命令。

### 参考资料

-   [ROS 2 Humble 官方教程](https://docs.ros.org/en/humble/Tutorials.html)
