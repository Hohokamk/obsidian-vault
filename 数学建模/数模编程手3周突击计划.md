## 🟢 第一阶段：基础工具 & 数据处理（Day 1 – Day 7）

> **💡 阶段分析**：编程手的第一要务是"拿到数据就能处理"。这一周不碰复杂模型，
> 只专注三件事——**数据清洗、可视化、曲线拟合**。这三项是几乎所有赛题的公共基础，
> 也是后续所有模型的"输入端"。练到肌肉记忆，赛场上才能快。

### Day 1 · Python 环境搭建 & NumPy 速通

- [ ] 安装 Anaconda / Miniconda，配置 Jupyter Notebook 或 VS Code 开发环境
- [ ] 安装核心库：`numpy`, `pandas`, `matplotlib`, `scipy`, `sklearn`
- [ ] NumPy 核心操作：数组创建、索引切片、广播机制、常用函数（`mean/std/dot/reshape`）
- [ ] 练习：用 NumPy 完成矩阵运算（乘法、求逆、特征值分解）
- [ ] 整理一份 **NumPy 速查表**（保存到仓库，后续比赛直接查）

> **🔑 指点**：NumPy 是一切数值计算的底座。重点掌握**广播机制**和**向量化运算**，
> 写代码时时刻想"能不能不用 for 循环"——向量化速度差 100 倍以上。

### Day 2 · Pandas 数据处理

- [ ] DataFrame 创建、读取 CSV/Excel、基本查询与筛选
- [ ] 缺失值处理：`dropna()`, `fillna()`, 插值法 `interpolate()`
- [ ] 分组聚合：`groupby()`, `agg()`, `pivot_table()`
- [ ] 数据合并：`merge()`, `concat()`, `join()`
- [ ] 练习：找一份 Kaggle 小数据集（如 Titanic），完成清洗 + 统计摘要

> **🔑 指点**：国赛数据题经常有脏数据（缺失、异常值、格式不统一）。
> Pandas 的 `groupby + agg` 组合拳务必熟练，80% 的数据统计需求它都能搞定。

### Day 3 · 数据可视化（Matplotlib + Seaborn）

- [ ] Matplotlib 基础：`plot`, `scatter`, `bar`, `hist`, `pie`
- [ ] 子图布局：`subplot`, `subplots`, `GridSpec`
- [ ] 图例/标签/标题/中文显示设置（`plt.rcParams['font.sans-serif']`）
- [ ] Seaborn 高级图表：`heatmap`（相关性矩阵）, `boxplot`, `violinplot`, `pairplot`
- [ ] 练习：对 Day 2 的数据集画出 ≥5 种图表，导出为高清 PNG（`dpi=300`）

> **🔑 指点**：比赛论文里图的质量直接影响评委印象。**中文显示**和**配色**是两个常见坑，
> 提前调好模板代码。推荐配色方案：`sns.set_palette("husl")` 或自定义学术配色。

### Day 4 · 曲线拟合 & 插值

- [ ] 多项式拟合：`np.polyfit()` + `np.poly1d()`
- [ ] 自定义函数拟合：`scipy.optimize.curve_fit()`
- [ ] 一维插值：`scipy.interpolate.interp1d`（线性、三次样条）
- [ ] 二维插值：`scipy.interpolate.interp2d` / `griddata`
- [ ] 练习：给一组带噪声的 sin 数据，分别用多项式和自定义函数拟合，对比效果

> **🔑 指点**：拟合题是国赛 C 题（数据分析类）的常客。关键是**先画图看趋势再选模型**，
> 不要上来就套高次多项式——过拟合是扣分大忌。`curve_fit` 可以拟合任意函数，
> 是万能武器，但要注意给合理的初始值 `p0`。

### Day 5 · 数据预处理专题

- [ ] 异常值检测：3σ 原则、IQR 方法、箱线图法
- [ ] 数据标准化：Min-Max 归一化、Z-score 标准化
- [ ] 降维入门：PCA 主成分分析（`sklearn.decomposition.PCA`）
- [ ] 相关性分析：Pearson / Spearman 相关系数 + 热力图
- [ ] 练习：构造一份含异常值和多特征的数据集，完成清洗→标准化→PCA→可视化全流程

> **🔑 指点**：数据预处理在论文中要写清楚"为什么这么做"，不能只贴代码。
> PCA 降维后记得解释"前 k 个主成分累计贡献率达到 XX%"，这是评委想看到的。

### Day 6 · MATLAB 基础速通（辅助工具）

- [ ] MATLAB 界面熟悉、基本语法、矩阵操作
- [ ] 常用工具箱：优化（`linprog`, `fmincon`）、统计、曲线拟合（`cftool`）
- [ ] MATLAB 与 Python 的互补场景：某些工具箱（如 Simulink、优化工具箱）MATLAB 更方便
- [ ] 练习：把 Day 4 的拟合任务用 MATLAB 重写一遍

> **🔑 指点**：国赛中 MATLAB 仍然是主流工具之一，尤其是**优化求解**和**Simulink 仿真**。
> 但作为编程手，Python 为主力即可，MATLAB 只需要在特定场景（如 `cftool` 交互拟合、
> `linprog` 求解线性规划）时拿出来用。**不要两个都半吊子**，先精通 Python。

### Day 7 · 第一阶段复盘 & 小测

- [ ] 整理本周所有代码到一个 Jupyter Notebook 合集（作为个人模板库）
- [ ] 回顾 NumPy / Pandas / Matplotlib 速查表，查漏补缺
- [ ] 限时练习（2 小时）：拿到一份数据，完成"清洗→统计→可视化→拟合"全流程
- [ ] 写一份简短的**自我评估**：哪些操作还需要查文档？哪些已经形成肌肉记忆？
- [ ] 把模板代码推到 Git 仓库，建好目录结构

> **🔑 阶段总结**：第一周结束后，你应该能在 30 分钟内完成任何数据集的探索性分析。
> 如果做不到，周末多花 2 小时补练。这是后面所有模型的地基。

## 🟡 第二阶段：核心算法 & 建模方法（Day 8 – Day 16）

> **💡 阶段分析**：这一周是**重中之重**。国赛三天能用到的 80% 模型都集中在这里。
> 按"优化→评价→统计→机器学习"四大板块推进。每个模型不需要推导数学原理，
> 但必须做到：**知道什么场景用什么模型 + 能在 20 分钟内写出可运行代码**。

### Day 8 · 线性规划（LP）

- [ ] 线性规划标准型：目标函数、约束条件、决策变量
- [ ] `scipy.optimize.linprog()` 使用方法
- [ ] MATLAB `linprog()` 对照学习
- [ ] 建模练习：生产计划问题 / 运输问题 / 投资组合问题（至少做 2 道）
- [ ] 整理**线性规划建模模板**（读题→设变量→列约束→写代码→解读结果）

> **🔑 指点**：线性规划是优化类题目的基础。难点不在代码，在于**把文字描述转化为数学约束**。
> 练习时重点训练"读题→建模"的转化能力。注意 `linprog` 默认求最小值，求最大值要取负。

### Day 9 · 整数规划 & 非线性规划

- [ ] 整数规划（IP）：`scipy.optimize.milp()` 或 PuLP 库
- [ ] 0-1 规划：指派问题、选址问题
- [ ] 非线性规划（NLP）：`scipy.optimize.minimize()`（SLSQP / L-BFGS-B 方法）
- [ ] 练习：用 PuLP 解一道经典的设施选址问题
- [ ] 练习：用 `minimize` 解一道带约束的非线性优化

> **🔑 指点**：整数规划在国赛中出现频率很高（如"选不选这个方案"就是 0-1 变量）。
> PuLP 库语法直观，推荐作为主力。非线性规划要注意**初值敏感性**——
> 换几个初值跑一下，确认不是局部最优。

### Day 10 · 评价模型（上）：AHP + 熵权法

- [ ] 层次分析法（AHP）：构造判断矩阵 → 一致性检验 → 计算权重
- [ ] AHP 代码实现（Python 完整模板）
- [ ] 熵权法：信息熵 → 计算客观权重
- [ ] AHP + 熵权法组合赋权
- [ ] 练习：对"选择最佳方案"类问题，用 AHP 和熵权法分别计算权重

> **🔑 指点**：评价模型是国赛**必考**题型。AHP 主观赋权 + 熵权法客观赋权 = 组合赋权，
> 这是论文中的加分项。一致性检验的 CR < 0.1 要在论文中明确写出来。

### Day 11 · 评价模型（下）：TOPSIS + 灰色关联

- [ ] TOPSIS（优劣解距离法）：标准化 → 正负理想解 → 相对贴近度 → 排名
- [ ] 灰色关联分析（GRA）：参考序列 → 关联系数 → 关联度
- [ ] 综合练习：用 TOPSIS + 灰色关联对同一组数据评价，对比结果
- [ ] 整理**评价模型决策树**：什么场景用哪种方法

> **🔑 指点**：TOPSIS 代码量小、效果好，是性价比最高的评价方法。
> 但单独用 TOPSIS 容易显得单薄，建议搭配 AHP/熵权法赋权，形成"组合评价"。
> 灰色关联适合"小样本、贫信息"场景，国赛中作为备选。

### Day 12 · 回归分析 & 假设检验

- [ ] 一元/多元线性回归：`sklearn.linear_model.LinearRegression`
- [ ] 回归诊断：R²、残差分析、VIF 多重共线性
- [ ] 逻辑回归（分类问题）：`sklearn.linear_model.LogisticRegression`
- [ ] 假设检验：t 检验、卡方检验、F 检验（`scipy.stats`）
- [ ] 练习：给一份数据，完成"回归建模→诊断→假设检验→结论"全流程

> **🔑 指点**：回归分析是数据处理类题目的核心。论文中不能只给回归方程，
> 一定要有**显著性检验**（p 值）和**拟合优度**（R²）。
> 如果残差呈现明显模式，说明模型选错了，要换非线性或加交互项。

### Day 13 · 时间序列分析

- [ ] 时间序列基础：趋势、季节性、周期性分解
- [ ] 平滑方法：移动平均、指数平滑
- [ ] ARIMA 模型入门：`statsmodels.tsa.arima.model.ARIMA`
- [ ] 练习：对一份月度/年度数据做预测（如 GDP、气温、销量）

> **🔑 指点**：时间序列预测题在国赛中不算高频，但一旦出现，ARIMA 是保底方案。
> 重点掌握**定阶**（ACF/PACF 图）和**模型检验**（Ljung-Box）。
> 如果数据量小（< 30），灰色预测 GM(1,1) 可能更合适。

### Day 14 · 聚类分析 & 分类模型

- [ ] K-Means 聚类：`sklearn.cluster.KMeans`，肘部法选 K
- [ ] 层次聚类 & DBSCAN 简介
- [ ] 分类模型：KNN、决策树、随机森林（`sklearn.ensemble.RandomForestClassifier`）
- [ ] 模型评估：准确率、混淆矩阵、交叉验证
- [ ] 练习：对 Iris 数据集做聚类 + 分类，画出决策边界

> **🔑 指点**：聚类是"无监督"的，适合数据探索阶段发现规律；分类是"有监督"的，
> 适合预测。国赛中两者都可能出现。**随机森林**是万金油分类器，
> 默认参数就不错，调参时重点关注 `n_estimators` 和 `max_depth`。

### Day 15 · 蒙特卡洛模拟 & 基础仿真

- [ ] 蒙特卡洛方法核心思想：随机采样 → 统计结果
- [ ] 随机数生成：均匀分布、正态分布、自定义分布
- [ ] 经典案例：计算 π、排队论仿真、库存模型仿真
- [ ] `numpy.random` 高级用法：`choice`, `shuffle`, `seed`
- [ ] 练习：用蒙特卡洛模拟一道概率估算题（如不规则面积计算）

> **🔑 指点**：蒙特卡洛是"暴力美学"——模型复杂到没有解析解时，用随机模拟逼近。
> 国赛中常用于**验证模型**或**估算概率**。关键是模拟次数要够大（≥10000 次），
> 结果才稳定。论文中要写清楚"模拟了 N 次，结果收敛"。

### Day 16 · 第二阶段复盘 & 算法串联

- [ ] 整理本周所有模型代码为**函数化模板**（每个模型封装成可调用的函数/类）
- [ ] 画一张**模型选择思维导图**：数据类型 → 问题类型 → 对应模型
- [ ] 限时练习（3 小时）：给一道国赛真题的数据，选择合适的模型并编程实现
- [ ] 对照已有资料 PDF（回归相关、线性规划、非线性规划等），查漏补缺
- [ ] 更新个人模板库

> **🔑 阶段总结**：第二周结束后，你应该能覆盖国赛大部分题型的编程需求。
> 关键不是"会多少个模型"，而是"看到题目能在 10 分钟内确定用什么模型并写出代码"。
> 如果某些模型还不熟，第三周实战中继续巩固。

## 🔴 第三阶段：综合实战 & 模拟冲刺（Day 17 – Day 21）

> **💡 阶段分析**：最后一周的目标是**把零散的模型知识串成完整的解题能力**。
> 通过做真题和限时模拟，训练"审题→建模→编程→写作"的全流程配合。
> 同时建立自己的**代码模板库**，赛场上可以直接调用，节省大量时间。

### Day 17 · 微分方程 & 差分方程建模

- [ ] 常微分方程（ODE）数值求解：`scipy.integrate.solve_ivp`
- [ ] 经典模型复现：SIR 传染病模型、Lotka-Volterra 捕食模型
- [ ] 差分方程：离散时间系统的建模与求解
- [ ] 练习：用 SIR 模型模拟一次传染病传播，拟合参数并预测峰值

> **🔑 指点**：微分方程建模在 A 题（连续型）中高频出现。编程手的任务是**数值求解 + 可视化**，
> 不需要手推解析解。`solve_ivp` 的 `method='RK45'` 是默认选择，
> 刚性问题换 `'Radau'` 或 `'BDF'`。

### Day 18 · 图论 & 网络优化

- [ ] 图论基础：用 `networkx` 建图、最短路径、最小生成树
- [ ] Dijkstra / Floyd 算法实现
- [ ] 网络流问题简介
- [ ] 旅行商问题（TSP）：贪心 + 模拟退火近似求解
- [ ] 练习：用 networkx 求解一道城市间最短路径 / 最优路线问题

> **🔑 指点**：图论题通常出现在 B 题。`networkx` 库能解决大部分基础图论问题。
> TSP 是 NP-hard，比赛中用**启发式算法**（模拟退火 / 遗传算法）求近似解即可，
> 不要试图求精确解。

### Day 19 · 真题实战（一）

- [ ] 选择一道近 3 年国赛真题（推荐 C 题 / D 题，数据驱动型）
- [ ] 限时 4 小时完成：数据读取 → 预处理 → 建模 → 求解 → 可视化
- [ ] 对照优秀论文，分析自己的差距（模型选择、代码质量、图表美观度）
- [ ] 记录本次实战中遇到的问题和解决方案

> **🔑 指点**：第一次做真题可能很不顺手，这很正常。重点是**熟悉完整流程**，
> 不要追求完美。做完后一定要对照优秀论文复盘——看别人用了什么模型、
> 图表怎么画的、论文结构怎么组织的。

### Day 20 · 真题实战（二）

- [ ] 选择另一道国赛真题（推荐 A 题 / B 题，机理分析型）
- [ ] 限时 4 小时完成：问题分析 → 模型建立 → 编程求解 → 结果验证
- [ ] 重点练习：模型假设的合理性、结果的灵敏度分析
- [ ] 整理两天实战的**经验教训清单**

> **🔑 指点**：A/B 题和 C/D 题的思路完全不同。A/B 题重机理建模（微分方程、物理模型），
> C/D 题重数据分析（统计、优化、评价）。编程手两种都要会，但可以根据队伍分工有所侧重。

### Day 21 · 全真模拟 & 终极复盘

- [ ] 全真模拟（6 小时）：随机抽一道国赛题，完整走一遍三天赛程的压缩版
- [ ] 模拟结束后自评：代码可运行性、结果合理性、图表规范性
- [ ] 整理最终版**代码模板库**，确保每个模型都有可直接调用的模板
- [ ] 写一份**赛前 Checklist**（环境配置、常用代码片段、常见坑点）
- [ ] 三周总复盘：标记所有已掌握的模型，标红仍需加强的部分

> **🔑 阶段总结**：模拟赛是赛前最后的练兵。做完后把模板库整理好，
> 赛场上编程手的核心竞争力就是——**拿到题就能调模板，改参数就能出结果**。
