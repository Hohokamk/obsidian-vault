学习嵌入式系统，确实会接触到大量名词。我按**学习路径和知识模块**帮你梳理了一份核心名词清单，每个都附了简短说明，方便你按图索骥。

---

### 一、基础硬件层

| 名词                   | 说明                                  |
| -------------------- | ----------------------------------- |
| **MCU**              | 微控制器，如 STM 32、ESP 32，嵌入式最核心的器件      |
| **MPU**              | 微处理器，通常指能跑 Linux 的芯片，如 i.MX 6、树莓派主控 |
| **SoC**              | 片上系统，把 CPU、GPU、外设集成在一颗芯片上           |
| **GPIO**             | 通用输入输出口，控制引脚高低电平                    |
| **UART**             | 串口通信，最常用的调试接口                       |
| **I 2 C**            | 两线制总线，接传感器、EEPROM 等                 |
| **SPI**              | 高速同步串行总线，接 Flash、屏幕等                |
| **CAN**              | 汽车/工业常用总线，抗干扰强                      |
| **ADC/DAC**          | 模数/数模转换，采集模拟信号或输出模拟量                |
| **PWM**              | 脉宽调制，控制电机、LED 亮度等                   |
| **中断**               | Interrupt，硬件事件打断 CPU 执行             |
| **DMA**              | 直接内存访问，不占 CPU 搬数据                   |
| **时钟树**              | Clock Tree，芯片各外设时钟来源与分频             |
| **寄存器**              | Register，直接操作硬件的底层接口                |
| **Datasheet**        | 芯片数据手册，硬件开发必读                       |
| **Reference Manual** | 参考手册，比 Datasheet 更详细的外设说明           |

### 二、编程与工具链

| 名词           | 说明                                |
| ------------ | --------------------------------- |
| **裸机编程**     | Bare-metal，不跑 OS，直接操作寄存器          |
| **HAL 库**    | 硬件抽象层库，如 STM 32 HAL               |
| **LL 库**     | 底层库，比 HAL 更接近寄存器                  |
| **CMSIS**    | ARM  Cortex-M 软件接口标准              |
| **交叉编译**     | 在 PC 上编译目标板代码，如 arm-none-eabi-gcc |
| **Makefile** | 组织编译规则的文件                         |
| **CMake**    | 更现代的构建系统                          |
| **链接脚本**     | Linker Script，决定代码/数据放到哪块内存       |
| **启动文件**     | Startup file，复位后第一条执行的汇编          |
| **烧录/下载**    | 把程序写入芯片，如 ST-Link、J-Link          |
| **调试器**      | Debugger，如 GDB、J-Link、DAP-Link    |
| **SWD/JTAG** | 两种调试接口协议                          |
| **逻辑分析仪**    | 抓时序波形，调 I 2 C/SPI 必备              |
| **示波器**      | 看模拟波形、信号质量                        |

### 三、操作系统层

| 名词                  | 说明                                 |
| ------------------- | ---------------------------------- |
| **RTOS**            | 实时操作系统，如 FreeRTOS、RT-Thread、Zephyr |
| **任务/Task**         | RTOS 中的执行单元                        |
| **调度器**             | Scheduler，决定哪个任务运行                 |
| **抢占**              | Preemption，高优先级任务打断低优先级            |
| **信号量**             | Semaphore，任务间同步                    |
| **互斥锁**             | Mutex，保护共享资源                       |
| **消息队列**            | Queue，任务间传数据                       |
| **事件组**             | Event Group，多事件同步                  |
| **优先级反转**           | Priority Inversion，RTOS 经典问题       |
| **临界区**             | Critical Section，不可被打断的代码段         |
| **上下文切换**           | Context Switch，保存/恢复任务现场           |
| **Tick**            | 系统节拍，RTOS 的时间基准                    |
| **Linux 嵌入式**       | 跑 Linux 的系统，如树莓派、全志、瑞芯微            |
| **设备树**             | Device Tree，描述硬件给 Linux 内核         |
| **内核模块**            | Kernel Module，动态加载驱动               |
| **字符设备驱动**          | 最常见的 Linux 驱动类型                    |
| **根文件系统**           | Rootfs，Linux 启动后挂载的文件系统            |
| **BusyBox**         | 嵌入式 Linux 常用精简工具集                  |
| **U-Boot**          | 嵌入式 Linux 常用引导程序                   |
| **Yocto/Buildroot** | 构建嵌入式 Linux 系统的工具                  |

### 四、通信与协议

| 名词 | 说明 |
|------|------|
| **Modbus** | 工业常用协议，RTU/TCP |
| **MQTT** | 物联网轻量级消息协议 |
| **TCP/IP** | 网络基础协议栈 |
| **LwIP** | 轻量级 TCP/IP 协议栈，适合 MCU |
| **BLE** | 低功耗蓝牙 |
| **LoRa** | 远距离低功耗无线 |
| **Zigbee** | 低功耗组网协议 |
| **USB** | 通用串行总线，含 CDC/HID/MSC 等类 |
| **Ethernet** | 以太网，含 MAC/PHY |
| **OTA** | 空中升级，远程更新固件 |

### 五、进阶与工程实践

| 名词 | 说明 |
|------|------|
| **低功耗设计** | Sleep/Stop/Standby 模式，电池设备关键 |
| **看门狗** | Watchdog，程序跑飞时复位 |
| **Bootloader** | 引导程序，负责升级和跳转 |
| **固件加密** | 保护代码不被读取 |
| **内存布局** | Flash/RAM 分区，栈、堆、数据段 |
| **栈溢出** | Stack Overflow，嵌入式常见崩溃原因 |
| **HardFault** | Cortex-M 硬件错误，调试重点 |
| **单元测试** | Unity、CMock 等嵌入式测试框架 |
| **CI/CD** | 持续集成，自动化编译测试 |
| **版本控制** | Git，代码管理必备 |
| **代码规范** | MISRA C、Google C++ Style 等 |
| **功能安全** | ISO 26262、IEC 61508 等标准 |

---

### 六、按学习顺序的建议

1. **C 语言 + 单片机基础** → GPIO、UART、中断、定时器
2. **常用外设** → I 2 C、SPI、ADC、PWM、DMA
3. **工具链** → 交叉编译、Makefile、调试器、逻辑分析仪
4. **RTOS** → FreeRTOS 任务、队列、信号量
5. **通信协议** → Modbus、MQTT、TCP/IP
6. **嵌入式 Linux** → U-Boot、内核、设备树、驱动
7. **工程化** → Git、CI、低功耗、Bootloader、OTA
