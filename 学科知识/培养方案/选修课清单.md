# 选修课清单

更新：2026-10-27｜方向：嵌入式、机器人、软硬件结合

> 复选框用于记录“已修”。已按你的反馈勾选电力电子技术、数字信号处理和人工智能引论；未勾选表示尚未登记完成，不代表一定没修过。学分认定以教务系统为准。

## 要修多少学分

| 类别        |       需要修的学分 | 规则                            |
| --------- | -----------: | ----------------------------- |
| 专业选修合计    | **暂按至少34学分** | 五个模块都要覆盖；限选和可选课程均计入此合计        |
| 其中：限选课    |     **24学分** | 下方所有【限选】课程都要修，不是每个模块挑一门       |
| 其中：应用技术模块 |    **至少2学分** | 无限选课，至少修其中一门认可课程              |
| 其余自由搭配    |    **至少8学分** | 24 + 2 + 8 = 34；可继续选下方各模块的可选课 |

**已登记的专业选修暂计7学分**：电力电子技术A 4 + 数字信号处理3。人工智能引论的学分与归属待核，暂未加进合计；其他已修课程尚未登记，因此暂不计算个人最终剩余学分。

> 本清单依据2022级文件。文件正文写专业任选最低33学分，表格写34，本清单暂按34安排；是否适用于你的年级须核对。下方“可选”对应原表的“任选”，“推荐”是结合你的方向给出的建议，不改变限选规则。

## 使用说明

- 以上专业选修共33门、可供选择共68学分，**不需要全部修完**。需要满足总学分、全部限选及五模块覆盖。
- 标注学期来自2022级计划；“第3学期”是否对应暑期小学期，以校历为准。实际开课、先修、容量和冲突以当年教务为准。
- 方案允许选本方案未列出的学院其他专业本科专业选修课程，**限2门**；或学院各专业研究生专业课程，**限1门**。具体认定与替代规则需先核对，不能自行替代限选；选研究生课程时也要核对门数限制。
- 本清单是普通Obsidian Markdown复选框；勾选后**顶部学分合计不会自动变化**，请按实际认定学分手动更新。
- 详细选课顺序与课业负担分析见 [[培养方案]]。
