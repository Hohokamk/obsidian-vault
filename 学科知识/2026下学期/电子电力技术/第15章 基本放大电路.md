# 第15章 基本放大电路 — 知识框架

> [!tip] 一句话主线
> 本章是**模拟电子技术的核心章节**：讲清楚"如何把一个微弱的电压/电流信号，不失真地放大成更大的信号"。
> 全程就围绕一个词转——**静态工作点 Q**：Q 定得好，不失真；Q 定歪了，全完蛋。

## 2. 15.1 放大的概念与性能指标

> [!note] 放大的本质
> 放大 = **能量的控制和转换**。小信号只起"控制"作用，真正的能量来自直流电源 VCC。
> 前提：**不失真**，失真了放大就失去意义。

**六大性能指标**：

| 指标 | 定义/公式 | 好坏标准 |
|------|-----------|----------|
| 放大倍数 | Au = Uo/Ui（还有 Ai、Ap） | 越大越好 |
| 输入电阻 | Ri = Ui/Ii | **越大越好**（从前级取电流小，影响小） |
| 输出电阻 | Ro（输出端看进去的等效电阻） | **越小越好**（带负载能力强） |
| 通频带 | fbw = fH − fL | 越宽适应频率越广 |
| 非线性失真系数 | D = 谐波总量 / 基波 | 越小越好 |
| 最大输出功率与效率 | Pom、η = Pom/PV | 功率大、效率高 |

## 3. 15.2 基本共射放大电路的工作原理

### 各元件作用
- **T**：NPN 三极管，放大元件
- **VCC**：为输出提供能量（放大的能量来源）
- **RC**：把 iC 的变化 → 转化为 uCE 的变化（电流变电压的关键）
- **VBB、Rb**：给发射结正偏，提供静态基极电流

### 静态工作点 Q
- Q 点（直流值）：UBEQ、IBQ、ICQ、UCEQ
- 基本关系：**ICQ = β·IBQ**，NPN 硅管 **UBEQ ≈ 0.7V**
- 为什么必须设 Q 点：没有合适的 Q 点，输出就会**失真**

### 放大原理（信号流动链）
```
ui → ΔuBE → ΔiB → ΔiC = β·ΔiB → (流过RC) → ΔuCE = −ΔiC·RC → uo
```
关键：靠 RC 把"电流变化"翻译成"电压变化"。

### 放大电路组成原则（4条）
1. 有提供合适 Q 点的直流电源（三极管放大区/场效应管恒流区）
2. 电阻与电源配合，保证 Q 点合适
3. 输入信号能作用到输入回路（产生 ΔuBE / ΔuGS）
4. 输出回路的动态电流能作用于负载

## 4. 15.3 放大电路的分析方法（主线）

### 4.1 直流通路 vs 交流通路

| | 直流通路 | 交流通路 |
|---|---|---|
| 耦合电容/旁路电容 | **开路**（隔直） | **短路**（通交） |
| 直流电源 VCC | 保留 | **短路**（内阻为0） |
| 用途 | 求 Q 点 | 求动态参数 Au、Ri、Ro |

### 4.2 图解法
- 用途：建立**形象直觉**，看 Q 点与失真关系、求最大输出幅度
- **直流负载线**：uCE = VCC − iC·RC（两个特殊点画出）
- **交流负载线**：斜率由 Rc//RL 决定
- **最大不失真输出电压**：Uomax ≈ min[(UCEQ − UCES), (ICQ·RL′)]

### 4.3 失真分析（高频考点 ⭐）
| Q点位置 | 失真类型 | 波形表现（NPN） |
|---------|----------|-----------------|
| Q 点过低 | **截止失真** | uo 波形**顶部**失真（iB 被削掉负半周） |
| Q 点过高 | **饱和失真** | uo 波形**底部**失真 |

### 4.4 微变等效电路法（考试/实用主线 ⭐）
- **条件**：小信号（微变量）、工作在 Q 点附近，三极管可线性化
- 三极管等效模型：
  - 输入回路（B–E 之间）：电阻 **rbe**
  - 输出回路（C–E 之间）：受控电流源 **ic = β·ib**

$$ r_{be} = r_{bb'} + (1+\beta)\frac{U_T}{I_{EQ}} \approx 200 + (1+\beta)\frac{26\text{mV}}{I_{EQ}(\text{mA})} $$

- **共射电路动态参数**（记牢 ⭐）：

$$ A_u = -\frac{\beta(R_C // R_L)}{r_{be}}, \quad R_i = R_B // r_{be}, \quad R_o = R_C $$

（负号 = 输入输出**反相**）

- **解题步骤**：求Q点 → 求 rbe → 画微变等效电路 → 列方程解 Au、Ri、Ro

## 5. 15.4 静态工作点的稳定

### 为什么 Q 点不稳 —— 温度的影响（三管齐下）
| 参数 | 温度影响 |
|------|----------|
| UBE | −2 mV/°C（温度升高，UBE 下降） |
| β | 每 +1°C 约 +0.5%~1% |
| ICBO | 每 +10°C 约**加倍** |

→ 温度升高 → IC 增大 → Q 点上移 → 易饱和失真

### 典型稳定电路：分压偏置（电流负反馈式）
- **关键设计**：I1 >> IBQ，使基极电位基本固定

$$ U_{BQ} \approx \frac{R_{b1}}{R_{b1}+R_{b2}} V_{CC}, \quad I_{CQ} \approx I_{EQ} = \frac{U_{BQ}-U_{BE}}{R_e} $$

> ⚠️ **下标认图不认名字**：本课件电路图里 Rb2 接 +VCC（上臂）、Rb1 接地（下臂），所以分子是 **Rb1**。
> 通用记法：**分压点电压 = 接地那一只 / 两只之和**。（2026-09-22 经课件原图核对修正）

- **稳定原理（负反馈闭环，背下来）**：
```
T↑ → IC↑ → IE↑ → UE(=IE·Re)↑ → UBE(=UB−UE)↓ → IB↓ → IC↓  ← 被拉回来
```
- 其他措施：二极管温度补偿（正/反向特性补偿）
- 注意：若去掉旁路电容 Ce，动态增益会下降（需重算 Au）

## 6. 15.5 三种基本接法对比（必背表格 ⭐⭐）

| 组态 | 共射 CE | 共集 CC（射极输出器） | 共基 CB |
|------|---------|----------------------|---------|
| 电压放大 Au | 大（**反相**） | ≈1（**同相**，电压跟随） | 大（**同相**） |
| 电流放大 | 有（β） | 有（1+β） | **无**（α≈1） |
| 输入电阻 Ri | 中（rbe） | **大** | **小** |
| 输出电阻 Ro | 大（≈Rc） | **小**（带载强） | 大 |
| 频率特性 | 一般 | 一般 | **高频好** |
| 主要用途 | 放大主力 | 输入级/输出级（缓冲、阻抗变换） | 高频电路 |

> 射极输出器的两个"招牌"：**输入电阻大**（不拖累前级）+ **输出电阻小**（带得动负载）。

### 补充：复合管（达林顿管）
- 两个三极管复合，β ≈ β1·β2，rbe = rbe1 + (1+β1)rbe2
- 同类型复合 → 类型不变；不同类型复合 → 类型跟前级相同

## 7. 15.6 频率特性

- **幅频特性**：|Au| 与 f 的关系；**相频特性**：φ 与 f 的关系
- **中频段**：耦合/旁路电容≈短路、结电容≈开路，Au 与 f 无关（前面算的都是中频段）

| 频段 | 增益变化 | 原因 | 相移 |
|------|----------|------|------|
| 低频段 | 增益↓ | 耦合电容、旁路电容容抗变大（分压） | **越前**（超前） |
| 高频段 | 增益↓ | 结电容、β下降、分布电容 | **滞后** |
| 通频带 | fbw = fH − fL | 下限 fL / 上限 fH | — |

## 8. 15.7 差分放大电路

### 为什么要它 —— 零点漂移（温度漂移）
- **现象**：直接耦合时，输入=0，输出却缓慢不规则漂移
- **原因**：Q 点随温度变化（本质是温度漂移）
- **抑制方法**：①直流负反馈 ②热敏元件补偿 ③**差分放大电路**（本节重点）

### 核心思想
- **共模信号**：两输入大小相等、极性相同（温度漂移可等效成共模）
- **差模信号**：两输入大小相等、极性相反（有用信号）
- 差分电路 = 靠**对称性**抵消共模（温漂），靠 **Re 的共模负反馈**进一步抑制

### 关键结论
- Re 对**差模**信号 ≈ 短路（E点"虚地"）；对**共模**信号有强负反馈
- **共模抑制比**：KCMR = |Ad/Ac|，双端输出理想为 ∞
- 差模输入电阻 Rid = 2(Rb + rbe)；双端输出 Rod = 2RC，单端输出 Rod = RC

### 四种接法
| 接法 | 差模增益 Ad | 共模增益 Ac |
|------|------------|------------|
| 双入双出 | 最大 | ≈0（KCMR=∞） |
| 双入单出 | 一半 | 有（靠 Re 抑制） |
| 单入双出 | =双入双出 | ≈0 |
| 单入单出 | =双入单出 | 有 |

> 口诀：Ad、Ac 只取决于**输出方式**，与输入方式无关。

## 9. 15.8 场效应管放大电路

### 场效应管分类
```
场效应管 FET（电压控制、高输入阻抗）
├─ 结型 JFET：N沟道 / P沟道
└─ 绝缘栅型 MOSFET
    ├─ N沟道：增强型（需UGS>UT开启）/ 耗尽型（UGS=0已有沟道，UP夹断）
    └─ P沟道：增强型 / 耗尽型
```

| 类型 | UGS=0 时 | 关键电压 |
|------|----------|----------|
| 增强型 | 无沟道（不导通） | **开启电压 UT / UGS(th)** |
| 耗尽型 | 有沟道（导通） | **夹断电压 UP / UGS(off)** |

- MOSFET 输入电阻可达 **10^10 Ω 以上**（栅极几乎不取电流）
- 三个工作区：可变电阻区 / **恒流区（放大用，也叫饱和区）** / 夹断区

### 三种接法（对照三极管）
| 场效应管组态 | 对应三极管 | 特点 |
|--------------|-----------|------|
| 共源 CS | 共射 CE | 有电压放大（反相） |
| 共漏 CD（源极输出器） | 共集 CC | Au≈1，Ri大，Ro小 |
| 共栅 CG | 共基 CB | 高频好 |

### 动态分析
- 低频小信号模型：**跨导 gm** + 漏源电阻 rDS
- gm ≈ 0.1~20 mS；rDS 很大，常可开路
- 共源：Au = −gm(RD//RL)，**Ri 极高**（109 Ω），Ro = RD

### 特点小结
电压控制、输入阻抗极高、噪声小、温漂小、利于集成；
但**跨导小，放大倍数一般比三极管低**；注意防静电击穿（栅源短接存放）。

## 10. 15.9 功率放大电路

### 功放追求什么
> 不是单纯追求高电压或大电流，而是**在电源电压确定下，输出尽可能大的功率**。
> 三大指标：最大输出功率 **Pom**、转换效率 **η**、最大输出电压 **Uom**

### 按导通角分类（θ 为半个周期内的导通角）
| 类别 | 导通角 θ | 效率（理想） | 说明 |
|------|----------|-------------|------|
| 甲类 | 2π（全导通） | 共射≤25%，变压器耦合≤50% | 静态功耗大 |
| 乙类 | π（半导通） | **最高 ~78.5%** | 有交越失真 |
| 甲乙类 | π<θ<2π | 介于之间 | **实用**（消除交越失真） |
| 丙类 | θ<π | — | 电流严重失真，用于高频 |
| 丁类 | 开关状态 | 很高 | 开关工作 |

### 电路形式发展
```
变压器耦合 → OTL(无输出变压器，单电源+大电容) → OCL(无输出电容，双电源) → BTL(桥式)
```
- **OTL**：单电源，输出接大电容（静态电容上电压 = VCC/2）
- **OCL**：双电源，静态输出为 0，正负电源交替供电
- 两只不同类型管交替工作 = **互补**（complementary）；同类型交替 = **推挽**
- **交越失真**：乙类时管子开启电压造成的"死区"
  → **消除方法**：静态给两管加微小偏压，使其**微导通**，工作在**甲乙类**

### OCL 电路计算（必考公式 ⭐）
$$ U_{op} = V_{CC} - U_{CES} \quad\text{(最大输出幅值)} $$
$$ P_{om} = \frac{U_{op}^2}{2R_L} $$
$$ P_V = \frac{2V_{CC}\cdot U_{op}}{\pi R_L} \quad\text{(正负电源总功率)} $$
$$ \eta = \frac{P_{om}}{P_V} = \frac{\pi U_{op}}{4V_{CC}} \xrightarrow{U_{op}=V_{CC}} \eta_{max} = \frac{\pi}{4} \approx 78.5\% $$

### 集成功率放大电路（补充）
- **LM386**（OTL 音频功放）：内部 = 差分输入级 + 共射中间级(恒流源有源负载) + OTL 输出级；深度电压串联负反馈；**增益可调 20~200**（1、8 脚接电容/电阻）
- **TDA1521**（OCL 立体声功放）、**TDA1556**（BTL）

## 11. 全章公式速查表

| 内容 | 公式 |
|------|------|
| 静态关系 | ICQ = β·IBQ；UBEQ≈0.7V(NPN硅) |
| 共射Q点 | UCEQ = VCC − ICQ·RC |
| 输入电阻 rbe | ≈ 200 + (1+β)·26mV/IEQ(mA) |
| 共射动态 | Au = −β(Rc//RL)/rbe，Ri = Rb//rbe，Ro = Rc |
| 分压偏置Q点 | UBQ≈VCC·Rb1/(Rb1+Rb2)（Rb1=接地那只），ICQ≈(UBQ−UBE)/Re |
| 最大不失真输出 | Uomax = min[(UCEQ−UCES), (UCC′−UCEQ)]，UCC′=交流负载线横轴截距 = UCEQ+ICQ·RL′ |
| 通频带 | fbw = fH − fL |
| 差分差模增益 Avd | 双端: −β(Rc//(RL/2))/(Rb+rbe)；单端: ±β(Rc//RL)/[2(Rb+rbe)] |
| 差分共模增益 Avc | 双端: 0；单端: ≈−R′L/(2Re) |
| 共模抑制比 | KCMR = \|Avd/Avc\|（或20lg dB）；单端≈βRe/(Rb+rbe)，双端≈∞ |
| 场效应管共源 | Au = −gm(RD//RL)，Ri 极高，Ro = RD |
| OCL 输出 | Uop=VCC−UCES，Pom=Uop²/2RL |
| OCL 效率 | η = πUop/(4VCC)，最大 ≈78.5% |
