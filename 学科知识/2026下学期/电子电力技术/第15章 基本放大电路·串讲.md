# 第15章 基本放大电路 · 串讲（为什么是这样）

> [!warning] 先诊断：你为什么觉得"朦"
> 不是你记不住，是这一章**同时跑了三条线**，课件又把它们平铺成 9 节，看着就糊：
>
> | 线 | 内容 | 变化方式 |
> |---|---|---|
> | **线1 对象** | 共射 → 稳定电路 → 三组态 → 差分 → 场效应管 → 功放 | 一节换一个电路 |
> | **线2 工具** | 图解法 / 微变等效法 / 近似估算 | 同一电路三种算法 |
> | **线3 指标** | 电压增益 → 频率 → 共模抑制 → 功率效率 | 口径在换 |
>
> **破解办法：把线2、线3 当"工具"挂在边上，主链只看线1——每一个新电路都是为了补上一个电路暴露的漏洞。**
> 下面第 1 节就是这条主链，先看懂它，再回头看细节。

## 1. 主线：九节是一条"补漏洞"的链

```
①15.1 定义什么叫"放大"        ──┐
                               │ 但要放大就得不失真
                               │ 不失真 ⇔ 器件始终在线性区 ⇔ 必须设 Q 点
②15.2 造一个能设 Q 点的电路     ←┘  （共射：VBB/Rb 定 IBQ，VCC/Rc 定 ICQ）
      ▼ 可 Q 点怎么算？输入信号怎么变成输出？
③15.3 两套分析工具（图解 / 微变）  ← 本章最核心的"工具层"
      ▼ 算完发现：Q 点会随温度漂
④15.4 加 Re 引入直流负反馈稳 Q    ← 代价是交流增益也掉了 → 用 Ce 旁路
      ▼ 但只有共射一种接法，够用吗？
⑤15.5 三种组态 CE/CC/CB          ← 共集当缓冲，共基管高频
      ▼ 上面所有公式都假设"单一频率、中频"
⑥15.6 频率特性                    ← 电容让高低频增益都掉 → 通频带
      ▼ 多级放大不能用耦合电容（否则没法集成）→ 直接耦合 → 零点漂移
⑦15.7 差分放大电路                ← 靠对称 + 取差消掉温漂
      ▼ 三极管输入电阻小，能不能换器件？
⑧15.8 场效应管放大电路            ← 电压控制、Ri 极高，三极管电路的"镜像"
      ▼ 前面都在放大"电压"，能不能直接放大"功率"？
⑨15.9 功率放大电路                ← 效率问题：甲类→乙类→甲乙类
```

**能背下来的一句话**：
> **先定义 → 造电路 → 学算法 → 发现 Q 点会漂就稳住它 → 发现一种接法不够就换接法 → 发现频率有影响就补频率 → 发现直接耦合会漂就差分 → 换器件（FET）→ 换目标（功率）。**

## 2. 逐堵"墙"的详解

### 墙 ① 什么叫"放大"（15.1）

> [!note] 放大 ≠ 凭空造能量
> **放大 = 用直流电源的能量，按输入信号的形状"塑造"输出。** 输入信号只起"控制"作用，真正出力气的是 VCC。
> 所以：**不失真是前提**，失真了放大就没意义。

**七项指标，但只需记"两进两出"**：

| 指标 | 定义 | 判断标准 | 为什么 |
|---|---|---|---|
| 放大倍数 Au | Uo/Ui | 越大越好 | — |
| **输入电阻 Ri** | Ui/Ii | **越大越好** | 从前级取电流小，不拖累信号源 |
| **输出电阻 Ro** | 输出端看进去的等效电阻 | **越小越好** | 带负载能力强（负载变化时输出电压稳） |
| 通频带 fbw | fH − fL | 越宽越好 | 适应不同频率信号 |
| 非线性失真系数 D | 谐波总量/基波 | 越小越好 | — |
| 最大不失真输出幅度 Uom | 峰峰值或有效值 | 越大越好 | — |
| 最大输出功率 Pom 与效率 η | η = Pom/PV | 功率大、效率高 | 功放专有（15.9） |

> ⭐ **"输入大、输出小"这条从 15.1 一直用到 15.5**：共集电极电路之所以值钱，就是因为它是唯一同时满足"Ri 大 + Ro 小"的组态。

### 墙 ② 为什么一定要设 Q 点（15.2）

**物理图像**：三极管的 BE 结本质是个二极管，有 ~0.7V 的门槛。输入的交流信号是"正负摆动"的，如果没有一个抬升到门槛之上的中心平台，**负半周会把 BE 结推到截止**，iB 直接被削掉 → 波形失真。

> Q 点的作用：**给交流信号一个中心平台，让波峰波谷都不出轨。**

**Q 点四件套**（直流值）：UBEQ、IBQ、ICQ、UCEQ
- ICQ = β·IBQ
- NPN 硅管 UBEQ ≈ 0.7V（PNP 锗管 −0.2V）
- UCEQ = VCC − ICQ·RC

**信号流动链（必背，一章的骨架）**：
```
ui → ΔuBE → ΔiB → ΔiC = β·ΔiB → ΔuCE = −ΔiC·RC → uo
```
> [!tip] 这条链里藏着本章最重要的三个"为什么"
> 1. **β 环节** = 电流放大，这是三极管的本事。
> 2. **RC 环节** = 把"电流变化"翻译成"电压变化"。**没有 RC 就没有电压放大**——所以 RC 不能省。
> 3. **负号**：iC 变大 → RC 上压降变大 → uCE = VCC − iC·RC 变小。**共射反相**，就是这么来的。

**各元件职责**（4 个，别记混）：
| 元件 | 作用 |
|---|---|
| T | 放大元件（执行者） |
| VCC | 供能（能量的来源） |
| RC | 电流→电压 转换器（**产生电压放大的关键**） |
| VBB、Rb | 给发射结正偏，定出静态基流 IBQ |

**两种共射电路**：
- **直接耦合**：去掉耦合电容，低频好，但零点漂移（→ 引出 15.7）
- **阻容耦合**：C1、C2 隔直通交，Q 点独立，但低频受限（→ 引出 15.6）

#### ⭐ 例题：算出 Q 点，还得判断工作在哪个区（课件 P16）

已知 β = 80，Rb = 300 kΩ，Rc = 2 kΩ，VCC = +12V（阻容耦合共射）

```
(1) Rb = 300 kΩ 时：
    IBQ = (VCC − UBEQ)/Rb ≈ 12V/300k = 40 μA     ← VCC >> 0.7V，UBE 常直接忽略
    ICQ = β·IBQ = 80 × 40μA = 3.2 mA
    UCEQ = VCC − RC·ICQ = 12 − 2k×3.2m = 5.6 V   ✅ 正值 → 放大区
    Q(40μA, 3.2mA, 5.6V)

(2) Rb = 100 kΩ 时：
    IBQ = 12V/100k = 120 μA
    ICQ = β·IBQ = 80 × 120μA = 9.6 mA
    UCEQ = 12 − 2k×9.6m = −7.2 V   ❌ 负值，不可能
         → 说明"工作在放大区"这个前提不成立
    → 取 IC 的上限：ICM = (VCC − UCES)/RC ≈ 12V/2k = 6 mA
    → 实际 Q(120μA, 6mA, 0)
    → 判据 β·IBQ (9.6mA) > ICM (6mA) → 工作在饱和区
```

> [!tip] 两条判据，任选一条
> ① 先按放大区算 UCEQ，**若 UCEQ < 0（或 < UCES）→ 饱和**；
> ② 直接比较 $\beta I_{BQ}$ 与 $I_{CM} = (V_{CC}-U_{CES})/R_C$，**大于即饱和**。
>
> **这道题真正想说明的事**：Rb 只从 300k 减到 100k（3 倍），电路就从放大区掉进饱和区。
> 这就是"**为什么必须设合适的 Q 点**"的量化证明 —— 也是 15.4 存在的理由。

### 墙 ③ 非线性器件到底怎么算（15.3）★ 最容易朦的一节

**矛盾的根源**：三极管的输入特性是指数曲线、输出特性是一族曲线 → **非线性方程，手算解不出来**。

于是有了两把工具，**它们不是"两种答案"，而是分工不同**：

| | 图解法 | 微变等效电路法 |
|---|---|---|
| **核心思路** | 不解方程，直接在特性曲线上作图求交点 | 在 Q 点附近把曲线**"拉直"成直线**，退化成线性电路 |
| **前提** | 需要特性曲线 | ①小信号（微变量）②只研究**变化量** ③工作在 Q 点附近 |
| **能求什么** | Q 点位置、**失真类型**、最大不失真幅度、参数影响趋势 | **Au、Ri、Ro**（定量，考试主力） |
| **性格** | 定性、给直觉 | 定量、给数字 |

> ⭐ **一句话分工**：**图解法用来看"位不位、歪不歪"，微变等效法用来算"多大"。**
> 考试里凡是要数字的 Au/Ri/Ro，一律用微变等效法；凡是问"什么失真、怎么调"的，用图解法。

#### 3.1 一切从这里开始：直流通路 vs 交流通路

| | 直流通路 | 交流通路 |
|---|---|---|
| 耦合电容 / 旁路电容 | **开路**（隔直） | **短路**（通交） |
| 直流电源 VCC | **保留** | **短路**（内阻为零，接"地"） |
| 用途 | 求 Q 点 | 求动态参数 Au、Ri、Ro |

#### 3.2 图解法：两条负载线

| | 直流负载线 | 交流负载线 |
|---|---|---|
| 方程 | uCE = VCC − iC·RC | 过 Q 点，斜率 −1/(RC//RL) |
| 斜率 | −1/RC | −1/(RC//RL)，**更陡** |
| 何时用 | 定 Q 点 | 看动态摆动范围、求最大幅度 |

**求 Q 点两步走**：
1. 输入回路**估算**：IBQ = (VCC − UBEQ)/Rb
2. 输出回路**作图**：直流负载线找两个特殊点（iC=0 → uCE=VCC；uCE=0 → iC=VCC/RC），与 iB=IBQ 那条曲线求交 → 得 ICQ、UCEQ

#### 3.3 失真诊断（⭐ 高频考点）

| Q 点位置 | 失真类型 | 原因 | uo 波形（NPN） |
|---|---|---|---|
| Q 点**过低** | **截止失真** | iB 的负半周被削掉（BE 结截止） | **顶部**失真 |
| Q 点**过高** | **饱和失真** | iC 的正半周顶到饱和区 | **底部**失真 |

> [!warning] 这个"顶/底"最容易记反
> **记忆法**：共射电路 **uo 与 ui 反相**。
> - 截止失真发生在 ui 的**正**半周被削 → 传到输出变成**底部**？不对——**截止是 iB 负半周被削**：ui 负半周 → iB 小 → iC 小 → uCE 大 → uo **顶部被削平**（电位高处被限制）。
> - 饱和失真：ui 正半周 → iB 大 → iC 大 → uCE 小 → uo **底部被削平**。
> **一句话**：**截止削顶、饱和削底**（NPN 共射）。

**用图解法估最大不失真幅度**（课件原式，P29）：
$$U_{omax} = \min\left[(U_{CEQ} - U_{CES}),\ (U_{CC}' - U_{CEQ})\right]$$
> - $U_{CC}'$ = **交流负载线在 uCE 轴上的截距**（iC = 0 那个点）
> - 两项含义：**往上一项**撞饱和（uCE 最多降到 UCES），**往下一项**撞截止
> - 等价写法：$U_{CC}' - U_{CEQ} = I_{CQ}\cdot R_L'$，所以也可写成 $\min\left[(U_{CEQ}-U_{CES}),\ I_{CQ}R_L'\right]$，$R_L'=R_C//R_L$
> - 课上补的结论：**Q 尽量设在线段 AB 的中点**，则 AQ = QB、CD = DE，上下同时到极限，幅度最大

**参数对 Q 点的影响**（P30–31）：

| 改变 | Q 点怎么动 |
|---|---|
| Rb ↑ | IBQ ↓ → Q 点**下移**（易截止失真） |
| VCC ↑ | 直流负载线**平行右移**，动态范围变大，但管耗也大 |
| Rc ↑ | 负载线斜率变缓 → Q 点**移近饱和区** |
| β ↑ | ICQ ↑、UCEQ ↓ → Q 点**移近饱和区** |

#### 3.4 微变等效电路法（考试主线）

**三极管怎么"拉直"**：
- **输入回路 B–E 之间** → 等效为一个电阻 **rbe**
- **输出回路 C–E 之间** → 等效为一个受控电流源 **ic = β·ib**
- （输出电阻 rce 很大，一般忽略）

$$r_{be} = r_{bb'} + (1+\beta)\frac{U_T}{I_{EQ}} \approx 200\,\Omega + (1+\beta)\frac{26\,\text{mV}}{I_{EQ}(\text{mA})}$$

> 课件实例（P44）：β=100，IEQ=4mA → rbe = 200 + 101×26/4 = **865 Ω**。这个数字要会算。

**共射电路三个动态参数（⭐ 必背）**：
$$A_u = -\frac{\beta (R_C // R_L)}{r_{be}}, \qquad R_i = R_B // r_{be}, \qquad R_o = R_C$$
> - 负号 = **反相**
> - Ri 只有 rbe 量级（几百Ω~几 kΩ）→ **偏小**，这正是共射的短板（→ 15.5 共集来补）
> - Ro ≈ RC，**偏大** → 带负载能力弱

**信号源有内阻时**（P42）：
$$\frac{\dot U_o}{\dot U_s} = \frac{R_i}{R_s + R_i}\cdot A_u$$
> 这是"Ri 要大"的量化解释：**Ri 越小，信号在 Rs 上被分掉的越多。**

**解题步骤（课件 P46 原文，4 步）**：
```
1. 首先利用图解法或近似估算法确定放大电路的静态工作点 Q。
2. 求出静态工作点处的微变等效电路参数 β 和 rbe。
3. 画出放大电路的微变等效电路。（可先画三极管的等效电路，
   再画放大电路其余部分的交流通路。）
4. 列出电路方程并求解。
```
> 考试常加第 5 步：**若问失真 → 看 Q 点位置判断（截止/饱和），并给出调整方向**。

### 墙 ④ Q 点为什么会跑（15.4）

**三管齐下的温度效应**：

| 参数 | 温度影响 | 后果 |
|---|---|---|
| UBE | −2 mV/°C | UBE 下降 → IB 增大 |
| β | +0.5% ~ +1% /°C | β 增大 |
| ICBO | 每 +10°C 约**加倍**（指数上升） | 漏电流增大 |

**合力**：温度 ↑ → **ICQ ↑ → Q 点上移 → 容易饱和失真**。

**解决办法：分压偏置 + 电流负反馈**
```
设计要点：IR >> IBQ（基极分压支路电流远大于基流）
→ UBQ ≈ Rb1/(Rb1+Rb2) · VCC  （只由分压决定，与管子无关，也不随温度变）

ICQ ≈ IEQ = (UBQ − UBE)/Re
```
> [!warning] 下标别死记（已经踩过一次）
> 本课件电路图里 **Rb2 接 +VCC（上臂）、Rb1 接地（下臂）**，所以是 **Rb1** 在分子。
> **正确记法：分压点电压 = 接地那一只 / 两只之和。** 换一本教材编号就反了，认图不认名字。

**稳定原理（闭环，必须背下来）**：
```
T↑ → ICQ↑ → IEQ↑ → UEQ(=IEQ·Re)↑ → UBEQ(=UBQ−UEQ)↓ → IBQ↓ → ICQ↓   ← 被拉回来
```
> ⭐ **这就是"直流负反馈"的第一次出场**。第 17 章会把它系统化——现在只要记住：**它是自动刹车。**

> [!tip] 为什么一定要加旁路电容 Ce
> Re 的刹车作用**对交流也一样有效**——那 Au 就完蛋了。
> 加一个大电容 Ce 与 Re 并联：**直流时 Re 起作用（稳 Q），交流时 Ce 把 Re 短路掉（保住 Au）。**
> **Ce 是"只让刹车在直流时发动"的开关。**

**⚠️ 若去掉 Ce（考试爱问）**：交流通路里 Re 还在，Au 变成
$$A_u = -\frac{\beta (R_C//R_L)}{r_{be}+(1+\beta)R_e}\ \ (\text{旁路电容缺失时})$$
**增益明显下降**，但输入电阻变大。

**其他温度补偿手段**：利用二极管的反向特性 / 正向特性做温度补偿（用热敏器件的漂移去抵消三极管的漂移）。

### 墙 ⑤ 共射够用吗：三种组态（15.5）

**判别口诀：看信号从哪进、从哪出，"公共端"是谁就叫共谁。**

**这是课件 P65–66 的原表**（$R_L'=R_C//R_L$，$R_e'=R_E//R_L$，$R_s'=R_B//R_S$）：

| 性能 | **共射 CE** | **共集 CC**（射极输出器） | **共基 CB** |
|---|---|---|---|
| 输入 / 输出 | b 进 / c 出 | b 进 / e 出 | e 进 / c 出 |
| **电压增益** $\dot A_u$ | 大（十几~几百）<br>$-\dfrac{\beta R_L'}{r_{be}}$ ← **反相** | 小（小于、近于1）<br>$\dfrac{(1+\beta)R_e'}{r_{be}+(1+\beta)R_e'}$ ← **同相** | 大（**数值同共射**）<br>$\dfrac{\beta R_L'}{r_{be}}$ ← **同相** |
| **电流增益** $\dot A_i$ | 大：**β** | 大：**−(1+β)** | **小：−α** |
| **输入电阻** $R_i$ | 中（几百Ω~几kΩ）<br>$r_{be}$ | **大（几十kΩ以上）**<br>$r_{be}+(1+\beta)R_e'$ | **小（几Ω~几十Ω）**<br>$\dfrac{r_{be}}{1+\beta}$ |
| **输出电阻** $R_o$ | 中（几十k~几百kΩ）<br>$r_{ce}$ | **小（几Ω~几十Ω）**<br>$\dfrac{r_{be}+R_s'}{1+\beta}$ | 大（几百k~几MΩ）<br>$(1+\beta)r_{ce}$ |
| 频率响应 | 差 | 较好 | **好** |
| 典型用途 | 电压放大主力 | **缓冲 / 阻抗变换** | 高频、宽带 |

> [!warning] ⚠️ 这张表和你别处看到的 "$R_o \approx R_C$" 不矛盾 —— **是两个口径**
> | 口径 | 共射 $R_o$ | 共基 $R_o$ | 从哪来 |
> |---|---|---|---|
> | **看器件本身**（本表） | $r_{ce}$（几十k~几百k） | $(1+\beta)r_{ce}$（几百k~几M） | P66 比较表，问的是"这个组态本身" |
> | **看整个电路**（含 $R_C$） | $R_C$ | $R_C//r_{cb} \approx R_C$ | P41、P64，求的是"这个电路的输出电阻" |
>
> **为什么能约掉**：$r_{ce} \gg R_C$，两者并联结果就是 $R_C$。
> **做题时**：题目画了完整的共射电路、问 $R_o$ → 答 $R_C$；题目让你比较三种组态的"器件特性" → 答 $r_{ce}$。
> **搞清这一点，"课件是不是写错了"的困惑就没了。**

**补充：考虑 $R_e$ 时的共基输入电阻**（P64）
$$R_i = R_e + \frac{r_{be}}{1+\beta}$$

**共集（射极输出器）两个招牌**：
> **Ri 极大（不拖累前级）+ Ro 极小（带得动负载）**，但 Au≈1，**只放大电流不放大电压**。

**共集三个公式（课件 P57–59 原式）**，记 $R_e' = R_E//R_L$、$R_s' = R_B//R_S$：

$$A_u = \frac{(1+\beta)R_e'}{r_{be}+(1+\beta)R_e'}\ (<1,\ \text{且同相})$$
$$R_i = R_B // \left[r_{be} + (1+\beta)R_e'\right]$$
$$R_o = R_E // \frac{r_{be}+R_s'}{1+\beta} \xrightarrow[\ (1+\beta)R_E \gg r_{be}+R_s'\ ]{} \approx \frac{r_{be}+R_s'}{1+\beta}$$

> [!warning] 两个"跟别人有关"，是本节最容易错的地方
> - **$R_i$ 与负载 $R_L$ 有关** —— 共射的 $R_i$ 与 $R_L$ **无关**，共集有关！
>   （课件原话就标在图上："ri 与负载有关"）
> - **$R_o$ 与信号源内阻 $R_S$ 有关** —— 分母里的 $R_s' = R_B//R_S$，正是这个意思。
>   所以共集电路接在不同的信号源后面，输出电阻是不一样的。

**共基的两个特点**：
- **没有电流放大**（$A_i = -\alpha$，α<1），但**有电压放大且同相**（数值和共射相同，只差一个负号）
- **Ri 极小**（$r_{be}/(1+\beta)$，几Ω~几十Ω）；**Ro 极大**（$(1+\beta)r_{ce}$，几百kΩ~几MΩ）
- **高频特性最好** → 用于高频/宽带放大

**补充：复合管（达林顿管）**
- β ≈ β1·β2，rbe = rbe1 + (1+β1)rbe2
- **同类型复合 → 类型不变；不同类型复合 → 类型随前级（第一只）**
- 用途：获得极高 β、提高中间级输入电阻（集成运放常用）

### 墙 ⑥ 为什么会跟频率有关（15.6）

**根因：电路里有两类电容，它们在不同频段"显形"。**

| 频段 | 谁在捣乱 | 后果 | 相移 |
|---|---|---|---|
| **低频段** | 耦合电容、发射极旁路电容（**容量大**）→ 容抗变大，分压掉信号 | 增益 ↓ | **超前** |
| **中频段** | 两类电容一个近似短路、一个近似开路 | **增益与频率无关** ← 前面所有公式都只在这里成立 | — |
| **高频段** | 结电容、分布电容（**容量小**）→ 容抗变小，把负载旁路掉；且 β 本身随频率下降 | 增益 ↓ | **滞后** |

$$f_{bw} = f_H - f_L \quad (\text{下限截止频率到上限截止频率})$$
> 边界定义：增益降到中频值 **0.707 倍（−3dB）** 处。

> ⭐ **必记的因果**：**低频怪耦合电容，高频怪结电容 + β 下降。**

### 墙 ⑦ 直接耦合的漂移：差分放大电路（15.7）

**为什么会有这一节**：要集成、要放大直流和低频 → 只能用**直接耦合**（去掉耦合电容）→ 但温漂没法隔绝。

**零点漂移**：输入为零，输出却**缓慢不规则地漂**。原因 = 管子参数受温度影响使 Q 点不稳（本质是温度漂移）。
> **级数越多，放大倍数越高，漂移越严重**——最后漂移把有用信号淹没了。

**抑制三招**：① 引入直流负反馈稳 Q；② 热敏元件补偿；③ **差分放大电路**（本节）

**差分的核心招数：对称 + 取差**

| 信号类型 | 定义 | 特点 |
|---|---|---|
| **共模信号** | 两输入**大小相等、极性相同** | 温漂可等效为共模 → **是要消掉的东西** |
| **差模信号** | 两输入**大小相等、极性相反** | **是要放大的有用信号** |

**三重机制**：
1. **参数完全对称** → 温度对两管影响一模一样 → 集电极电位同向同量变化 → **输出取差值就被减掉了**
2. **Re 的共模负反馈** → 共模电流同时流过 Re，Re 上压降变化 → 强烈抑制（Ac 极小）
3. **对差模，Re 相当于短路** → E 点电位在差模作用下不变 = **"虚地"**
   （同理，双端输出时负载 RL 的**中点也是虚地**）

> ⭐ **本章最值钱的一句结论**（P96）：
> **Ad 和 Ac 只与"输出方式"（双端出 / 单端出）有关，与"输入方式"（双端入 / 单端入）无关！**

**四种接法对照**：

| 接法 | Ad | Ac |
|---|---|---|
| 双入双出 | **最大** | ≈0（KCMR → ∞） |
| 双入单出 | 减半 | 有（靠 Re 抑制） |
| 单入双出 | = 双入双出 | ≈0 |
| 单入单出 | = 双入单出 | 有 |

**关键参数（课件 P96–98 原式，"只看输出方式"的具体体现）**：

$$A_{vd} = -\frac{\beta\left(R_C // \tfrac{R_L}{2}\right)}{R_b + r_{be}}\ \ (\text{双端输出}), \qquad A_{vd} = \pm\frac{\beta(R_C // R_L)}{2(R_b + r_{be})}\ \ (\text{单端输出})$$
$$A_{vc} = 0\ \ (\text{双端输出}), \qquad A_{vc} \approx -\frac{R_L'}{2R_e}\ \ (\text{单端输出})$$
$$R_{id} = 2(R_b + r_{be})\ \ (\text{单双端输入都一样}), \qquad R_{od} = 2R_C\ (\text{双出})\ /\ R_C\ (\text{单出})$$
$$K_{CMR} = \left|\frac{A_{vd}}{A_{vc}}\right| \quad\text{或}\quad 20\lg\left|\frac{A_{vd}}{A_{vc}}\right| \text{(dB)};\qquad \text{单端输出时} \approx \frac{\beta R_e}{R_b + r_{be}}$$

> [!tip] 三处必须看懂的地方
> 1. **双端输出时负载是 $R_L/2$** —— 因为 $R_L$ 的中点虚地，相当于两半分别挂在两个集电极上。
> 2. **单端输出时负载是 $R_L$**，但分母多一个 2 → 增益正好是双端的一半。
> 3. **$A_{vc} \approx -R_L'/(2R_e)$** —— 分母有 $R_e$，所以**增大 $R_e$ 就是提高共模抑制比的唯一手段**（这条式子把"为什么"写出来了）。

**长尾式电路静态**：$I_{E1}=I_{E2}=(U_{EE}-U_{BE})/2R_E$，$U_{CE1}=U_{CE2}\approx U_{CC}+U_{EE}-(R_C+2R_E)I_{E1}$，$U_o=0$

> **改善共模抑制的根本措施 = 增大 Re**（或把 Re 换成恒流源）。

### 墙 ⑧ 换个器件：场效应管放大电路（15.8）

**为什么要换**：三极管是**电流控制**、输入电阻只有 kΩ 量级。场效应管是**电压控制**，**栅极几乎不取电流 → 输入电阻 10⁹ Ω 以上**（MOS 可达 10¹⁰~10¹²）。

**① 分类（一条判据搞定）**

```
场效应管 FET（电压控制、高输入阻抗）
├─ 结型 JFET ── N沟道 / P沟道
└─ 绝缘栅型 MOSFET（IGFET）
    ├─ N沟道：增强型 / 耗尽型
    └─ P沟道：增强型 / 耗尽型
```

> [!tip] **唯一判据：UGS = 0 时，漏源之间有没有导电沟道？**
> - **有** → **耗尽型**（靠"耗尽"夹断）→ 关键电压叫 **夹断电压 UP / UGS(off)**
> - **无** → **增强型**（靠"增强"感生）→ 关键电压叫 **开启电压 UT / UGS(th)**

**② 与三极管的对应（换个名字而已）**

| 三极管 | 场效应管 | 作用 |
|---|---|---|
| b 基极 | **G 栅极** | 控制端 |
| e 发射极 | **S 源极** | 载流子来源 |
| c 集电极 | **D 漏极** | 载流子收集 |

**三个工作区**：可变电阻区 / **恒流区（=放大区，放大用）** / 夹断区
**放大条件**：工作在**恒流区**（对应三极管的放大区）

**N 沟道增强型的工作原理四步**（P104–107）：
1. UGS=0：源漏之间是两个背靠背 PN 结 → 不通
2. 0 < UGS < UT：排斥衬底空穴，形成耗尽层
3. UGS ≥ UT：形成**反型层（N 型导电沟道）**→ 但 UDS=0，ID=0
4. UDS > UGS−UT：沟道呈**楔形**，漏端出现**预夹断**，之后 iD 基本由 uGS 决定，与 uDS 无关 → **可视为受 uGS 控制的电流源**

**③ 静态工作点三种设法（课件有、容易漏！）**

| 方法 | 适用 | 关键式 |
|---|---|---|
| **基本共源** | 增强型 MOS | 外加 VGG 直接给 UGSQ = VGG |
| **自给偏压** | JFET / 耗尽型 MOS | **UGSQ = −IDQ·RS**（靠 RS 上压降自造负偏压） |
| **分压式偏置** | 增强型 MOS | 由 R1、R2 分压定 UGQ，再联立转移特性求 IDQ |

**分压式输出回路**：UDSQ = VDD − IDQ(RD + RS)

**④ 动态分析**

- 核心参数：**跨导 gm = ΔiD/ΔuGS**（单位 mS），一般 **0.1 ~ 20 mS**；rDS 几百 kΩ，常视为开路
- **共源**：$A_u = -g_m(R_D // R_L)$（**反相**），Ri 极高，$R_o = R_D$
- **共漏（源极跟随器）**：$R_i = R_G + (R_1//R_2)$，$R_o = R_S // \frac{1}{g_m}$（**小**），Au < 1 同相

| FET 组态 | 对标三极管 | 特点 |
|---|---|---|
| 共源 CS | 共射 CE | 有电压放大（反相） |
| 共漏 CD | 共集 CC | Au≈1，Ri 大，Ro 小 |
| 共栅 CG | 共基 CB | 高频好 |

**⑤ 特点小结**：电压控制、**输入阻抗极高**、噪声小、温漂小、利于集成；
**但跨导小，电压放大倍数一般低于三极管**；⚠️ **存放时栅源要短接，焊接时烙铁要良好接地**（防静电击穿——MOS 管著名的死法）。

### 墙 ⑨ 目标换成"功率"：功率放大电路（15.9）

**为什么共射不能当功放**（P132–133）：静态时电源提供的功率 ICQ·VCC 全部消耗在 RC 和管子上 → **输出功率只有一部分、效率仅 25%**。

> [!note] 功放的**根本矛盾**
> 要有大输出功率 → 就要有大信号 → 静态电流就得大 → **静态一直白白耗电** → 效率低。
> **解法只有一条：让管子"按需导通"，别一直开着。**

**① 三项指标**：最大输出功率 Pom、转换效率 η = Pom/PV、最大输出电压 Uom
（功放管工作在**极限状态**，要选 ICM、U(BR)CEO、PCM，要装**散热片**）

**② 按导通角 θ 分类**

| 类别 | 导通角 | 理想效率 | 说明 |
|---|---|---|---|
| **甲类** | θ = 2π（全周期导通） | 共射 ≤25%，**变压器耦合 ≤50%** | 失真小，静态功耗大 |
| **乙类** | θ = π（半周期） | **最高 ≈78.5%** | **有交越失真** |
| **甲乙类** | π < θ < 2π | 介于之间 | **实用**（微导通，消除交越失真） |
| 丙类 | θ < π | — | 严重失真，用于高频谐振功放 |
| 丁类 | 开关状态 | 很高 | 管子只在饱和导通时耗功 |

**③ 电路形式演进**

```
变压器耦合 → OTL（无输出变压器，单电源 + 大电容）→ OCL（无输出电容，双电源）→ BTL（桥式）
```

| | **OTL** | **OCL** |
|---|---|---|
| 供电 | **单电源** | **双电源（±VCC）** |
| 关键件 | 输出大电解电容（几百~几千 μF） | 无输出电容 |
| 静态 | 电容上电压 = **VCC/2**，基极电位设为 VCC/2 | T1、T2 均**截止**，**输出电压为 0** |
| 工作 | T1、T2 轮流导通，射极跟随 | 正负电源交替供电，双向跟随 |

**术语辨析（爱考）**：
- **互补**：**不同**类型的两只管子（NPN+PNP）交替工作
- **推挽**：**同**类型管子交替导通（变压器耦合电路用的）

**④ 交越失真**：乙类时，管子有开启电压 → 输入在 0 附近时两管都不通 → 出现"死区"
> **消除方法**：静态时给两管加一个略大于两管开启电压之和的偏压，使其**微导通** → 工作在**甲乙类**。
> （课件用 D1、D2 + R2 提供偏压：UB1,B2 = UD1 + UD2 + UR2，静态调节 R1 使 uo = 0）

**⑤ OCL 公式四件套（⭐ 必考）**

> ⚠️ **先把符号分清，这是最容易翻车的地方**（课件两个符号混着用）：
> | 符号 | 含义 | 与 VCC 的关系 |
> |---|---|---|
> | $U_{op}$ | 最大输出**幅值**（峰值） | $= V_{CC} - U_{CES}$ |
> | $U_{om}$ | 最大输出**有效值** | $= (V_{CC}-U_{CES})/\sqrt2$ |

$$U_{op} = V_{CC} - U_{CES} \quad(\text{最大输出幅值})$$
$$P_{om} = \frac{U_{om}^2}{R_L} = \frac{U_{op}^2}{2R_L} = \frac{(V_{CC}-U_{CES})^2}{2R_L} \quad(\text{两种写法等价，看题目给的是幅值还是有效值})$$
$$i_c = \frac{V_{CC}-U_{CES}}{R_L}\sin\omega t \quad(\text{集电极电流})$$
$$P_V = \frac{2}{\pi}\cdot\frac{V_{CC}(V_{CC}-U_{CES})}{R_L} \quad(\text{正负电源总共消耗的平均功率，等于平均电流} \times \text{电源电压})$$
$$\eta = \frac{P_{om}}{P_V} = \frac{\pi}{4}\cdot\frac{V_{CC}-U_{CES}}{V_{CC}} \xrightarrow{\ U_{CES}\to 0\ } \eta_{max} = \frac{\pi}{4} \approx 78.5\%$$
> 课件原话：**理想情况下 UCES 可忽略；但大功率管 UCES 较大，不能忽略。**

> **课件例题（P146）**：VCC = 15V，UCES = 3V，RL = 4Ω
> ① $P_{om} = \dfrac{(15-3)^2}{2\times4} = \dfrac{144}{8} =$ **18 W**；$\eta = \dfrac{\pi}{4}\times\dfrac{12}{15} =$ **0.62**（≈62.8%）
> ② 若输入最大有效值 8V（Uo ≈ Ui）→ $U_{om}$ = 8V（**有效值**）→ $P_{om} = \dfrac{8^2}{4} =$ **16 W**
> ⚠️ 两问口径不同：**① 给的是电源电压（→ 幅值），② 直接给有效值**。用的公式也不同，别用混。

**⑥ 集成功率放大电路**
- **LM386**（OTL 音频功放）：内部三级 = **差分输入级（双入单出）+ 共射中间级（恒流源有源负载）+ OTL 输出级**；R7 引入**深度电压串联负反馈**；**增益可调 20~200**（1、8 脚之间接电容可到最大，接电阻可调）
- **TDA1521**：2 通道 OCL 立体声功放，Pom = 12W，Uom = 9.8V
- **TDA1556**：2 通道 BTL 立体声功放

> ⭐ 注意 LM386 内部结构这一句——**它是第 16 章集成运放结构的完整预告**（差分输入 + 共射中间级 + 功放输出级）。

### 表 A：审题决策流

```
题目问什么？
│
├─ 问 Q 点数值 ──────────────→ 画直流通路（电容开路，VCC 保留）
│                              估算 IBQ ≈ VCC/Rb → ICQ = β·IBQ → UCEQ = VCC − ICQ·Rc
│                              ⚠️ 还要判工作区（课件 P16 例题）：
│                                 UCEQ < 0（或 β·IBQ > ICM）→ 饱和区
│                                 此时取 ICQ = ICM = (VCC−UCES)/Rc，UCEQ ≈ 0
│
├─ 问 Au / Ri / Ro ──────────→ 画交流通路（电容短路，VCC 接地）
│                              换成 rbe + βib → 列方程
│                              （若是共集/带 Re 未旁路，注意 (1+β)R 项）
│
├─ 问"什么失真 / 怎么调" ───→ 用图解法 + Q 点位置
│                              Q 低→截止（削顶）→ 减小 Rb / 增大 IBQ
│                              Q 高→饱和（削底）→ 增大 Rb / 增大 Re
│
├─ 问"最大不失真幅度" ─────→ Uomax = min[UCEQ-UCES, ICQ·R'L]
│
├─ 问组态 / 波形对不对 ────→ 看信号从哪进哪出；共射反相、共集共基同相
│
├─ 问差分电路 ─────────────→ 先判输入方式（双/单入）、再判输出方式（双/单出）
│                              Ad、Ac 只看输出方式！Rid=2(Rb+rbe)
│
└─ 问功放功率 / 效率 ──────→ Uop=VCC-UCES → Pom=Uop²/2RL → η=πUop/(4VCC)
                               ⚠️ 分清给的是幅值还是有效值
```

### 表 B：Q 点 ↔ 失真 速查（NPN 共射）

| 现象 | 诊断 | 调整 |
|---|---|---|
| uo **顶部**削平 | **截止失真**（Q 过低，iB 负半周被削） | 减小 Rb（增大 IBQ）；或减小 Rc |
| uo **底部**削平 | **饱和失真**（Q 过高，iC 正半周进饱和） | 增大 Rb；或增大 Re、减小 Rc |

## 4. ⚠️ 十三个最容易"朦"和最容易错的地方

| # | 坑 | 正解 |
|---|---|---|
| 1 | 把图解法当"另一种算法" | 图解法管**定性/失真/幅度**，微变等效法管**定量参数**，不是二选一 |
| 2 | 直流负载线 = 交流负载线 | **不一样**。交流负载线过 Q 点、更陡（斜率 −1/(Rc//RL)） |
| 3 | 认为"放大是信号自己变大了" | 放大是**直流电源供能 + 信号控制**，信号只做"指挥" |
| 4 | 记反截止/饱和削顶削底 | NPN 共射：**截止削顶、饱和削底** |
| 5 | 忘掉 Ce 的作用 | **Ce = 只让 Re 的负反馈在直流时生效**，去掉它 Au 大幅下降 |
| 6 | 共集的 Ri 与 RL 无关 | **有关！** Ri = Rb//[rbe+(1+β)(Re//RL)]（共射才无关） |
| 7 | 差分电路 Ad、Ac 与输入方式有关 | **无关**，只与**输出方式**有关（单出 = 双出的一半） |
| 8 | 混淆 UP 与 UT | **增强型用 UT（开启电压），耗尽型用 UP（夹断电压）**；判据是 UGS=0 有没有沟道 |
| 9 | OCL 公式里 Uop 当有效值用 | **Uop 是幅值**（=VCC−UCES），Uom 是有效值；Pom=Uop²/2RL=Uom²/RL，别混 |
| 10 | 甲/乙/甲乙类效率记混 | 甲类 ≤25%（共射）/≤50%（变压器）；乙类 ≈78.5%；**甲乙类是实用的那个** |
| 11 | 看到课件写 $R_o=r_{ce}$ 就以为和自己记的 $R_o=R_C$ 冲突 | **是两个口径**：器件本身 = $r_{ce}$；整机（含 $R_C$）= $R_C$。因 $r_{ce}\gg R_C$，并联后就是 $R_C$ |
| 12 | 以为共集的 $R_i$、$R_o$ 只由自己决定 | **$R_i$ 与 $R_L$ 有关，$R_o$ 与 $R_S$ 有关**（共射才无关） |
| 13 | 算出 $U_{CEQ}<0$ 就以为算错了 | 不是算错，是**假设"放大区"不成立** → 电路在饱和区，取 $I_{CM}=(V_{CC}-U_{CES})/R_C$ |
