## 0. 先看结论：这本书该怎么定位

**一句话**：它是一本**面向非电类专业的电子技术通识教材**，特点是"广而浅"。

对你的价值排序：

| 用途 | 评价 |
|------|------|
| 电力电子技术A 的**入门铺垫** | ⭐⭐⭐⭐ 很合适，整流/逆变/斩波概念讲得清楚 |
| 电力电子技术A 的**主教材** | ⭐⭐ **不够**，现代内容缺失严重（见第 5 节） |

## 1. 为什么你觉得难 —— 5 个真实原因

不是你笨，是这本书的**结构性难度**摆在那儿：

### ① 它其实是两本完全不同的书
- 第14–19 章 = **模拟电子技术**（连续信号，要算、要画图、要近似）
- 第20–23 章 = **数字电子技术**（离散信号，要逻辑、要状态）

学到第 20 章会突然**换脑**。很多人在这里崩，以为是难度陡增，其实是**思维方式换了**。

### ② 起手就缺物理基础
第14 章半导体要懂：能带、载流子、掺杂、PN 结……书上只用 4 页（p23–27）带过。
没物理底子 → **起点就卡死**。

> 对策：这一段**允许跳过细节，只记结论**。不要在第一页就死磕。

### ③ 器件和电路"循环依赖"
要先懂器件特性才能分析电路，但器件特性又得在电路里才显现出来。
这是**先有鸡还是先有蛋**的问题，第一次学必然懵。

> 对策：**先接受，后回看**。第一遍把器件当"黑盒规则"用，学完电路再回头看第14章，会豁然开朗。

### ④ 同一件事讲三遍
放大电路（第15章）用了三种方法：
- 图解法（p59、p67）
- 微变等效电路法（p61）
- 工程估算

书上三种都讲，但**不说哪个是重点**。

> 对策：**微变等效电路法是主线**（考试/实用都用它），图解法只用来建立直觉。

### ⑤ 工程近似 vs 数学精确
满篇"忽略""近似""理想化"——最典型的是**理想运放的"虚短虚断"**（p117）。
习惯了数学精确推导的人极不适应。

> 对策：接受"工程上足够准就是对的"。这行的规则是**量级正确 > 数值精确**。

## 3. 学习路线（按你的课程倒推）

你有 **电力电子技术A**（4学分，周二/周三晚，李杰、齐洁）+ 数字电路基础需求。
按这个顺序走，别从头线性读：

### 阶段 1：打通器件地基（第14章，p23–54）— 必啃
这是**唯一的地基**，绕不过去。

| 内容 | 页码 | 优先级 |
|------|------|--------|
| PN 结及其单向导电性 | p27 | 🔴 核心 |
| 二极管伏安特性 | p29 | 🔴 核心 |
| 三极管电流分配和放大原理 | p37 | 🔴 核心 |
| 三极管特性曲线 | p40 | 🔴 核心 |
| 稳压二极管 | p33 | 🟡 重要 |
| 半导体的导电特性（本征/N型/P型） | p23–27 | 🟢 只记结论 |

### 阶段 2：放大与反馈（第15–17章，p55–174）— 选择性学
**如果时间紧，这阶段可以只抓概念。**

必须搞懂（因为电力电子要用）：
- 🔴 **三极管三种工作状态：截止 / 放大 / 饱和**（p40 特性曲线）—— 这是电力电子"开关工作"的基础！
- 🔴 微变等效电路法（p61）
- 🟡 负反馈的四种类型（p152）

可浅尝：频率特性（p75）、功率放大（p91）、场效管细节（p96）

### 阶段 3：电能变换（第18–19章，p175–238）— 你的课核心 ⭐
**这是主线，投入最多时间。**

**第18章 直流稳压电源**（p175–201）— 19章的前置
```
交流 → 整流(18.1) → 滤波(18.2) → 稳压(18.3) → 直流
```
- 🔴 单相桥式整流（p177）
- 🔴 电容滤波（p182）
- 🟡 串联型稳压（p189）、开关型稳压（p193）

**第19章 电力电子技术**（p202–238）— 正片
- 🔴 晶闸管（p203–210）
- 🔴 可控整流电路（p213）
- 🔴 电压型单相/三相桥式逆变（p228、p229）
- 🔴 正弦波脉宽调制 SPWM（p233）
- 🟡 交流调压（p234）
- ⚠️ 直流斩波（p236）— **不到1页，严重不足**

### 阶段 4：数字部分（第20–23章，p239–427）
和你的**离散数学**强联动，学起来会比模拟部分轻松。

- 🔴 **第20章 门电路和组合逻辑**（p239–315）— 重中之重

## 4. 具体学法（这本书的正确打开方式）

### ✅ 波形是第一语言
模拟/电力电子部分，**看懂波形图比背公式重要 10 倍**。
每学一个电路，自己动手画一遍电压/电流波形。画不出来 = 没懂。

### ✅ 三遍法
| 遍数 | 做什么 |
|------|--------|
| 第1遍 | 看框图 + 看结论，**不纠结推导**，建立直觉 |
| 第2遍 | 跟推导，搞清公式从哪来 |
| 第3遍 | 做题 + 画波形（习题答案在 p443） |

### ✅ 用仿真代替空想
书附录 I 有 **NI Multisim 10.1 简介**（p439）。
装个 **LTspice**（免费）或 Multisim，把半波整流、桥式整流、斩波电路搭出来看波形。
**这比干读强 10 倍** —— 尤其是电力电子，波形一出来原理就通了。

### ✅ 建"四件套"笔记卡
每种变换电路一张卡，固定四栏：
```
器件 → 拓扑 → 波形 → 公式
```
例：Buck 电路 / 桥式整流 / 单相逆变 …… 各一张。

### ✅ 别在物理细节上卡死
第14章的能带理论、载流子运动，**第一遍直接跳**。
等你学完三极管放大，再回头看会秒懂。

## 5. ⚠️ 关键缺口：这本书对你的课不够用

你的 **电力电子技术A** 大纲是：
> 功率半导体（MOSFET、IGBT）/ AC-DC 整流 / **DC-DC 变换（Buck、Boost、Buck-Boost）** / DC-AC 逆变 / **PWM 控制**

本书第19章的覆盖情况：

| 大纲要求 | 本书情况 |
|---------|---------|
| AC-DC 整流 | ✅ 充分（18.1 + 19.2，p176–221） |
| DC-AC 逆变 | ✅ 尚可（19.3，p228–234） |
| PWM 控制 | ⚠️ 只有 SPWM 一小节（p233），讲得太浅 |
| DC-DC 变换（Buck/Boost） | ❌ **19.5 直流斩波不到 1 页（p236）** |
| IGBT / 功率 MOSFET | ❌ 19.1.3 仅 3 页（p210–213），且以晶闸管为主线 |

**根本原因**：本书第19章以**晶闸管（SCR，老式半控器件）**为主线，
而你的课讲**现代全控器件（IGBT / MOSFET）** —— 这是两条技术路线。

### 建议
1. **本书读第18–19章当作"概念铺垫"**，先把整流/逆变/斩波的物理图像建立起来
2. **另配一本现代电力电子教材**：如 **王兆安《电力电子技术》（第5版）** —— Buck/Boost/IGBT/PWM 讲得系统
3. 上课以老师 PPT 为准，本书查缺补漏
