# 第14章 常用半导体器件 — 知识框架

> [!tip] 一句话主线
> 这一章是整本模拟电子书的**地基**：从"半导体为什么能导电"讲到"二极管、三极管怎么用"。
> 全章只有一个终极目标——**理解 PN 结的单向导电性**，二极管、三极管全是它派生的。
> 学完要能回答三件事：①PN结为什么单向导电 ②三极管为什么能放大 ③怎么判断管子工作在哪个区。

## 2. 1.1 半导体基础知识

### 2.1 本征半导体
- **定义**：纯净的、有晶体结构的半导体（硅 Si / 锗 Ge）
- **两种载流子**：
  - **自由电子**（带负电）
  - **空穴**（可看作带正电的载流子）—— 电子挣脱共价键后留下的空位
- 电子-空穴**成对出现**；不断产生（本征激发）又不断复合，温度一定时达到动态平衡
- 载流子浓度**随温度升高按指数规律增大** → 导电能力增强
- T = 0 K 时不导电（如绝缘体）
- 室温下：硅 n=p≈1.43×10¹⁰/cm³；锗 n=p≈2.38×10¹³/cm³

### 2.2 杂质半导体（关键结论表）
| | N 型半导体 | P 型半导体 |
|---|---|---|
| 掺入杂质 | 5价（磷、锑、砷） | 3价（硼、镓、铟） |
| 杂质原子 | **施主**原子（施放电子） | **受主**原子（接受电子→产生空穴） |
| 多数载流子（多子） | **自由电子**（n >> p） | **空穴**（p >> n） |
| 少数载流子（少子） | 空穴 | 电子 |

> [!note] 两个"决定"
> - **多子**浓度由**掺杂浓度**决定
> - **少子**浓度由**温度**决定（少子对温度敏感 → 这是后面温漂的根源）
> - 杂质半导体整体保持**电中性**

### 2.3 PN结（本章地基 ⭐）
**形成过程（五步，理解即可）**：
```
扩散运动(多子浓度差) → 形成空间电荷区/耗尽层 → 产生内电场
   → 内电场阻碍扩散、促进漂移(少子) → 扩散与漂移动态平衡 → PN结稳定
```

**单向导电性（必背 ⭐）**：
| 偏置 | 接法 | 空间电荷区 | 结果 |
|------|------|-----------|------|
| 正向偏置（正偏） | P 接 + | **变窄** | 导通，正向电流大 |
| 反向偏置（反偏） | P 接 − | **变宽** | 截止，只有很小的反向饱和电流 IS |

**PN结电流方程**（只需定性掌握）：
$$ i = I_S \left( e^{\frac{u}{U_T}} - 1 \right), \quad U_T = \frac{kT}{q} \approx 26\,\text{mV (300K)} $$

**伏安特性**：正向特性 + 反向特性 + 反向击穿
- 反向击穿两种机制：**齐纳击穿**（高掺杂、低压）、**雪崩击穿**（低掺杂、高压）→ 稳压管原理

**电容效应**：结电容 Cj = 势垒电容 Cb + 扩散电容 Cd
- 反偏：Cb 为主（Cj≈Cb）；正偏：Cd 为主（Cj≈Cd）
- 高频时要考虑结电容的影响

## 3. 1.2 半导体二极管

### 3.1 结构与伏安特性
- **结构**：PN结 + 引线 + 封装
  - 点接触型：结面积小、结电容小 → 检波/变频等**高频**电路
  - 面接触型：结面积大 → 工频大电流**整流**
  - 平面型：用于**集成电路**
- **伏安特性**：同 PN结。开启电压 / 导通电压
  | | 硅 Si | 锗 Ge |
  |---|-------|-------|
  | 开启电压（死区） | 0.5 V | 0.1 V |
  | 导通电压 UD(on) | **0.7 V** | 0.2 V |
- **温度影响**：负温度系数 —— 温度升高，正向特性**左移**、反向特性**下移**

### 3.2 主要参数
| 参数 | 含义 |
|------|------|
| IF | 最大整流电流（正向平均电流上限） |
| U(BR) / URM | 反向击穿电压 / 最高反向工作电压 |
| IR (IS) | 反向电流（越小越好，对温度敏感） |
| fM | 最高工作频率 |
| Cj | 极间电容 |

### 3.3 分析方法与等效模型（大信号）
| 模型 | 近似程度 | 正偏 | 反偏 |
|------|----------|------|------|
| 理想模型 | 最粗 | 压降 0（开关闭合） | 电流 0（开关断开） |
| **恒压降模型** | 常用 | 恒压源 UD(on)（硅 0.7V） | 截止（支路断开） |
| 折线模型 | 最细 | 有内阻的恒压源 | 截止 |

### 3.4 稳压二极管（反向击穿区工作 ⭐）
- **工作条件**：**反偏**，工作在反向击穿区（电流变化大、电压几乎不变）
- **稳压电路**：UO = UZ
  ```
  UI↑ → UO↑ → IZ↑ → IR↑ → UR↑ → UO↓   ← 靠 IZ 变化补偿 UI 波动
  ```
  （关键元件：**限流电阻 R**，必须保证 IZmin < IZ < IZmax）
- **主要参数**：
  - UZ：稳定电压
  - **rZ = ΔUZ/ΔIZ**：动态电阻（**越小**稳压性能越好）
  - PZM：最大耗散功率
  - IZmax / IZmin：最大/最小稳定工作电流
  - 温度系数 αVZ

### 3.5 其他类型二极管
| 二极管 | 工作条件 | 用途 |
|--------|----------|------|
| 发光二极管 LED | **正偏** | 发光（导通压降 1~2V，电流几十 mA） |
| 光电二极管 | **反偏** | 光电转换（有光照产生光电流） |
| 变容二极管 | 反偏 | 电容随电压变化（调谐） |
| 隧道 / 肖特基 | — | 高频、高速 |

## 4. 1.3 双极型晶体管（三极管 BJT）

### 4.1 结构与类型
- **两种类型**：NPN、PNP（以 NPN 为主）
- **"三区三极两结"**：发射区、基区、集电区；e(发射极)、b(基极)、c(集电极)；发射结、集电结
- 名称由来：**双极型** = 电子、空穴**两种载流子**都参与导电
  （对比第15章的场效应管 FET 是单极型、只有多子导电）

### 4.2 电流放大作用（核心 ⭐）
**放大必须同时满足（内外因）**：
| 内因（结构） | 外因（偏置） |
|--------------|--------------|
| 发射区高掺杂 | 发射结**正偏** |
| 基区做得很薄、低掺杂 | 集电结**反偏** |
| 集电区面积大 | — |

**内部载流子运动**（理解链）：
```
发射结正偏 → 发射区电子注入基区(扩散)
   → 大部分电子被集电结收集(漂移) → IC
   → 少数电子与基区空穴复合 → IB
```
（基区薄 + 低掺杂 → 复合少 → β 大）

**电流分配关系（必背 ⭐）**：
$$ I_E = I_C + I_B $$
$$ I_C = \beta I_B + I_{CEO}, \quad I_E = (1+\beta) I_B + I_{CEO} $$
$$ I_{CEO} = (1+\beta) I_{CBO} \quad (\text{穿透电流} = (1+\beta)\times\text{反向饱和电流}) $$

### 4.3 共射特性曲线与三个工作区（高频考点 ⭐）
**输入特性**：iB = f(uBE)|uCE。uCE≥1V 后曲线右移
**输出特性**（三个区，判断工作状态的核心）：

| 工作区 | 偏置条件 | 电流关系 | 用途 |
|--------|----------|----------|------|
| **放大区** | 发射结正偏、集电结反偏 | **IC = β·IB**（恒流、受控） | 放大 |
| **饱和区** | 两个结都正偏 | IC ≠ βIB（IC 不再随 IB 增大） | 开关闭合 |
| **截止区** | 两个结都反偏 | IB<0、IC≈0 | 开关断开 |

> [!important] 与电力电子的联系
> 饱和≈导通、截止≈关断 —— 这就是电力电子"**开关工作**"的物理基础。
> 放大区只在模拟放大时用；电力电子器件主要工作在饱和/截止来回切换。

### 4.4 主要参数
| 类别 | 参数 |
|------|------|
| 直流参数 | β（直流放大系数）、ICBO、ICEO |
| 交流参数 | β（交流）、α（共基）、fT（特征频率，β降到1的频率） |
| 极限参数 | **PCM** 最大集电极耗散功率、**ICM** 最大集电极电流、击穿电压 U(BR) |

$$ \beta = \frac{\alpha}{1-\alpha}, \quad \alpha = \frac{\beta}{1+\beta}, \quad U_{(BR)CBO} > U_{(BR)CEO} > U_{(BR)EBO} $$

（PCM、ICM、U(BR)CEO 围成的区域 = 安全工作区，使用不得超过）

### 4.5 温度的影响
| 参数 | 影响 |
|------|------|
| ICBO | 每升高 **10°C 约加倍**；硅管 ICBO 比锗管小得多 |
| 输入特性 | 温度升高正向特性**左移** |
| 输出特性 | 温度升高 **IC 增大**（Q 点上移 → 第15章的温漂根源） |

### 4.6 三极管工作状态的判断（必考 ⭐）
**① 电位判别法**（对 NPN 管）：
```
放大区：UC > UB > UE
饱和区：UE < UC ≤ UB
截止区：...
（PNP 管全部不等式反向：放大时 UC < UB < UE）
```
**② 电流判别法**：
```
IB > IBS(临界饱和基流) → 饱和
IB < IBS              → 放大
```

**③ 判断管型与硅/锗**（给三个电极电位时）：
| 判断项 | 依据 |
|--------|------|
| 硅/锗 | UBE≈0.6~0.7V → 硅；UBE≈0.2~0.3V → 锗 |
| NPN/PNP | NPN：UBE>0（b 比 e 高 0.7）；PNP：UBE<0 |
| 找 b 极 | 与 e 差一个 UBE(0.7/0.2V) 的那个电极 |

**④ 电流方向判断管脚/管型**（电流法）：利用 IE = IB + IC 和 KCL，电流流向"流出"的为 e 极等。

## 5. 全章公式速查表

| 内容 | 公式 |
|------|------|
| PN结电流 | i = IS·(e^(u/UT) − 1)，UT≈26mV@300K |
| 三极管电流分配 | IE = IC + IB |
| 放大区 | IC = βIB + ICEO |
| 穿透电流 | ICEO = (1+β)ICBO |
| β 与 α | β = α/(1−α)，α = β/(1+β) |
| 稳压管动态电阻 | rZ = ΔUZ/ΔIZ（越小越好） |
| 击穿电压关系 | U(BR)CBO > U(BR)CEO > U(BR)EBO |
