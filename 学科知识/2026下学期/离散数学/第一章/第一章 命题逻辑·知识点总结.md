## 1.1 命题与联结词

### 命题的判定（两步）
1. 是不是**陈述句**？（疑问/祈使/感叹句直接排除）
2. 有没有**唯一真值**？（真值未知 ≠ 不唯一）

典型易错点：
- 「本命题是假的」→ 悖论，真假共存，**不是命题**
- 「x + y > 10」→ 命题**变元**，真值不唯一，不是命题
- 「明年中秋晚上是晴天」「火星上有生命」→ 真值现在未知但**客观唯一**，是命题（"待定"）
- 「11 + 1 = 100」→ 是命题，真假取决于进制
- 「我和他是同学」→ **简单命题**（不要硬拆）；「我和他都是学生」→ 复合命题

### 五个联结词（必背真值表）

| 联结词 | 记号 | 语义 | 为真条件 |
|---|---|---|---|
| 否定 | ¬p | 非p | 与 p 相反 |
| 合取 | p∧q | p且q | **全真为真** |
| 析取 | p∨q | p或q | **有真为真**（相容或） |
| 蕴涵 | p→q | 若p则q | **仅当前真后假时为假** |
| 等价 | p↔q | 当且仅当 | **同真同假为真** |

### 蕴涵 → 的三个坑（考试最爱）
1. **p 为假时 p→q 恒为真**。「若3+3≠6 则地球是静止的」是真命题。
2. 自然语言变体要分清方向：**「只要p就q」「p仅当q」「只有q才p」都符号化为 p→q**（q 是必要条件）。
3. p、q 无内在联系也能组成蕴涵式——数理逻辑只看真值，不看语义。

> 记忆锚点（课件例子）：「上了王者就带你飞」——只有**上了王者却没带你飞**（前真后假）才算失信；没上王者时无论带不带都不算失信。

### 互斥或
自然语言的"或"若表达互斥（且两命题本身不互斥），要拆开写：
- 总冠军是湖人或火箭：p、q 本身互斥 → 直接 `p∨q`
- 老王或老李中一人出差：t、u 本身不互斥 → `(t∧¬u)∨(¬t∧u)`

### 符号化要点
- **优先级：¬ > ∧ > ∨ > → > ↔**，同级从左往右，拿不准就加括号
- 联结词常被省略：「狗急跳墙」= p→q
- 否定词位置要准：「你和他不都是傻子」= ¬(p∧q)，不是 ¬p∧q
- 附加联结词：p↑q（与非）、p↓q（或非）、p⊕q（异或）——16 个二元真值函数中的三个

## 1.2 命题公式与赋值

- **命题常元**（有确定真值）vs **命题变元**（类比函数的自变量，未赋值前不是命题）
- **合式公式**：递归定义——(1) 单个变元/常元是基础；(2)(3) ¬、∧、∨、→、↔ 构造是归纳；(4) 有限次构造是极小性。命题公式是符号串，**不是命题**
- **公式层次**：单个变元是 0 层；¬B 比 B 高一层；二元联结取 max(i,j)+1
- **赋值/解释**：给全部变元各指派一个真值；使 A=1 的叫**成真赋值**，使 A=0 的叫**成假赋值**
  - 变元按 p₁p₂…（下标序）或 p,q,r（字典序）排列赋值，如 011 表示 p=0,q=1,r=1
- **真值表**：n 个变元 → 2ⁿ 行；构造时各层次列从低到高，公式值放最后一列

### 公式三分类
| 类型 | 定义 | 主范式特征 |
|---|---|---|
| 重言式（永真） | 所有赋值下为真 | 含全部 2ⁿ 个极小项 |
| 矛盾式（永假） | 所有赋值下为假 | 主析取范式记作 0 |
| 可满足式 | **不是**矛盾式 | 至少含 1 个极小项 |

关系：重言式 ⊂ 可满足式；重言式的否定是矛盾式，反之亦然。

## 1.3 等值演算

- n 个变元只能生成 **2^(2ⁿ) 个真值不同的公式**（真值函数），但公式写法无穷多——等值演算就是"换写法"
- **A ⇔ B 的定义**：A↔B 是重言式。注意 ⇔ 是**公式间的关系符号**，不是联结词；计算机无法直接判断 A⇔B，但可以计算 A↔B 是否重言式
- 判定 A⇔B：真值表完全相同，或主范式相同

### 16 条等值式（课件原话：全文背诵）
```
1. 双重否定律    A ⇔ ¬¬A
2. 幂等律        A ⇔ A∨A,  A ⇔ A∧A
3. 交换律        A∨B ⇔ B∨A,  A∧B ⇔ B∧A
4. 结合律        (A∨B)∨C ⇔ A∨(B∨C),  (A∧B)∧C ⇔ A∧(B∧C)
5. 分配律        A∨(B∧C) ⇔ (A∨B)∧(A∨C)   ← ∨对∧ 也分配，与代数不同！
                 A∧(B∨C) ⇔ (A∧B)∨(A∧C)
6. 德·摩根律     ¬(A∨B) ⇔ ¬A∧¬B,  ¬(A∧B) ⇔ ¬A∨¬B
7. 吸收律        A∨(A∧B) ⇔ A,  A∧(A∨B) ⇔ A
8. 零律          A∨1⇔1,  A∧0⇔0
9. 同一律        A∨0⇔A,  A∧1⇔A
10. 排中律       A∨¬A ⇔ 1
11. 矛盾律       A∧¬A ⇔ 0
12. 蕴涵等值式   A→B ⇔ ¬A∨B           ★ 用得最多
13. 等价等值式   A↔B ⇔ (A→B)∧(B→A)
14. 假言易位     A→B ⇔ ¬B→¬A
15. 等价否定等值式 A↔B ⇔ ¬A↔¬B
16. 归谬论       (A→B)∧(A→¬B) ⇔ ¬A
```
两个扩展吸收律（习题常用）：
- `A∨(¬A∧B) ⇔ A∨B`
- `(A∧B)∨(¬A∧C)∨(B∧C) ⇔ (A∧B)∨(¬A∧C)`（共识律/第三吸收律）

### 置换规则
公式 F(A) 中子公式 A 换成与之等值的 B，得 F(B) ⇔ F(A)。**可以只换局部**——这是等值演算能一步步推的关键。

### 实际应用
嵌套 if-else 化简：`if P then (if Q then X else Y) else (if Q then X else Y)` → 执行 X 的条件 `(P∧Q)∨(¬P∧Q) ⇔ Q`，直接化简为 `if Q then X else Y`。这正是逻辑化简在程序/电路里的价值。

## 1.4 联结词完备集

- **完备集**：任一真值函数都能只用该集合中的联结词表示
- **冗余联结词**：可被集合内其他联结词定义；**极小完备集**：无冗余

消元推导链（必会）：
```
{¬,∧,∨,→,↔}  --A↔B⇔(A→B)∧(B→A)-->  {¬,∧,∨,→}
             --A→B⇔¬A∨B---------->  {¬,∧,∨}
             --A∧B⇔¬(¬A∨¬B)------>  {¬,∨}   ← 极小
             --A∨B⇔¬(¬A∧¬B)------>  {¬,∧}   ← 极小
```
另有 **{¬,→} 也是完备集**：`A∧B ⇔ ¬(A→¬B)`

> 嵌入式视角：这就是数字电路里 **单个 NAND 门（或单个 NOR 门）可以搭出任意逻辑电路** 的数学依据。

## 1.5 范式

**动机**：真值表法耗时（2ⁿ 行），等值演算法耗脑（靠技巧）。范式 = 解方程前先把方程化成 `ax²+bx+c=0` 的标准形。

### 基础概念
- **文字**：命题变元或其否定
- **简单合取式/析取式**：有限个文字的 ∧ / ∨
- **析取范式** = 简单合取式的 ∨；**合取范式** = 简单析取式的 ∧
- 范式**不唯一**（所以才需要主范式）

### 求范式的三步法
1. 消冗余联结词：`A→B ⇔ ¬A∨B`，`A↔B ⇔ (¬A∨B)∧(¬B∨A)`
2. ¬ 内移：双重否定消掉、德·摩根展开
3. 分配律：求析取范式用 **∧ 对 ∨ 分配**（`p∨(q∧r) ⇔ (p∧r)∨(q∧r)` 注意方向），求合取范式用 ∨ 对 ∧ 分配

### 极小项 mᵢ 与极大项 Mᵢ（对照记，必背）

| | 极小项 mᵢ | 极大项 Mᵢ |
|---|---|---|
| 形式 | 简单**合取**式 | 简单**析取**式 |
| 编码 | 原形→1，否定→0 | **原形→0，否定→1**（相反！） |
| 该编码赋值是 | **成真**赋值 | **成假**赋值 |
| n 变元个数 | 2ⁿ 个 | 2ⁿ 个 |

n=3 时：m₀=¬p∧¬q∧¬r (000)，m₃=¬p∧q∧r (011)，m₆=p∧q∧¬r (110)；Mᵢ 与 mᵢ 下标对应同一编码但语义相反，M₀=p∨q∨r。

### 主析取范式
- **存在且唯一**（定理 1.3）。求法四步：转化→（缺变元的合取式用 `Aᵢ ⇔ Aᵢ∧(p∨¬p)` 补齐）展开→消去重复/矛盾项→按下标排序
- 简记：`m₂∨m₃∨m₅∨m₇ ⇔ ∑(2,3,5,7)`

**三大用途**：
1. **判等值**：A⇔B ⟺ 主析取范式相同。经典结论：`p→(q→r) ⇔ p∧q→r`，但与 `p→q→r` 不等值
2. **判类型**：含全部 2ⁿ 个极小项→重言式；0 个→矛盾式
3. **解应用题**：主析取范式的极小项下标 = **成真赋值 = 可行方案**（课件例：选派 A/B/C 出国，∑(1,2,5) 对应三种方案）

### 主析取 ↔ 主合取互换（镜像关系）
设 n 个变元，主析取范式含 s 个极小项：
- 成真赋值 s 个，成假赋值 **2ⁿ−s** 个
- 主合取范式的极大项下标 = 主析取范式的**补集**
- 例：A ⇔ ∑(0,3,6,7) ⟹ A ⇔ ∏(1,2,4,5)

## 1.6 命题逻辑的推理理论

- 推理形式结构：`(A₁∧A₂∧…∧Aₖ) → B`，为**重言式**则推理正确，记 `A₁∧…∧Aₖ ⇒ B`
- ⇒ 与 → 的区别同 ⇔ 与 ↔：⇒ 是关系符号，不是联结词
- **数理逻辑只管形式有效，不要求前提、结论为真命题**——p、q 全是假命题，推理照样可以正确
- 判定法四种：真值表 / 等值演算 / 主范式 / 构造证明（前三种判"是不是重言式"，第四种直接推）

### 8 条推理定律（全文背诵）
```
(1) 附加律          A ⇒ A∨B
(2) 化简律          A∧B ⇒ A
(3) 假言推理        (A→B)∧A ⇒ B          （Modus Ponens）
(4) 拒取式          (A→B)∧¬B ⇒ ¬A        （Modus Tollens）
(5) 析取三段论      (A∨B)∧¬B ⇒ A
(6) 假言三段论      (A→B)∧(B→C) ⇒ A→C
(7) 等价三段论      (A↔B)∧(B↔C) ⇒ A↔C
(8) 构造性二难      (A→B)∧(C→D)∧(A∨C) ⇒ B∨D
```
（16 条等值式每条还能派生 2 条推理定律）

### 构造证明：11 条推理规则
核心高频：**前提引入、结论引入、置换规则、假言推理、附加、化简、拒取式、假言三段论、析取三段论、构造性二难、合取引入**。
书写格式：每行 `编号 公式 （依据：用到第几行 + 规则名）`。

标准例（先符号化再证明）：
> 前提 `p→r, q→s, p∨q`，结论 `r∨s`：
> (1) p→r 前提引入 → (2) ¬r→¬p 假言易位 → (3) p∨q 蕴涵等值式得 ¬p→q → (4) 假言三段论 ¬r→s → (5) 蕴涵等值式得 r∨s ∎

### 两个进阶技巧
**附加前提证明法（CP 规则）**：结论是蕴涵式 `…→(A→B)` 时，把 A 提为新前提，只证 B：
`(A₁∧…∧Aₖ)→(A→B) ⇔ (A₁∧…∧Aₖ∧A)→B`

**归谬法（反证法）**：把 **¬B** 加入前提，若 `A₁∧…∧Aₖ∧¬B` 为矛盾式（不相容），则推理正确。收尾标志是推出 `s∧¬s` 这类矛盾式。

### 四种方法对比（课件小结）
| 方法 | 特点 |
|---|---|
| 真值表 | 无脑但 2ⁿ 行，组合爆炸 |
| 等值演算 | 每步靠熟记与技巧 |
| 主范式 | 步骤机械（补变元→消重→排序），但变元多时繁琐 |
| 构造证明 | 最简练，靠规则熟练度；公式非重言式时不易发现 |
