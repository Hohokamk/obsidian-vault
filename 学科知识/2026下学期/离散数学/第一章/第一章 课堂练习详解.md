## 练习 1（1.1 后）命题符号化并求真值

**(1) 如果今年湖人夺冠，那么说明詹姆斯牛，或者别的队太菜。**
- p：湖人夺冠；q：詹姆斯牛；r：别的队太菜
- 符号化：**p → (q ∨ r)**
- 真值：取决于实际。p 为假（湖人未夺冠）时按蕴涵定义为**真**；p 为真时看 q∨r。

**(2) 若 4 是质数，则 3 是偶数且 4 不是质数。**
- p：4 是质数（**假**）；q：3 是偶数（**假**）
- 注意「4 不是质数」就是 ¬p，别再引入新变元：符号化 **p → (q ∧ ¬p)**
- 真值：p = 0，**前件为假 ⟹ 整个蕴涵式为真（1）**。这正是蕴涵联结词的"善意推定"。

**(3) 下午如果没课，我们就去看电影，否则就不去。**
- p：下午有课；q：我们去看电影
- 「否则」= 前件不成立时的另一支，符号化为 **(¬p → q) ∧ (p → ¬q)**，等值于 **¬p ↔ q**
- 真值取决于当天实际情况（有课没去、没课去了 → 真；没课没去、有课去了 → 假）

## 练习 2（1.2 后）真值表 + 判断公式类型

**(1) p → q ↔ ¬p ∨ q**

按优先级即 `(p→q) ↔ (¬p∨q)`：

| p q | p→q | ¬p∨q | (p→q)↔(¬p∨q) |
|---|---|---|---|
| 0 0 | 1 | 1 | 1 |
| 0 1 | 1 | 1 | 1 |
| 1 0 | 0 | 0 | 1 |
| 1 1 | 1 | 1 | 1 |

**重言式**（全部赋值下为真）。它其实就是**蕴涵等值式 A→B ⇔ ¬A∨B** 本身——所以 ↔ 两侧真值永远相同。

**(2) ¬q → ¬p ∨ ¬q → ¬p**（左结合：`((¬q)→((¬p)∨(¬q)))→(¬p)`）

| p q r | ¬q→(¬p∨¬q) | 整体 |
|---|---|---|
| 0 0 0 | 1 | 1 |
| 0 0 1 | 1 | 1 |
| 0 1 0 | 1 | 1 |
| 0 1 1 | 1 | 1 |
| 1 0 0 | 1 | 0 |
| 1 0 1 | 1 | 0 |
| 1 1 0 | 1 | 0 |
| 1 1 1 | 1 | 0 |

**非重言式的可满足式**，成真赋值 000/001/010/011，**∑(0,1,2,3)**。

捷径（不用列表也能看穿）：
`¬q → (¬p∨¬q) ⇔ q ∨ ¬p ∨ ¬q ⇔ (q∨¬q) ∨ ¬p ⇔ 1`（排中律 + 零律）
于是原式 ⇔ `1 → ¬p ⇔ ¬p`，结果与 q、r 完全无关。

## 练习 3（1.3 后）等值演算证明

**证明：p∧q∧r ⇔ (¬(q→p) ∧ p) ∨ (p∧q∧r)**

从右端入手（先啃掉 ¬(q→p) 这块硬骨头）：
```
  (¬(q→p) ∧ p) ∨ (p∧q∧r)
⇔ (¬(¬q∨p) ∧ p) ∨ (p∧q∧r)          [蕴涵等值式]
⇔ ((q∧¬p) ∧ p) ∨ (p∧q∧r)           [德·摩根律 + 双重否定律]
⇔ (q ∧ (¬p∧p)) ∨ (p∧q∧r)           [结合律]
⇔ (q ∧ 0) ∨ (p∧q∧r)                [矛盾律]
⇔ 0 ∨ (p∧q∧r)                      [零律]
⇔ p∧q∧r                            [同一律]  ∎
```
**关键**：`¬(q→p) ∧ p` 是矛盾式（它断言"q 真且 p 假"同时又断言 p 真），所以整项可以被 0 吃掉。程序校验：左右两端 8 行真值完全一致 ✓

## 练习 4（1.4 后）化为各联结词完备集中的公式

原式 **¬(p∨q) ↔ r**。技巧：先统一消 ↔，再按目标集合消 ∧ 或 ∨。
`A↔B ⇔ (A→B)∧(B→A) ⇔ (¬A∨B)∧(¬B∨A)`，其中 A = ¬(p∨q)，B = r，¬A ⇔ p∨q。

**(1) {¬, ∨}**（保留 ¬ 和 ∨，用 `X∧Y ⇔ ¬(¬X∨¬Y)` 消 ∧）
```
  ¬(¬(p∨q∨r) ∨ ¬(¬r ∨ ¬(p∨q)))
```

**(2) {¬, ∧}**（用 `X∨Y ⇔ ¬(¬X∧¬Y)` 消 ∨）
```
  ¬(¬p ∧ ¬q ∧ ¬r) ∧ ¬(r ∧ ¬(¬p ∧ ¬q))
```
思路：X = p∨q∨r ⇔ ¬(¬p∧¬q∧¬r)；Y = ¬r∨¬(p∨q) ⇔ ¬(r ∧ (p∨q))，而 p∨q ⇔ ¬(¬p∧¬q)。

**(3) {¬, →}**（先 `p∨q ⇔ ¬p→q`，再用 `X∧Y ⇔ ¬(X→¬Y)`）
令 `A = ¬(¬p→q)`（即 ¬(p∨q)）：
```
  ¬((A → r) → ¬(r → A)),  其中 A = ¬(¬p→q)
```
三式均已程序验证与原式真值表完全一致 ✓

## 练习 5（1.5 前）求析取范式与合取范式

**(1) ((p∨q) → r) → p**
```
⇔ ¬(¬(p∨q) ∨ r) ∨ p            [蕴涵等值式]
⇔ ((p∨q) ∧ ¬r) ∨ p             [德·摩根律 + 双重否定]
⇔ (p∧¬r) ∨ (q∧¬r) ∨ p          [分配律]
⇔ p ∨ (q∧¬r)                   [吸收律：p 吃掉 p∧¬r]
```
- **析取范式**：`p ∨ (q ∧ ¬r)`
- **合取范式**：对上式用 ∨ 对 ∧ 分配 → `(p∨q) ∧ (p∨¬r)`

**(2) (q → p) → r**
```
⇔ ¬(¬q∨p) ∨ r ⇔ (q∧¬p) ∨ r     [蕴涵等值式 + 德·摩根 + 双重否定]
```
- **析取范式**：`(q ∧ ¬p) ∨ r`
- **合取范式**：`(q∨r) ∧ (¬p∨r)`

## 练习 6（1.5 中）求主析取范式

**(1) ((p∨q) → r) → p**
由练习 5(1) 的析取范式 `p ∨ (q∧¬r)` 补变元展开：
- `p ⇔ (p∧¬q∧¬r) ∨ (p∧¬q∧r) ∨ (p∧q∧¬r) ∨ (p∧q∧r)` = m₄∨m₅∨m₆∨m₇
- `q∧¬r ⇔ (¬p∧q∧¬r) ∨ (p∧q∧¬r)` = m₂∨m₆，去重后留 m₂、m₆

**主析取范式 ⇔ m₂ ∨ m₄ ∨ m₅ ∨ m₆ ∨ m₇ ⇔ ∑(2,4,5,6,7)**
（成真赋值 010、100、101、110、111；成假赋值 000、001、011）

**(2) (¬q ∨ p) → r**
注意 `¬q∨p ⇔ q→p`，所以这题与练习 5(2) 是**同一个公式**：
`(q∧¬p) ∨ r` 展开：
- `q∧¬p ⇔ (¬p∧q∧¬r) ∨ (¬p∧q∧r)` = m₂∨m₃
- `r ⇔ (¬p∧¬q∧r) ∨ (¬p∧q∧r) ∨ (p∧¬q∧r) ∨ (p∧q∧r)` = m₁∨m₃∨m₅∨m₇

**主析取范式 ⇔ m₁ ∨ m₂ ∨ m₃ ∨ m₅ ∨ m₇ ⇔ ∑(1,2,3,5,7)**

## 练习 7（1.5 后）求主合取范式

**(1) (r ∧ (p∨q)) → r**
不用算：前件 `r∧(p∨q)` 已经蕴含 r，所以这是**重言式**（8 行全 1，程序已验证）。
- **主合取范式 ⇔ 1**（不含任何极大项，∏() 为空）
- 对应主析取范式 = ∑(0,1,2,3,4,5,6,7)

**捷径**：`X∧Y → X` 恒为重言式（化简律的公式版），看到这种结构直接判重言式。

**(2) ¬r → p ∨ r → q**（按优先级左结合：`((¬r)→(p∨r))→q`）

先化成合取范式（注意 ¬r→X 里 ¬r 是**整个前件**，要整体用蕴涵等值式）：
```
  ((¬r) → (p∨r)) → q
⇔ (r ∨ p ∨ r) → q                 [蕴涵等值式：¬r→X ⇔ ¬(¬r)∨X ⇔ r∨X]
⇔ (p ∨ r) → q                     [幂等律、交换律]
⇔ ¬(p∨r) ∨ q                      [蕴涵等值式]
⇔ (¬p ∧ ¬r) ∨ q                   [德·摩根律]
⇔ (¬p∨q) ∧ (¬r∨q)                 [分配律]
```
再补缺失变元升为极大项：
- `¬p∨q ⇔ (¬p∨q∨r) ∧ (¬p∨q∨¬r)` = M₄ ∧ M₅
- `¬r∨q ⇔ (p∨q∨¬r) ∧ (¬p∨q∨¬r)` = M₁ ∧ M₅

合取去重：
```
⇔ M₁ ∧ M₄ ∧ M₅ ⇔ ∏(1,4,5)
```
**主合取范式 ⇔ M₁ ∧ M₄ ∧ M₅ ⇔ ∏(1,4,5)**（成假赋值 001、100、101）

> 歧义提示：若老师原意是 `¬(r→p) ∨ (r→q)`（即 ¬ 作用于整个括号），则结果为 ∏(5)。课上以板书/口述为准，方法完全相同。

## 练习 8、9（1.6）灭霸题：符号化 + 构造证明

**题目**：如果只有钢铁侠在地球、美国队长不在，那么就打不赢灭霸。结局一定是打赢灭霸或者宇宙一半生命变成灰。钢铁侠在地球。宇宙一半生命没有变成灰。因此美国队长在地球。

**符号化**
- p：钢铁侠在地球；q：美国队长在地球；r：打赢灭霸；s：宇宙一半生命变成灰
- 前提：`(p ∧ ¬q) → ¬r`、`r ∨ s`、`p`、`¬s`
- 结论：`q`
- **推理的形式结构**：`((p∧¬q)→¬r) ∧ (r∨s) ∧ p ∧ ¬s → q`

**构造证明**
```
(1) (p ∧ ¬q) → ¬r      前提引入
(2) r ∨ s              前提引入
(3) ¬s                 前提引入
(4) r                  (2)(3) 析取三段论
(5) ¬(p ∧ ¬q)          (1)(4) 拒取式
(6) ¬p ∨ q             (5) 德·摩根律
(7) p                  前提引入
(8) q                  (6)(7) 析取三段论   ∎
```
程序校验：4 个变元共 16 行赋值下，形式结构恒为真 → **推理正确，q 是有效结论** ✓
（第 5 步是题眼：已知打赢了 +「钢铁侠在且美队不在 ⟹ 打不赢」→ 反推「钢铁侠在且美队不在」为假；再配上「钢铁侠在」，只能推出美队在。）

## 练习 10（1.6 末）附加前提法 vs 直接证明

**前提**：p∨q、p→r、q→s　**结论**：¬s→r

### 法一：附加前提证明法（CP 规则）
结论是蕴涵式，把前件 ¬s 提为新前提，只需证 r：
```
(1) ¬s                 附加前提引入
(2) q → s              前提引入
(3) ¬q                 (1)(2) 拒取式
(4) p ∨ q              前提引入
(5) p                  (4)(3) 析取三段论
(6) p → r              前提引入
(7) r                  (5)(6) 假言推理   ∎
```

### 法二：不用附加前提（全程等值变形 + 三段论）
```
(1) p ∨ q              前提引入
(2) ¬p → q             (1) 蕴涵等值式
(3) q → s              前提引入
(4) ¬p → s             (2)(3) 假言三段论
(5) ¬s → p             (4) 假言易位
(6) p → r              前提引入
(7) ¬s → r             (5)(6) 假言三段论   ∎
```
程序校验：`(p∨q)∧(p→r)∧(q→s) → (¬s→r)` 在 16 行赋值下恒为真 ✓

## 方法选择小结（做作业时的决策树）

| 题型 | 首选方法 |
|---|---|
| 判断两公式是否等值 | 主析取范式相同 ⟺ 等值（最机械，不靠灵感） |
| 判断公式类型 | 主析取范式：全含 2ⁿ 项=重言式，0 项=矛盾式 |
| 求范式 / 主范式 | 三步法（消 →↔ → ¬ 内移 → 分配律），再补变元展开 |
| 判断推理是否正确 | 变元少 → 主范式；变元多 → 构造证明 |
| 证明推理（结论是蕴涵式） | 附加前提法（CP 规则）优先 |
| 证明推理（结论是原子命题） | 直接构造证明；卡住时上归谬法（加 ¬B 推出矛盾） |
