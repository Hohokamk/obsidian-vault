## 0. 一句话把两章串起来

命题逻辑把**一整句话**当成不可再分的原子，只关心句子之间的真假关系。所以在"凡人都会死 → 苏格拉底是人 → 苏格拉底会死"这种推理上，它**必然**失效：结论的正确性不来自句子与句子之间的真假搭配，而来自句子**内部**的结构。

一阶逻辑要做的只有一件事 —— **把原子砸开**，露出里面的个体词、谓词、量词，然后**重造一整套演算系统**。

这就是第二章存在的全部理由。下面所有内容都挂在这条因果链上：

```mermaid
flowchart LR
    A["命题逻辑<br/>把句子当原子"] --> B["原子之间的真假关系<br/>→ 联结词、真值表、范式、推理"]
    B --> C["天花板：句子内部结构被丢弃<br/>凡人都死/苏格拉底是人 ⇒ 推不出"]
    C --> D["一阶逻辑<br/>把命题拆成 个体词 + 谓词 + 量词"]
    D --> E["新问题：什么是公式？什么是真？怎么等值？怎么推理？"]
    E --> F["2.1 概念 → 2.2 公式与解释<br/>→ 2.3 等值与前束范式 → 2.4 推理理论"]
```

## 1. 第一章总收官

### 1.1 全章主线（一条链，不是六个抽屉）

第一章六节是**层层递进**的，每一节都在解决上一节留下的麻烦：

| 台阶 | 节 | 它解决的问题 | 留下的新麻烦 |
|---|---|---|---|

**记忆口诀（第一章全章）**：
> **分单位 → 建函数 → 学变形 → 数门槛 → 定标准 → 练证明**

### 1.2 每一节的必背清单

#### 1.1 命题与联结词
- 判断是不是命题的两步：**① 是不是陈述句？（疑问/祈使/感叹直接排除）② 有没有唯一真值？**（真值未知 ≠ 不唯一，"明年中秋是否晴天"是命题）
- ⚠️ 三个高频坑：
  - 「本命题是假的」→ **悖论，不是命题**
  - 「$x+y>10$」→ **命题变元**，不是命题
  - 「我和他是同学」→ **简单命题**（不能硬拆成两个）；「我和他**都是**学生」才是复合命题
- 五个联结词：$\neg p$（相反）、$p\land q$（全真才真）、$p\lor q$（有真就真）、$p\to q$（**仅当前真后假为假**）、$p\leftrightarrow q$（同真同假为真）
- 优先级：$\neg > \land > \lor > \to > \leftrightarrow$，同级从左往右
- 互斥或必须拆写：「老王或老李中一人出差」= $(t\land\neg u)\lor(\neg t\land u)$，不能只写 $t\lor u$

#### 1.2 命题公式与赋值
- 合式公式是**递归定义**：基础（单个变元）+ 归纳（联结词构造）+ 极小性（只有有限次构造出来的才算）
- **命题公式不是命题** —— 它没赋值，真值不确定
- 公式层次：单个变元是 0 层；$\neg B$ 比 $B$ 高一层；二元联结取 $\max(i,j)+1$
- 赋值写法：按下标序（$p_1p_2\dots$）或字典序（$p,q,r$），如 `011` = $p{=}0,q{=}1,r{=}1$
- 三分类：**重言式**（全 1）/ **矛盾式**（全 0）/ **可满足式**（不是矛盾式）。重言式 ⊂ 可满足式

#### 1.3 等值演算
- $A\Leftrightarrow B$ 的定义：$A\leftrightarrow B$ 是**重言式**。$\Leftrightarrow$ 是**公式间的关系符号，不是联结词**（对应地，$\Rightarrow$ 与 $\to$ 的关系同理）
- 等值式一共 **16 组、24 条**（课件标题写"16 条"，第二章课件说"1.3 节的 24 个等值式"，两个数都对：双重否定、排中、矛盾、蕴涵、等价、假言易位、等价否定、归谬论 8 组各 1 条，另外 8 组各 2 条，共 24 条）
- ★ 最高频：**蕴涵等值式 $A\to B\Leftrightarrow\neg A\lor B$**
- ⚠️ **分配律 $\lor$ 对 $\land$ 也成立**（$A\lor(B\land C)\Leftrightarrow(A\lor B)\land(A\lor C)$），这是与中学代数最大的不同
- **置换规则**：$F(A)$ 中的子公式 $A$ 可换成等值的 $B$ —— 这是等值演算能"一步一步推"的前提

#### 1.4 联结词完备集
```
{¬,∧,∨,→,↔} --A↔B⇔(A→B)∧(B→A)--> {¬,∧,∨,→}
              --A→B⇔¬A∨B---------> {¬,∧,∨}
              --A∧B⇔¬(¬A∨¬B)-----> {¬,∨}   ← 极小完备集
              --A∨B⇔¬(¬A∧¬B)-----> {¬,∧}   ← 极小完备集
```
- 另有 $\{\neg,\to\}$ 也是完备集：$A\land B\Leftrightarrow\neg(A\to\neg B)$
- 【补充，非课件内容】单个 **与非 ↑** 或单个 **或非 ↓** 也能构成完备集 —— 这就是数字电路里"单门搭出任意逻辑"的数学依据（课件 1.4 未证明）

#### 1.5 范式
- 三层概念：**文字** → **简单析取式 / 简单合取式** → **析取范式 / 合取范式**
- 求范式的三步：消 $\to,\leftrightarrow$ → $\neg$ 内移 → 分配律展开。**范式不唯一**
- 极小项 $m_i$ / 极大项 $M_i$ 对照表（必背）：

| | 极小项 $m_i$ | 极大项 $M_i$ |
|---|---|---|
| 形式 | 简单**合取**式 | 简单**析取**式 |
| 编码 | 原形 → 1，否定 → 0 | **原形 → 0，否定 → 1**（相反！） |
| 该编码赋值是 | **成真**赋值 | **成假**赋值 |
| 个数 | $2^n$ | $2^n$ |

- **主析取范式存在且唯一**（定理 1.3），简记 $\sum(i_1,i_2,\dots)$
- 三大用途：① 判等值（等值 ⟺ 主析取范式相同）② 判类型（全 $2^n$ 个极小项⟹重言式；0 个⟹矛盾式）③ **解应用题**（极小项下标 = 成真赋值 = 可行方案）
- 主析取 ↔ 主合取：下标互为**补集**。$A\Leftrightarrow\sum(0,3,6,7)\Longrightarrow A\Leftrightarrow\prod(1,2,4,5)$

#### 1.6 推理理论
- 形式结构 $(A_1\land A_2\land\dots\land A_k)\to B$ 是**重言式** ⟺ 推理正确，记 $A_1\land\dots\land A_k\Rightarrow B$
- **数理逻辑只管形式有效，不要求前提和结论是真命题**（前提全假，推理照样可以正确）
- 8 条推理定律：附加、化简、假言推理、拒取式、析取三段论、假言三段论、等价三段论、构造性二难
- 11 条推理规则，四个判定/证明方法（真值表 / 等值演算 / 主范式 / 构造证明）
- 两个进阶技巧：**附加前提证明法**（结论是蕴涵式时把前件提为新前提）、**归谬法**（把 $\neg B$ 加入前提，推出矛盾）

## 2. 第一章的天花板在哪 —— 这是第二章的开场白

课件第二章开篇就摆了一个反例，必须能复述：

> **苏格拉底三段论**
> $P$：凡人都是要死的。$Q$：苏格拉底是人。$R$：苏格拉底是要死的。
> 推理写作 $P\land Q\to R$。

如果只用命题逻辑，$P,Q,R$ 是三个**互相独立的原子**，那么：

$$P\land Q\to R$$

**不是重言式**（取 $P{=}1,Q{=}1,R{=}0$ 即假）。也就是说，命题逻辑**判不出这个推理是对的**。

再一个例子：$P$「熊猫是动物」、$Q$「长颈鹿是动物」，它们明明是同一类结构，命题逻辑却只能记成两个毫不相干的字母，**"共性"整个丢失了**。

### 结论（三条，必须记牢）

| 命题逻辑丢掉了什么 | 后果 |
|---|---|
| 简单命题**内部**的成分与结构 | 无法揭示前提与结论在**形式结构**上的联系 |
| 命题之间的**共同特性** | 同样的推理模式无法复用 |
| 由此导致 | 命题逻辑**适用面狭窄**；且在 $n$ 大时真值表爆炸 |

> 修复方案：把简单命题进一步拆成 **个体词 + 谓词 + 量词**，研究它们之间的关系，重新总结推理形式和规则 —— 这就是**一阶逻辑**（又称谓词逻辑 / 一阶谓词逻辑）。

### 3.2 2.1 一阶逻辑的基本概念（最重要的一节）

**① 个体词与谓词 —— 简单命题被拆成主语和谓语两部分**

- **个体词**：可以独立存在的客体（具体事物或抽象概念）。$2$、你、易烊千玺、计算机、熊猫、自然数、定理、爱情都能当个体词
- **个体常项** $a,b,c$：具体的、特指的（地球、科比）
- **个体变项** $x,y,z$：抽象的、泛指的、在一定范围内变化的
- **个体域（论域）**：个体变项的取值范围，可以有限也可以无限
- ⚠️ **全总个体域**：包含宇宙全体事物的个体域。**若无特别声明，个体域均指全总个体域**
- **谓词**：刻画个体词的性质及个体词之间关系的词（"…是素数"、"…比…帅"）
- **谓词常项**（有具体含义）/ **谓词变项**（含义未指定）
- **元数**：谓词包含个体的数目。1 元谓词描述**性质**，$m(\ge2)$ 元谓词刻画**关系**
- 关键判断：$P(a)$ **是命题**；$P(x)$ **不是命题**，是命题变元。$n$ 元谓词要变成命题，**至少要加 $n$ 个量词**
- **0 元谓词**：不带个体变项的谓词 → 命题逻辑里的命题常项/变项都是 0 元谓词。**命题是谓词的特殊情况**

**② 量词**

- **全称量词 $\forall$**：对应"所有 / 任意 / 一切 / 每一个"，$x$ 称全称性变项（$\forall$ 是 All 的 A 倒过来）
- **存在量词 $\exists$**：对应"存在着 / 有一个 / 有些 / 至少存在一个"，$\exists$ 是 Exist 的 E 反过来
- 量词是**对个体词附加约束**的词；**只有个体变项才能冠量词**（可以说"所有人…"，不能说"所有科比…"）

**③ ★★★ 特性谓词与"固定搭配"（全章最容易被扣分的点）**

以"所有的活人都呼吸"、"有的人吸烟"为例。个体域取**活人类集合**时可以直接写 $\forall xF(x)$、$\exists xG(x)$；一旦个体域改成**全总个体域**，就必须把"人"从中分离出来，引入**特性谓词** $M(x)$：$x$ 是活人。

$$\text{(1) 所有的活人都呼吸} \quad\Longrightarrow\quad \forall x\bigl(M(x)\to F(x)\bigr)$$
$$\text{(2) 有的人吸烟} \quad\Longrightarrow\quad \exists x\bigl(M(x)\land G(x)\bigr)$$

> 🔑 **固定搭配**：**全称量词后的特性谓词作蕴涵式的前件；存在量词后的特性谓词作合取式的一项。**

⚠️ **写反了会怎样（必须能说出理由）**：
- 写成 $\forall x(M(x)\land F(x))$ → 含义变成"宇宙间一切事物都是活人**且**都要呼吸"，把各种个体不加区分地混为一体
- 写成 $\exists x(M(x)\to F(x))$ → 含义变成"存在某个东西，如果它是活人则它会抽烟"。**当所有活人都不抽烟时这个命题也为真**，因为宇宙间总有不是人的东西让 $M(x)$ 为假 —— 这已经不是原命题了

补充结论：**只有当个体变项是个体域的真子集时，才需要引入特性谓词**。个体域为"黄种活人集合"时不需要。

**④ 量词必须注意的 5 点（课件原文）**

1. 在不同个体域中，符号化形式可能不同，真值也可能改变
2. 个体域未声明 → 一律用全总个体域
3. ⚠️ **多个量词同时出现时不能随意颠倒顺序**
4. 引入特性谓词后：全称后配蕴涵，存在后配合取（固定搭配）
5. $n$ 元谓词不是命题；个体域和谓词含义确定后，要变成命题**至少需要 $n$ 个量词**

量词顺序的经典例（个体域 = 实数集）：
- $\forall x\exists y(x+y=5)$ —— **真命题**（对每个 $x$ 都能找到对应的 $y$）
- $\exists y\forall x(x+y=5)$ —— **假命题**（要一个 $y$ 对所有 $x$ 都成立）

**⑤ 一个必须知道的坏消息**

> 命题逻辑里判断重言式有通用办法（真值表）；**一阶逻辑里没有一般的能行算法**。
> **1936 年 Turing 证明**：当个体域是无限集时，一阶逻辑中判定公式的重言性和矛盾性**是不可解的**。
> 困难来自：个体域无限 + 谓词设定的任意性。但**不排除**某些子类（如命题逻辑）是可判定的。

### 3.3 2.2 一阶逻辑公式及解释

**① 字母表（7 类）**：个体常项 / 个体变项 / 函数符号 / 谓词符号 / 量词符号 $\forall\exists$ / 联结词 $\neg\land\lor\to\leftrightarrow$ / 括号与逗号

**② 项（定义 2.1，递归）**
1. 个体常项和变项是项
2. 若 $f(x_1,\dots,x_n)$ 是任意 $n$ 元函数，$t_1,\dots,t_n$ 是任意 $n$ 个项，则 $f(t_1,\dots,t_n)$ 是项
3. 只有有限次应用 (1)(2) 形成的符号串才是项

> 直观理解：**项 = 广义的个体**（个体本身 + 个体通过函数衍生出的东西）

**③ 原子公式与合式公式**
- **原子公式**：$P(t_1,\dots,t_n)$，其中 $P$ 是 $n$ 元谓词、$t_i$ 是项
- **合式公式（谓词公式）**递归定义：原子公式是 → $(\neg A)$ 是 → $(A\lor B),(A\land B),(A\to B),(A\leftrightarrow B)$ 是 → $\forall xA$、$\exists xA$ 是 → 只有有限次构造出来的才是
- **谓词公式与命题公式的唯一区别就是量词**

**④ 辖域、指导变项、约束/自由出现（定义 2.2）**
- 在 $\forall xA(x)$、$\exists xA(x)$ 中：$x$ 是**指导变项**，$A$ 是量词的**辖域**
- 辖域中 $x$ 的所有出现叫**约束出现**，其余变项的出现叫**自由出现**
- 判辖域口径：**量词后有括号 → 括号内就是辖域；量词后无括号 → 量词后最短的公式是辖域**
- 多个量词连续出现（如 $\forall x\forall y$）时，后面的量词在**前面量词的辖域之中**

**⑤ 闭式**：无自由变项的公式。$\forall x\forall y(P(x)\land Q(y)\to R(x,y))$ 是闭式；$P(x)\to\forall y(Q(y)\to R(x,y))$ 不是（$x$ 自由）

- ⚠️ 有 $n$ 个量词 **不代表** 一定是闭式（$\forall x(P(x,y)\to\exists yQ(x,y)\land\forall zR(x,y,z))$ 有 3 个量词，但 $y$ 仍自由出现一次）
- ⚠️ 要让含 $n$ 个自由变项的公式变成闭式，**至少**要加 $n$ 个量词

**⑥ 解释（定义 2.3）—— 这是"真值"的来源**
谓词公式 $A$ 的一个解释 $I$ 由 4 部分组成：
- (a) 给定个体域 $D_I$
- (b) 对每个个体常项赋给 $D_I$ 中的一个元素
- (c) 对每个函数符号指定 $D_I$ 上的一个具体函数
- (d) 对每个谓词符号指定 $D_I$ 上的一个具体谓词

> **解释不包含个体变项**，因为个体变项可以通过量词限制。
> **闭式在任何解释下都成为命题**；不是闭式的公式在某个解释下可能成为命题，也可能仍然不是命题（因为有自由变项）。

**⑦ 赋值**：给定解释 $I$，对公式中每个自由变项 $x$ 指定 $D_I$ 中的一个值 $\sigma(x)$。
> **任何谓词公式在解释 + 赋值下的结果都是命题。**
> **闭式与赋值无关。**

**⑧ 公式三分类（定义 2.4）**：在任何解释下都为真 → **重言式**；任何解释下都假 → **矛盾式**；至少存在一种解释使之为真 → **可满足式**
- 重言式一定是可满足式，反之不然
- ⚠️ 到目前为止**没有可行的算法**判断谓词公式是否可满足

**⑨ 代换实例（定义 2.5）**：命题公式 $A_0$ 中的命题变项全换成谓词公式，得到的就是 $A_0$ 的**代换实例**
> **重言式的代换实例均为重言式，矛盾式的代换实例均为矛盾式。** —— 这是第二章里最省力的一条判定捷径（例 2.9 就是靠 $\forall xP(x)\to\forall x\exists yQ(y)\to\forall xP(x)$ 是 $P\to(Q\to P)$ 的代换实例，直接判为重言式）

### 3.4 2.3 一阶逻辑等值式与前束范式

**① 等值式（定义 2.6）**：$A\leftrightarrow B$ 是重言式 ⟹ $A\Leftrightarrow B$
> ⚠️ 由于重言式的代换实例都是重言式，**第一章 1.3 节的 24 条等值式，它们的代换实例全部合法地成为一阶逻辑的等值式**。（如由 $p\lor\neg p$ 得 $\forall xP(x)\lor\neg\forall xP(x)$）

**② 换名规则**：把量词辖域中某约束变项的所有出现**及相应的指导变项**换成该辖域中**未曾出现过**的个体变项符号，其余部分不变
- 目的：避免同一个变项在同一个公式中**既约束又自由**
- 类比：就像 $\sum_{i=1}^{n}a_i$ 里把 $i$ 换成 $j$，公式含义不变
- ⚠️ 四类典型错误：辖域内约束变项漏改 / 不该改的自由变项改了 / 换成辖域里已存在的符号 / 辖域外的自由变项也一起改了
- （教材另有"代替规则"处理自由变项的替换，本次课件未展开）

**③ 有限个体域中消去量词**（$D=\{a_1,\dots,a_n\}$）
$$\forall xA(x)\Leftrightarrow A(a_1)\land A(a_2)\land\dots\land A(a_n) \qquad \exists xA(x)\Leftrightarrow A(a_1)\lor A(a_2)\lor\dots\lor A(a_n)$$
> 直观：**全称量词是合取的推广，存在量词是析取的推广**。这也是"量词否定等值式 = 德摩根律"的原因。

**④ 量词否定等值式（超常用）**
$$\neg\forall xA(x)\Leftrightarrow\exists x\neg A(x) \qquad \neg\exists xA(x)\Leftrightarrow\forall x\neg A(x)$$
> 本质就是德摩根律（在有限个体域上可直接证明）

**⑤ ★ 量词辖域收缩与扩张等值式（8 条，$B$ 中不含约束变项 $x$）**

| # | 等值式 | 口诀/本质 |
|---|---|---|
| (1) | $\forall x(A(x)\lor B)\Leftrightarrow\forall xA(x)\lor B$ | $\lor$ 可交换，本质分配律 |
| (2) | $\forall x(A(x)\land B)\Leftrightarrow\forall xA(x)\land B$ | $\land$ 可交换，本质幂等律 |
| (3) | $\forall x(A(x)\to B)\Leftrightarrow\exists xA(x)\to B$ | **$\forall$ 变 $\exists$！** |
| (4) | $\forall x(B\to A(x))\Leftrightarrow B\to\forall xA(x)$ | 量词不动 |
| (5) | $\exists x(A(x)\lor B)\Leftrightarrow\exists xA(x)\lor B$ | $\lor$ 可交换，本质幂等律 |
| (6) | $\exists x(A(x)\land B)\Leftrightarrow\exists xA(x)\land B$ | $\land$ 可交换，本质分配律 |
| (7) | $\exists x(A(x)\to B)\Leftrightarrow\forall xA(x)\to B$ | **$\exists$ 变 $\forall$！** |
| (8) | $\exists x(B\to A(x))\Leftrightarrow B\to\exists xA(x)$ | 量词不动 |

> 🔑 课件批注：**只要 $A(x)$ 前面没有 $\neg$，$\forall$ 和 $\exists$ 就不用换**。只有 $A(x)$ 出现在蕴涵式**前件**位置时（(3)(7)），量词才互换。

**⑥ 量词分配等值式**
$$\forall x\bigl(A(x)\land B(x)\bigr)\Leftrightarrow\forall xA(x)\land\forall xB(x) \qquad \exists x\bigl(A(x)\lor B(x)\bigr)\Leftrightarrow\exists xA(x)\lor\exists xB(x)$$
> $\forall$ 对 $\land$、$\exists$ 对 $\lor$ 有分配律，本质是结合律。

⚠️ **但 $\forall$ 对 $\lor$、$\exists$ 对 $\land$ 无分配律**：
$$\forall x(A(x)\lor B(x))\;\not\Leftrightarrow\;\forall xA(x)\lor\forall xB(x) \qquad \exists x(A(x)\land B(x))\;\not\Leftrightarrow\;\exists xA(x)\land\exists xB(x)$$
- 反正例（个体域 = 自然数，$A(x)$：$x$ 是奇数，$B(x)$：$x$ 是偶数）：$\forall x(A\lor B)$ 真（不是奇就是偶），$\forall xA\lor\forall xB$ 假
- 此时**无法收缩辖域，但可以扩张**（用换名规则）

**⑦ 前束范式（定义 2.11）**：形如
$$Q_1x_1Q_2x_2\dots Q_kx_kB$$
其中 $Q_i$ 是 $\forall$ 或 $\exists$，$B$ **不含量词**。即**所有量词都在公式最前面，辖域一直延伸到公式末尾**。

- **定理**：任一谓词公式都可化为与之等值的前束范式。构造性算法四步：
  1. 消去 $\to$、$\leftrightarrow$
  2. $\neg$ 向内深入，只作用于原子公式
  3. **换名**：使所有约束变项符号互不相同，且自由变项与约束变项符号也不同
  4. 用量词辖域扩张/收缩或量词分配等值式，按量词在公式中出现的顺序把它们移到最前
- ⚠️ 前束范式**不唯一**（量词左移次序无机械规定，尾部也无进一步要求）
- ⚠️ **重要限制**：量词顺序可交换**仅适用于一元谓词**。当辖域中存在二元谓词且其变项都被约束时，**不能改变量词顺序**（如 $\forall x\exists y(A(x,y)\land B(y))$）
- 术语：前面那串量词叫**首标**，后面不含量词的部分叫**尾部**
- 课件原话（很实在）：**"前束范式只是好看，没啥用"** —— 它不像命题逻辑的范式那样能解决判定问题，只是让形式整齐规范

### 3.5 2.4 一阶逻辑推理理论

**① 推理形式结构**：$A_1\land A_2\land\dots\land A_k\to B$ 是**永真式** ⟹ 推理正确，$B$ 是逻辑结论
> ⚠️ 判断是否为永真式，比命题逻辑**困难得多** —— 所以本节重点是**构造证明的方法**

**② 推理定律的三个来源**
1. **命题逻辑中重言蕴涵式的代换实例**（如 $\forall xF(x)\land\exists yG(y)\Rightarrow\forall xF(x)$）
2. **每个基本等值式生成 2 条推理定律**（左⇒右、右⇒左）
3. **4 条量词分配蕴涵律**（下）

**③ ★ 量词分配蕴涵律（4 条，注意与"量词分配等值式"区分）**
$$\forall xA(x)\lor\forall xB(x)\Rightarrow\forall x\bigl(A(x)\lor B(x)\bigr)$$
$$\exists x\bigl(A(x)\land B(x)\bigr)\Rightarrow\exists xA(x)\land\exists xB(x)$$
$$\forall x\bigl(A(x)\to B(x)\bigr)\Rightarrow\forall xA(x)\to\forall xB(x)$$
$$\forall x\bigl(A(x)\to B(x)\bigr)\Rightarrow\exists xA(x)\to\exists xB(x)$$
> 前两条正是"无分配律"那两条的**单向版本**（反向不成立）。

**④ ★★★ 四条量词推理规则（本节核心，也是全章最难的地方）**

课件强调：这 4 条规则里的 $A\Rightarrow B$ **不一定**表示 $A\to B$ 是重言式，只表示"在一定条件下，$A$ 为真时 $B$ 也为真"。**所以条件必须严格遵守，否则会把错误的推理也变成"正确"的。**

| 规则 | 形式 | 成立条件 |
|---|---|---|
| **UI** 全称量词消去<br/>Universal Instantiation | $\forall xA(x)\Rightarrow A(y)$<br/>$\forall xA(x)\Rightarrow A(c)$ | (1) $x$ 是 $A(x)$ 中**自由出现**的个体变项<br/>(2) 第 1 式中 $y$ 为任意的、**不在 $A(x)$ 中约束出现**的个体变项<br/>(3) 第 2 式中 $c$ 为**任意的个体常项** |
| **UG** 全称量词引入<br/>Universal Generalization | $A(y)\Rightarrow\forall xA(x)$ | (1) $y$ 在 $A(y)$ 中自由出现，且 $y$ 取任何值时 $A$ 均为真<br/>(2) 取代 $y$ 的 $x$ **不能在 $A(y)$ 中约束出现** |
| **EG** 存在量词引入<br/>Existential Generalization | $A(c)\Rightarrow\exists xA(x)$ | (1) $c$ 为**特定的**个体常项（不要求 $A(c)$ 为真）<br/>(2) 取代 $c$ 的 $x$ **不能在 $A(c)$ 中出现** |
| **EI** 存在量词消去<br/>Existential Instantiation | $\exists xA(x)\Rightarrow A(c)$ | (1) $c$ 是**使 $A$ 为真的特定的**个体常项<br/>(2) $c$ **不在 $A(x)$ 中出现**<br/>(3) **若 $A(x)$ 中除 $x$ 外还有其它自由变项，不能用此规则** |

**记忆口诀（课件原话）**：
> 这 4 条可形象地称为**"脱帽"与"戴帽"**规则 ——
> **对全称量词：脱帽（UI）容易、戴帽（UG）难；**
> **对存在量词：戴帽（EG）容易、脱帽（EI）难。**

**⑤ 三个必考的"踩坑"反例（能复述就稳了）**

1. **UI 用错**：个体域 = 实数集，$\forall x\exists y(x<y)$ 是真命题。若用 $y$ 取代 $x$ 得 $\exists y(y<y)$ —— 假命题。原因是 $y$ 在 $\exists y(\cdot)$ 中**约束出现**，违背条件 (2)
2. **EI 用错（最阴险的）**：个体域 = 自然数集，$\exists xP(x)\land\exists xQ(x)$ 真（存在奇数、也存在偶数），但 $\exists x(P(x)\land Q(x))$ 假。错误推导中把 (2) 得到的 $c$（某奇数）拿去使 $Q(c)$ 为真 —— 违背 EI 条件 (1)。**$c$ 必须是"使 $A$ 为真的特定的"常项**
3. **EI 条件 (3) 用错**：个体域 = 实数集，$\forall x\exists y(x<y)$ 真，但如果先 UI 得到 $\exists y(c<y)$（$c$ 是自由变项），再对它用 EI → 违背条件 (3)；再 UG 就得到假的 $\forall x(x<c)$

**⑥ ★ 顺序陷阱（必须记住）**
> **EI 规则中得到的常项，一定满足 UI 规则的条件；反之不真。所以一定要先 EI、后 UI。**

- 正确：(1) $\exists xP(x)$ 前提引入 → (2) $P(c)$ (1) EI → (3) $\forall x(P(x)\to Q(x))$ 前提引入 → (4) $P(c)\to Q(c)$ (3) UI → (5) $Q(c)$ 假言推理 → (6) $\exists xQ(x)$ EG
- 错误：先 UI 得到 $P(c)\to Q(c)$，再 EI 得到 $P(c)$ —— (4) 的 $c$ 不一定满足 (2) 的 $c$

**⑦ 三种证明方法（第一章的三种技巧原样搬过来）**
- **构造证明法**（直接）
- **附加前提证明法**：结论是蕴涵式时，把前件提为新前提
- **归谬法**：把 $\neg B$ 加入前提，推出矛盾式（不相容）

**⑧ 收官例题：苏格拉底三段论**
> 前提：$\forall x(M(x)\to D(x))$，$M(s)$；结论：$D(s)$

| 步骤 | 公式 | 依据 |
|---|---|---|
| (1) | $\forall x(M(x)\to D(x))$ | 前提引入 |
| (2) | $M(s)\to D(s)$ | (1) UI |
| (3) | $M(s)$ | 前提引入 |
| (4) | $D(s)$ | (2)(3) 假言推理 |

> 第一章判不出的推理，第二章用 **一个 UI + 一次假言推理**就证完了 —— 这就是"把原子砸开"的全部回报。

## 7. 关键坑点速查（考前只看这一节）

| ⚠️ 坑 | 正确做法 |
|---|---|
| 特性谓词写反 | **全称配蕴涵 $\forall(M\to F)$，存在配合取 $\exists(M\land G)$** |
| 以为量词能随意换序 | $\forall x\exists y$ 与 $\exists y\forall x$ **一般不等值** |
| 把 $\forall x(A\lor B)$ 拆成 $\forall xA\lor\forall xB$ | 这是**无分配律**的，只能单向蕴涵 |
| $\forall x(A\to B)$ 想把量词收缩出去 | (3) 式要**把 $\forall$ 换成 $\exists$** |
| 前束范式以为唯一 | **不唯一**；量词顺序可换仅限**一元谓词** |
| 闭式 = 量词数 = 自由变项数 | **不成立**，量词数够也可能仍有自由变项 |
| UI/UG/EG/EI 随便用 | 4 条规则**都有条件**，用之前先核条件 |
| 先 UI 后 EI | **必须先用 EI、后用 UI** |
| 换名时只改一半 | 辖域内**所有**出现和**指导变项**都要同时改，且不能换成辖域内已有的符号 |
| 以为一阶逻辑能判重言式 | **Turing 1936**：个体域无限时判定问题**不可解** |
