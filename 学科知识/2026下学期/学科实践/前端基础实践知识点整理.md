# 前端基础实践知识点整理

## 总体关系

```text
HTML：页面有什么（结构）
CSS：页面长什么样（表现）
JavaScript：页面如何响应和变化（行为）
DOM：JavaScript 操作 HTML 的桥梁
开发者工具：观察页面结构、样式、错误和数据变化
```

这批示例覆盖了一条完整基础链路：

1. 用 HTML 搭建注册、登录和省市联动页面。
2. 用 CSS 完成表单、卡片、浮动布局和响应式页面。
3. 用 JavaScript 获取和修改 DOM，处理表单、按钮及下拉框事件。
4. 用浏览器开发者工具查看 DOM、控制台日志、错误和网络请求。

## 一、HTML 文档结构与语义

### 1. 基本文档骨架

- `<!DOCTYPE html>`：声明使用 HTML5 文档类型。
- `<html lang="zh-CN">`：根元素，`lang` 表示页面主要语言。
- `<head>`：保存页面元数据和资源引用，不直接显示在页面正文中。
- `<body>`：保存用户在页面中看到和操作的内容。
- `<meta charset="UTF-8">`：设置字符编码，避免中文乱码。
- `<title>`：浏览器标签页标题，也是搜索结果中的页面标题。

### 2. 常用结构元素

- `header`：页头或内容区头部。
- `article`：相对独立的内容区域。
- `footer`：页脚。
- `div`：通用块级容器，主要用于布局和分组。
- `h1`：一级标题，通常表示页面主题。
- `p`：段落。
- `ul`、`li`：无序列表和列表项。

### 3. 文本、图片和链接

- `img` 使用 `src` 指定图片地址，使用 `alt` 可提供替代文本。
- `a` 使用 `href` 指定链接目标。
- `target="_blank"` 表示在新标签页打开链接。
- 相对路径会相对于当前文档地址或 `<base>` 指定的地址解析。

## 二、`head` 中的六类核心元素

| 元素 | 作用 | 关键属性或注意点 |
| --- | --- | --- |
| `title` | 定义标签页及搜索结果标题 | 每个文档应有一个明确的标题 |
| `base` | 为相对 URL 指定基础地址和默认打开方式 | `href`、`target`；通常只使用一个 |
| `link` | 引用 CSS、favicon、字体、预加载资源 | `rel`、`href`、`type`、`media` |
| `meta` | 描述文档元数据 | `charset`、`viewport`、`name`、`content`、`http-equiv` |
| `style` | 定义当前文档的内部 CSS | `media` 可按设备或媒介应用样式 |
| `script` | 引入或嵌入 JavaScript | `src`、`async`、`defer`、`type` |

### 1. `meta` 的常见用途

- `charset`：字符编码。
- `viewport`：移动端视口与缩放控制。
- `description`：页面描述，影响搜索结果摘要。
- `keywords`：页面关键词，现代搜索引擎权重较低。
- `author`：作者信息。
- `http-equiv="refresh"`：定时刷新或跳转。
- `http-equiv="X-UA-Compatible"`：兼容旧版 IE 的渲染模式。
- `og:*`：规定社交媒体分享时展示的标题、描述、图片和链接。

### 2. `link` 的常见用途

- `rel="stylesheet"`：加载外部 CSS。
- `rel="icon"`：设置网站图标。
- `rel="preload"`：提前加载字体、图片等关键资源。
- `media="print"`：只让样式在打印时生效。
- `crossorigin`：控制跨域资源请求。

### 3. `script` 的加载与执行

| 写法 | 加载行为 | 执行时机 | 是否保持顺序 |
| --- | --- | --- | --- |
| 普通 `script` | 阻塞后续解析 | 下载后立即执行 | 是 |
| `async` | 异步下载 | 下载完成后立即执行，可能打断解析 | 否 |
| `defer` | 异步下载 | HTML 解析完成后执行 | 是 |
| `type="module"` | 模块加载 | 默认具有延迟执行特点 | 是 |

因此，需要操作 DOM 的普通脚本通常放在 `body` 末尾，或使用 `defer`。

## 三、HTML 表单

### 1. 表单容器

```html
<form action="#" method="post">
```

- `action`：提交地址。
- `method`：请求方法，常见值为 `get` 和 `post`。
- `name`：控件的提交字段名，最终作为键值对发送。
- `id`：页面内唯一标识，用于 CSS、JavaScript 和 `label` 关联。

### 2. 常用表单控件

- `input type="text"`：单行文本。
- `input type="email"`：电子邮件，浏览器可检查格式。
- `input type="password"`：密码输入，内容被遮盖。
- `input type="file"`：文件上传。
- `input type="checkbox"`：复选框。
- `input type="submit"`：提交按钮。
- `select`、`option`：下拉列表。
- `textarea`：多行文本。
- `button type="submit"`：表单提交按钮。

### 3. 常用表单属性

- `placeholder`：输入提示，不代替 `label`。
- `required`：必填。
- `minlength`、`maxlength`：最小和最大字符数。
- `accept="image/*"`：限制可上传文件的类型。
- `for="控件id"`：让点击标签文字时也能聚焦对应控件。
- `value`：控件当前值或选项提交值。

### 4. 表单验证的两层含义

- HTML 属性验证：如 `required`、`type="email"`、`minlength`，由浏览器参与提交约束。
- JavaScript 实时验证：监听 `input` 事件并显示错误信息。
- JavaScript 提交验证：监听 `submit` 事件，比较密码等复杂条件。
- `event.preventDefault()`：阻止浏览器默认提交行为，适合前端演示。
- 前端验证只能改善体验，不能替代服务器端验证。

## 四、CSS 核心知识点

### 1. CSS 的三种使用位置

- 外部样式表：`<link rel="stylesheet" href="login.css">`，适合页面级复用。
- 内部样式：`<style>`，适合单页面或示例。
- 行内样式：元素的 `style` 属性，优先级直观但不利于复用。

### 2. 选择器

- 元素选择器：`body`、`input`。
- 类选择器：`.form-group`。
- ID 选择器：`#form_div`。
- 后代选择器：`header img`。
- 子元素选择器：`header > h1`。
- 分组选择器：`p > a, #auto_div > a`。
- 属性选择器：`input[type="submit"]`。
- 伪类：`:hover`、`:focus`、`:active`。
- 伪元素：`::after`。

### 3. 盒模型

- `margin`：外边距。
- `border`：边框。
- `padding`：内边距。
- `width`、`height`：内容区域或整体盒尺寸。
- `box-sizing: border-box`：让宽度包含内边距和边框，便于计算。
- 通用重置：

```css
* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}
```

### 4. 页面布局

- 固定宽度居中：`width: 1000px; margin: 0 auto;`。
- 浮动布局：`float: left/right`。
- 浮动影响：父元素可能无法正确计算高度，示例中使用 `overflow: hidden` 处理。
- 传统横向分栏：给多个子元素设置固定宽度并浮动。
- Flex 布局：使用 `display: flex`、`justify-content`、`align-items` 完成居中和对齐。
- Grid 布局：使用 `display: grid`、`gap`、`grid-template-columns` 构建自适应卡片。
- 自适应列：

```css
grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));
```

- `display: none`：元素不显示且不占据布局空间。
- `position: relative`：作为绝对定位后代的参照。
- `position: absolute`：相对于最近的已定位祖先进行定位。

### 5. 常见视觉样式

- 字体：`font-family`、`font-size`、`font-weight`、`line-height`。
- 文本：`color`、`text-align`、`text-decoration`。
- 背景：`background-color`、`background-image`、`linear-gradient`。
- 边框：`border`、`border-radius`。
- 阴影：`box-shadow`。
- 透明颜色：`rgba()`。
- 过渡：`transition`。
- 变换：`transform: translateY()`、`scale()`。
- 鼠标状态：`cursor`。

### 6. CSS 变量

```css
:root {
    --primary-color: #4a6bdf;
}

button {
    background: var(--primary-color);
}
```

- `--变量名`：定义自定义属性。
- `var(--变量名)`：读取变量。
- 好处是主题色和公共值可以集中修改。

### 7. 响应式设计

```css
@media (max-width: 600px) {
    .form-container {
        padding: 20px;
    }
}
```

- 媒体查询可根据屏幕宽度应用不同样式。
- 页面需要同时考虑固定桌面布局和移动端窄屏布局。
- `container`、`max-width` 和百分比宽度可减少内容溢出。

## 五、JavaScript 基础

### 1. 数据与变量

- `var`：函数作用域，较旧写法。
- `let`：块级作用域，可重新赋值。
- `const`：块级作用域，不能重新绑定。
- 字符串、数字、布尔值：基础数据类型。
- 数组：保存一组有序数据。
- 二维数组：数组中的每个元素仍是数组，可用于保存省份对应的城市列表。
- 对象：使用键值对保存结构化数据。
- 模板字符串：使用反引号和 `${表达式}` 拼接字符串。

### 2. 程序控制

- 算术运算：`+`、`-`、`*`、`/`。
- 比较运算：`===`、`!==`、`<`、`>`。
- 逻辑运算：`&&`、`||`。
- 条件判断：`if...else`。
- 循环：`for`。
- 函数：使用 `function` 定义。
- 箭头函数：`() => {}`。
- 回调函数：把函数作为参数传给事件监听器或定时器。

### 3. 常用内置能力

- `Date`：获取当前时间。
- `setTimeout()`：延迟执行函数。
- `alert()`：弹出提示框。
- `console`：向控制台输出信息。

## 六、DOM 与事件

### 1. 获取元素

- `document.getElementById("id")`：按 ID 获取一个元素。
- `document.querySelector("selector")`：获取第一个匹配元素。
- `document.querySelectorAll("selector")`：获取所有匹配元素。

### 2. 读取和修改 DOM

- `.value`：读取或设置表单控件的值。
- `.textContent`：读取或设置文本内容。
- `.style`：修改行内样式。
- `.length`：获取数组长度或某些 DOM 集合的长度。
- `.options`：访问下拉框中的选项集合。
- `.selectedIndex`：获取当前选中项的索引。
- `.text`：读取或设置 `option` 的显示文本。
- `.value`：读取或设置 `option` 提交值。

### 3. 事件监听

- `window.onload`：页面及资源加载完成后执行。
- `DOMContentLoaded`：DOM 解析完成后执行，不必等待图片等资源。
- `onchange`：值改变并确认后触发，常用于下拉框。
- `addEventListener("click", handler)`：监听点击。
- `addEventListener("input", handler)`：监听输入实时变化。
- `addEventListener("submit", handler)`：监听表单提交。
- 事件对象 `event`：包含事件详细信息。
- `event.preventDefault()`：阻止默认行为。
- `this`：在普通事件回调中通常指向绑定事件的元素。

### 4. 省市二级联动算法

1. 准备一维省份数组 `provinces`。
2. 准备与省份索引对齐的二维城市数组 `citys`。
3. 页面加载后，根据省份数量动态生成 `option`。
4. 将数组元素写入 `option.text`，将索引写入 `option.value`。
5. 用户改变省份时，读取 `province.selectedIndex`。
6. 使用 `citys[index]` 获得该省份对应的城市数组。
7. 清空并重新生成城市下拉框选项。

核心思想是：**两个数组的索引严格对应**，省份索引就是城市数组的外层索引。

## 七、浏览器开发者工具与控制台

### 1. 打开方式与常见面板

- 右键“检查”或按 `F12` 打开开发者工具。
- `Elements`：查看和修改页面 DOM 与 CSS。
- `Console`：查看日志、错误，并直接执行 JavaScript。
- `Network`：查看资源加载、Ajax/XHR 请求和状态码。
- `Sources`：查看源代码、设置断点和调试函数。

### 2. 控制台的两类核心能力

- 信息输出与记录：浏览、JavaScript 引擎或代码输出日志、警告和错误。
- 交互式执行环境：直接执行 JavaScript，与当前页面实时交互。

### 3. 常用 `console` 方法

| 方法 | 作用 |
| --- | --- |
| `console.log()` | 输出普通信息 |
| `console.info()` | 输出提示信息 |
| `console.warn()` | 输出警告 |
| `console.error()` | 输出错误 |
| `console.debug()` | 输出调试信息 |
| `console.table()` | 用表格展示数组或对象 |
| `console.group()` / `console.groupEnd()` | 开始和结束日志分组 |
| `console.dir()` | 以对象属性列表形式查看对象或 DOM 元素 |
| `console.assert()` | 条件不成立时输出断言错误 |
| `console.count()` / `console.countReset()` | 统计和重置调用次数 |
| `console.time()` / `console.timeEnd()` | 测量代码耗时 |
| `console.trace()` | 输出调用堆栈 |

### 4. 控制台交互能力

- 直接计算表达式和拼接字符串。
- 定义变量、函数和对象。
- 获取、修改和点击页面 DOM 元素。
- 访问页面中的全局变量或全局函数。
- 查看 `window`、`document` 等全局对象。
- `$_`：最近一次表达式的结果。
- `$0` 至 `$4`：Elements 面板中最近选中的 DOM 元素。
- `$(selector)`：等价于 `document.querySelector()`。
- `$$(selector)`：等价于 `document.querySelectorAll()`。
- `clear()`：清空控制台。
- `monitorEvents(element, events)`：监听元素事件。
- `debug(function)` / `undebug(function)`：添加或移除函数断点。

### 5. 调试相关信息

- JavaScript 语法错误、类型错误和引用错误。
- 资源加载失败及 `404` 状态码。
- 同源策略和 CORS 安全错误。
- 实时表达式 Live Expression：持续显示某个表达式的当前值。
- 控制台筛选器：按错误、警告、信息、来源或关键词过滤日志。

## 八、高频易错点

- `label` 的 `for` 必须对应控件的 `id`，而不是 `name`。
- 表单真正提交的字段名由 `name` 决定，漏写或拼错会导致后端接收不到。
- 示例登录页中密码字段写成了 `name="passowrd"`，正确拼写应为 `password`。
- `placeholder` 不能代替正式标签，因为输入后提示会消失。
- HTML 和 JavaScript 前端验证都只是用户体验层，不能代替服务器验证。
- `e.preventDefault()` 会阻止表单默认提交，不能误以为页面正在真实发送数据。
- `var` 与 `let`、`const` 的作用域不同，新代码优先使用 `let`、`const`。
- `async` 不保证脚本执行顺序，`defer` 会按顺序在 DOM 解析后执行。
- `<base>` 会改变页面全部相对 URL 的解析结果，使用时要特别谨慎。
- 浮动元素通常需要父元素处理高度塌陷，示例中的 `overflow: hidden` 正是用于此目的。
- 绝对定位元素会寻找最近的已定位祖先，常给父元素设置 `position: relative`。
- 省市联动的数组索引必须对应，否则选择省份后会显示错误城市。
- 直接改写 `select.length` 会改变选项数量，适合动态生成下拉项。
- 外部 CSS 和图片路径错误时，应结合 Network 面板检查是否为 `404`。
