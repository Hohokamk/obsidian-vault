## 二、五案例如何组成完整应用

五个案例合并后，可以形成下面的完整链路：

```text
浏览书籍
→ 分类筛选与关键词搜索
→ 查看书籍详情
→ 复制联系方式或确认拨号
→ 收藏书籍
→ 发布自己的书
→ 在“我的”页面查看统计
→ 关闭后重新打开，数据仍然存在
```

从课程作业角度看，这个闭环已经完整。

从生产应用角度看，它仍然属于本地数据演示项目，还缺少后端接口、用户认证、图片上传、交易流程、内容审核、订单和真实数据库。

## 三、作业形式与提交要求

### 1. 页面结构

必做 5 个页面：

| 页面 | 路径 | 导航栏标题 | 类型 |
| --- | --- | --- | --- |
| 书市首页 | `pages/index/index` | 校园二手书市 | tabBar |
| 收藏夹 | `pages/collect/collect` | 我的收藏 | tabBar |
| 发布书籍 | `pages/publish/publish` | 发布书籍 | tabBar |
| 我的 | `pages/mine/mine` | 我的 | tabBar |
| 书籍详情 | `pages/detail/detail` | 书籍详情 | 普通页 |

要求：

- `pages` 数组的第一项必须是首页。
- tabBar 固定 4 项：书市、收藏、发布、我的。
- tabBar 切换必须使用 `uni.switchTab()`。
- 首页进入详情必须使用 `uni.navigateTo()`，并在 URL 中传入 `?id=`。
- 详情页使用 `uni.navigateBack()` 返回。

### 2. 提交物

提交一个压缩包，包含：

1. 项目源码文件夹。
2. 运行截图。
3. 200 字以内的说明文档。

项目文件夹命名：

```text
学号_姓名_校园二手书市
```

压缩时不要包含 `unpackage` 目录。

截图清单建议准备 8 张：

1. 首页筛选前。
2. 首页筛选后。
3. 详情页确认拨号弹窗。
4. 收藏夹有数据。
5. 收藏夹空态。
6. 发布页填好的状态。
7. 我的页含底部平台信息。
8. `pages.json` 中的 tabBar 配置。

## 四、五个页面的功能要求

### 1. 书市首页

- 显示静态 8 本书和用户发布的 `myBooks`。
- 支持全部、教材、文学、教辅、数码、其他 6 个分类。
- 搜索框实时过滤书名或描述。
- “共 N 本”随筛选结果变化。
- 使用 `scroll-view` 实现纵向滚动。
- 下拉刷新 0.6 秒后停止，并弹出 Toast。
- 点击卡片进入详情页。
- 从详情页返回时在 `onShow` 中刷新收藏状态。
- 列表为空时显示“书市暂时没有书～”。

### 2. 书籍详情页

- 使用 `onLoad(options)` 接收 `id`。
- `options.id` 是字符串，查找前必须使用 `Number()`。
- 显示书名、价格、原价、成色、分类、校区、浏览量、卖家和描述。
- 复制联系方式使用 `uni.setClipboardData()`。
- 联系卖家必须先 `showModal` 确认，再 `makePhoneCall`。
- 收藏状态写入本地存储。
- 下拉刷新后浏览量增加。
- 找不到书时显示“没有找到这本书”。
- 底部提供返回书市或返回上一页的操作。

### 3. 收藏夹

- 从 `collectIds` 读取收藏 id。
- 使用 `map` 把 id 转换成书籍对象。
- 使用 `computed` 生成收藏列表和数量。
- 没有收藏时显示空态和“去书市看看”。
- “去书市看看”必须使用 `switchTab`。
- 取消收藏前必须二次确认。
- 从详情页返回时在 `onShow` 中刷新。

### 4. 发布书籍

- 表单字段使用 `v-model` 和 `reactive` 或 `ref`。
- 书名使用 `v-model.trim`。
- 校验书名、价格、分类、成色、描述、电话。
- 描述下方实时显示“已输入 N / 200 字”。
- 校验失败时 Toast 提示并 `return`。
- 校验通过后使用 `showModal` 二次确认。
- 确认后写入 `myBooks`。
- 发布成功后 1.5 秒切回首页。
- 提交过程中禁用按钮，防止连续点击。

### 5. 我的

- 复刻静态个人名片页的布局思路。
- 圆形头像、昵称、学校或院系。
- 使用 `computed` 显示发布数量和收藏数量。
- “清空我的数据”必须二次确认。
- “关于本 App”使用 `showModal`。
- 使用条件编译显示当前运行平台。

## 五、案例技术点拆解

### 2.1 静态个人名片页

核心知识：

- HBuilderX 新建 uni-app Vue3 项目。
- `pages`、`static`、`pages.json`、`manifest.json` 的作用。
- 单文件组件 SFC 三段式：

```vue
<template>
</template>

<script setup>
</script>

<style scoped>
</style>
```

- HTML 标签到 uni-app 组件的映射：

| HTML | uni-app |
| --- | --- |
| `div` | `view` |
| `span`、`p` | `text` |
| `img` | `image` |
| `a` | `navigator` |

- `rpx` 以 750 为设计基准。
- 图片必须有宽高，路径使用 `/static/...`。
- 条件编译使用 `#ifdef`、`#ifndef` 和 `#endif`。

对应作业：

- 项目初始化。
- “我的”页面。
- 全项目布局和样式规范。

### 2.2 动态待办清单

核心知识：

- `ref` 保存基本类型、对象和数组。
- 在 `script` 中读写 `ref` 必须使用 `.value`。
- `reactive` 适合对象和数组，但不能整体重新赋值。
- `v-for` 渲染列表，必须用稳定的 `item.id` 作为 `:key`。
- `v-model` 完成输入框和数据的双向绑定。
- `@click` 处理添加、切换和删除。
- `.trim`、`.number`、`.stop` 等修饰符。
- `uni.showToast()` 提供操作反馈。

对应作业：

- 首页列表。
- 搜索框。
- 发布表单。
- 按钮交互与用户反馈。

### 2.3 待办清单增强版

核心知识：

- 只保存一份原始数据，其他结果通过 `computed` 派生。
- `v-if` 适合较少变化的条件。
- `v-show` 适合频繁切换的显示状态。
- `v-if` 和 `v-for` 不要写在同一个标签上。
- 顶部 Tab 只改变当前视图状态，不修改原始数据。
- `uni.showModal()` 用于危险操作二次确认。
- 本地存储实现数据持久化。
- `watch(..., { deep: true })` 可以监听数组内部变化。

对应作业：

- 首页分类筛选和搜索。
- 收藏列表与数量。
- 发布确认。
- 清空数据确认。
- 本地持久化。

### 2.4 多页面新闻列表

核心知识：

- 页面必须在 `pages.json` 中注册。
- tabBar 页面之间使用 `switchTab()`。
- 非 tabBar 页面使用 `navigateTo()`。
- `onLoad(options)` 在页面创建时执行一次。
- `onShow()` 在页面每次显示时执行，适合刷新列表。
- `scroll-view` 必须有确定高度才能滚动。
- `enablePullDownRefresh` 和 `onPullDownRefresh` 配合使用。
- 刷新完成后必须调用 `uni.stopPullDownRefresh()`。

对应作业：

- 5 页路由结构。
- 4 项 tabBar。
- 首页和收藏页刷新。
- 详情页参数传递与返回。

### 2.5 新闻详情页

核心知识：

- `showToast` 用于轻提示。
- `showModal` 用于需要用户确认的操作。
- 异步 API 的后续逻辑必须写入 `success` 或 `fail` 回调。
- `setClipboardData` 复制联系方式。
- `makePhoneCall` 必须在用户确认后调用。
- H5 和微信开发者工具不能验证真实拨号，必须使用真机。
- 拨号失败必须提供 `fail` 回调，不能静默失败。
- 收藏状态需要本地存储。
- 使用 `navigateBack()` 返回上一页。

对应作业：

- 详情页三个主要操作。
- 下拉刷新浏览量。
- 返回书市。
- 拨号安全保护。

## 六、数据与存储约定

### 1. 静态数据

数据文件：

```text
src/data/books.js
```

每本书至少包含：

```js
{
  id: 1,
  title: '高等数学（第七版·上册）',
  price: 15,
  originalPrice: 45,
  category: '教材',
  condition: '9成新',
  desc: '书籍描述',
  seller: '林之南',
  phone: '13800138000',
  cover: '/static/books/b1.png',
  campus: '东校区',
  publishTime: '2026-10-01',
  views: 128
}
```

要求：

- 静态数据补齐 8 本。
- 分类覆盖教材、文学、教辅、数码、其他。
- `cover` 使用 `/static/...` 绝对路径。

### 2. 本地存储

| key | 类型 | 含义 |
| --- | --- | --- |
| `collectIds` | 数组 | 收藏的书籍 id |
| `myBooks` | 数组 | 用户发布的书籍对象 |

首页显示的数据：

```js
const allBooks = computed(() => {
  const mine = uni.getStorageSync('myBooks') || []
  return [...mine, ...books]
})
```

新书 id 建议使用：

```js
Date.now()
```

## 七、代码规范

- 每个 `.vue` 文件使用 `template`、`script setup`、`style scoped` 三段式。
- 尺寸统一使用 `rpx`。
- 布局优先使用 flex。
- 图片元素必须设置宽高。
- 图片路径统一使用 `/static/...`。
- 文本放入 `text` 组件。
- 每个列表都要有空态。
- 用户操作必须有 Toast、弹窗或状态变化反馈。
- 提交类按钮需要禁用状态，防止重复提交。
- 控制台不能出现红色报错。

## 九、高频易错点

- `options.id` 是字符串，比较前必须 `Number()`。
- 图片没有宽高时会显示异常。
- 图片用相对路径可能在部分平台失效。
- 文本不放在 `text` 中，App 端可能不显示。
- `ref` 在 `script` 中忘记 `.value`，页面不会更新。
- `reactive` 数组整体赋值会丢失响应式。
- tabBar 页面使用 `navigateTo()` 会报错。
- 刷新逻辑写在 `onLoad` 中，从详情页返回时不会执行。
- `scroll-view` 没有高度时不能滚动。
- 忘记 `stopPullDownRefresh()`，刷新动画会一直转。
- 拨号没有放进 `res.confirm` 分支，点击取消也会拨号。
- 收藏只保存在内存中，关闭应用后会丢失。
- 发布存储 key 写成 `mybooks`，大小写不一致导致读取失败。
- 发布按钮没有禁用，可能连续写入多条数据。
