## 一、最关键的一个发现：课程名 ≠ 课程内容

| 项目        | 情况                                      |
| --------- | --------------------------------------- |
| 培养方案上的课程名 | **数字信号处理**（任选课，3 学分，周二 5-6 节）           |
| 课件首页标题    | **信号与系统**                               |
| 实际教材      | **郑君里、应启珩、杨为理《信号与系统》（第三版）上、下册**，高等教育出版社 |
| 课程定位      | 计算机系专业选修课（部分课件页脚写"专业必修课"）               |

**结论：这门课实际教的是《信号与系统》，不是通常意义上的 DSP。** 离散时间系统、z 变换、DFT/FFT 这些 DSP 核心内容都在**下册**，按这套课件的覆盖范围看，本课大概率讲不到。

这直接推翻了我最初的一个判断：郑君里那本书**不是"先修参考书"，它就是你的正课教材**。所以要吃透，不是"按需查阅"。

> 如果你选这门课的目标是学 DSP（做音频/图像/通信方向的 AI），要有心理准备：这门课是 DSP 的数学前传，不是 DSP 本身。

## 三、课件覆盖的内容（第 1—6 次课，全部未学）

### 第 1 次课 — 课程说明 + 第一章 §1.1–§1.2

- 课程背景、知识储备、作业与考试规则、就业方向
- 应用领域举例：电路分析、心电信号去噪、图像恢复与增强、土星轮廓特征提取、直流电动机调速
- §1.1 信号与系统：信号/消息/信息的概念区分；信号分析、系统分析、系统设计、信号设计四类任务
- §1.2 信号的描述、分类与典型示例
  - 描述方式：数学表达式 / 波形图 / **变换域描述**
  - 分类维度：确定性与随机、周期与非周期、连续与离散
  - **模拟 / 抽样 / 数字** 三分（时间轴与幅度轴的双重离散）
  - 典型连续信号：实指数、正弦、复指数、**Sa(t) 抽样信号**；与 sinc(t) 的关系
- **番外篇（老师自己加的）**：虚数、复数、欧拉公式
  - 用"逆时针旋转 90°"解释 i² = −1
  - 用"航向旋转"解释复数乘法的物理意义
  - 泰勒级数法证明欧拉公式

### 第 2 次课 — §1.3–§1.6

- §1.3 信号的运算：**移位、反褶、尺度变换**、相加、相乘、微分、积分、**卷积（预告）**
  - 典型训练题：由 f(t) 求 f(−2t+1) 的波形（反折 → 尺度 → 时移 三步）
  - 强调"反褶是卷积中一个非常重要的过程"
- §1.4 阶跃信号与冲激信号（**核心**）
  - 单位斜变、截平斜变、三角脉冲
  - **单位阶跃 u(t)**：本课程规定 u(0) = 1/2
  - 矩形脉冲 = 阶跃之差；阶跃信号描述"接入特性"
  - 符号函数 sgn(t) = 2u(t) − 1
  - **单位冲激 δ(t)**：Dirac 定义、广义极限定义（矩形脉冲系列取极限，面积恒为 1）
  - δ(t) 的性质：**筛选（抽样）特性**、偶函数、与 u(t) 的微积分关系
  - **冲激偶 δ′(t)**：奇函数、面积为零、与 f′(0) 的关系
- §1.5 信号的分解：直流/交流分量、偶/奇分量、实部/虚部分量、脉冲分量、**正交函数分解**
- §1.6 系统模型及其分类：图形符号、数学表示式（输入-输出描述 vs 状态变量描述）、方框图基本单元
- **课后作业：1-2、1-3(1,4)、1-4、1-7、1-10(a)、1-12**

### 第 3 次课 — §1.7–§1.8 + 第二章 §2.1–§2.2、§2.5–§2.6

- 系统按数学模型分 8 类：连续/离散、即时/动态、集总/分布、线性/非线性、时变/时不变、可逆/不可逆、因果/非因果、稳定/非稳定
- §1.7 LTI 系统四大特性：**叠加性与均匀性、时不变特性、微分特性、因果特性**
  - 强调："常系数线性微分方程描述的系统，**仅在起始状态为零时**才是线性时不变且因果的"
- §1.8 系统分析方法概述：三条演进线（输入输出→状态、连续→离散、时域→变换域）
- **第二章开篇**：§2.1 引言 —— 时域法（经典法、状态变量、卷积）vs 变换域法
- §2.2 微分方程的建立与求解
  - 经典法三步曲：齐次解（特征方程求根）+ 特解（查表）+ 定系数
  - 重根情形的齐次解形式
- §2.5 **零输入响应与零状态响应**
  - 全响应 = 自由响应 + 强迫响应 = 零输入响应 + 零状态响应
  - **扩展线性**：响应分解性、零状态线性、零输入线性
  - 瞬态响应与稳态响应
- §2.6 **冲激响应 h(t) 与阶跃响应 g(t)**
  - n > m 时 h(t) 为齐次解形式 × u(t)
  - n ≤ m 时需含 δ 的导数项，用**冲激匹配法**定系数
  - g(t) 与 h(t) 互为积分/微分关系
- **课后作业：1-17、1-18、1-20、1-21(1,3)**

### 第 4 次课 — 习题课 + §2.7–§2.8 卷积

- **习题课部分**
  - 冲激函数性质辨析（含 ∫f(t−t₀)δ(t)dt = f(−t₀) 这类易错项）
  - 冲激偶性质辨析（δ′(t) = −δ′(−t)，注意 δ′(t−t₀) = −δ′(t₀−t)）
  - 尺度变换与冲激结合的计算：e^(−2t)·δ(−2t+4) 的系数要乘 1/2
  - **系统类型判断方法**：
    - 线性：验证 T[a₁f₁ + a₂f₂] = a₁y₁ + a₂y₂
    - 时不变：验证 T[f(t−t₀)] = y(t−t₀)
    - 因果：输出不依赖未来输入
    - 典型反例：y(t) = sin[f(t)]u(t) 非线性且时变；y(t) = f(1−t) 线性但时变
- **§2.7 卷积**：由"任意信号分解为冲激之和"推出 rzs(t) = e(t) * h(t)
- **卷积积分图解法五步**：反折 → 平移 → 相乘 → 积分（+ 分段讨论 t 的取值范围）
- **§2.8 卷积的性质**
  - 卷积代数：交换律、分配律（并联系统）、结合律（串联系统）
  - 微分性与积分性
  - 微积分性：f₁*f₂ = f₁^(−1) * f₂′
  - 冲激性：f(t)*δ(t) = f(t)，f(t)*δ(t−t₀) = f(t−t₀)
  - 阶跃性：f(t)*u(t) = ∫f(τ)dτ
- 课后自学：§2.9（用算子符号表示微分方程）、§2.10（分配函数概念）

### 第 5 次课 — **第一次作业讲评**

- 作业 1-3(4)：周期信号求周期
- 作业 1-7：分段信号波形绘制
  - **关键方法**：形如 [u(t) − u(t−T)]·Sa(4πt/T) 的信号 = 门信号 × 单频信号，门信号起"选通"作用，取值为 −1 时还要反相
- 卷积相关作业讲解（含阶跃函数参与的卷积 → **必须讨论 t 的取值范围**）

### 第 6 次课 — 卷积习题续 + **第三章开篇**

- u(t) 参与的卷积，积分上下限随 t 变化
- 与冲激、延迟冲激、冲激串 δ_T(t) 的卷积（图形化理解）
- 用卷积性质简化计算
- **第三章 傅里叶变换**
  - 引言："什么是变换"——通过提取信号特征进行信号分析的工具
  - **本章思路主线：傅里叶级数 → 傅里叶变换 → 卷积定理 → 抽样定理**
  - §3.2 周期信号的傅里叶级数分析
    - 三角函数形式与各系数的积分表达式；三角函数集是**完备正交函数集**
    - 常用形式 c₀ + Σcₙcos(nω₁t + φₙ)
    - **狄利克雷条件**（有限间断点、有限极值、绝对可积）
    - 基波与各次谐波
    - **单边频谱图**；周期信号频谱具有**离散性、谐波性**
    - **指数形式**与双边频谱图；负频率只是数学处理，正负频率成对合并才是实际频谱
    - **周期信号的功率特性 / 帕塞瓦尔定理**：时域与频域能量守恒

### 4.1 你手上有"开卷预告"，怎么用

| --- | --- |

| **提前学 MATLAB / numpy** | 课程目标明确要求，而且这是你 CS 背景的主场，最容易拿分 |

### 4.2 课程重心预判（基于课件篇幅分布）

| 章节 | 课件投入 | 判断 | 说明 |
| --- | --- | --- | --- |
| 第 1 章 绪论 | 约 1.5 次课 | **地基** | 冲激函数、信号的运算与分解，是后续一切的基础 |

### 4.3 最大的战略信息：作业占 50%

课件明确写了"**作业 50% + 期末 50%**"。含义：

1. **作业必须全交、全对、全工整**。这一项的分值等于整个期末考。
2. 老师会**每次都讲评作业**（第 5 次课整节课都在讲评第一次作业），说明作业质量被高度关注。
3. 作业题全部出自郑君里教材课后题（1-2、1-7、2-13、2-15、2-18……），**教材答案在书上第 406 页起**。刷题闭环完整。
4. 从讲评内容看，高频扣分点集中在三处：
   - **卷积的分段讨论范围**（t 的取值范围没写全）
   - **冲激函数性质中的符号**（尤其冲激偶的奇偶性）
   - **尺度变换的系数**（δ(at) 提取系数容易漏 1/|a|）

   这三类错误在开课后要重点自查。

### 4.4 开课后的听课重点

从课件能看出老师的讲课习惯，听课可以对症下药：

- **老师爱加"番外篇"**（第 1 次课自己补了虚数、复数、欧拉公式的直观讲解）→ 这类补充往往是他认为学生最容易卡住的地方，要认真记。
- **重物理解释、轻电路推导** → 遇到公式推导跳跃时，不要慌，先抓"这个变换在物理上代表什么"。
- **每章配"小结"页** → 这些小结页就是复习提纲，可以直接抄进笔记。

### 4.5 关于"我到底在学 DSP 还是信号与系统"

如果选课目标是学**数字信号处理**：

- 这门课教的是**连续时间信号分析**，即 DSP 的数学前传
- **真正的 DSP 核心**（离散时间系统、z 变换、DFT/FFT、数字滤波器设计）在郑君里**下册第 7–12 章**
- 想补 DSP，两条路：
  1. 课程结束后自学下册第 7–10 章（尤其第 9 章 DFT 与 FFT）
  2. 直接上 Oppenheim《离散时间信号处理》或 Mitra《数字信号处理》，比郑君里下册更贴近工程
