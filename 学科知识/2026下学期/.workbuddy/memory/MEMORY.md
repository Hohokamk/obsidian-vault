# 2026 下学期 · 项目长期记忆

## 用户偏好（学习类任务）

- 要**有逻辑、有关系的结构**，不要分类罗列。
  问"框架 / 关系"时，要的是**因果链**（谁生出了谁、为什么会有这一章），不是**目录树**（谁属于谁）。
- **反感无意义的量化统计**。曾明确驳回"用可提取字数评估课件质量"：
  > "你不要跟我纠结字数的问题，他大多数字在图片上面，所以你读取不出来。"
  → 教训：不要量化"读不到的东西"。要量化就量化可验证对象（页数、年份、截止日期）。
- 要**明确结论**，不要"可能 / 建议考虑"这类模糊措辞。事实与推算要分开标注。
- 喜欢的呈现形式：表格、分级标题、记忆口诀、关键坑点标注、⚠️ 标记。
