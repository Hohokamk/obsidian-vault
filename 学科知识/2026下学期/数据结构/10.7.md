## 一、如果你想存"一组二元组 (x, y)"—— 比如路径坐标

这是最常见的场景，也就是你上面 `path` 那种。

cpp

#include <vector>
using namespace std;
// 方式 1：vector + pair（最常用）
vector<pair<int, int>> path;
path.push_back({3, 5});
path.push_back(make_pair(1, 2));
// 访问
path[0].first;   // 3
path[0].second;  // 5

cpp

// 方式 2：vector + 自定义 struct（语义更清晰）
struct Point {
    int x, y;
};
vector<Point> path;
path.push_back({3, 5});
path[0].x;   // 3
path[0].y;   // 5

cpp

// 方式 3：vector + array（固定两个元素）
vector<array<int, 2>> path;
path.push_back({3, 5});
path[0][0];  // 3
path[0][1];  // 5
