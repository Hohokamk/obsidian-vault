## 第 2 章 线性表（PPT 74 页）结构

主线：逻辑结构 → 存储结构 → 基本运算 → 时间复杂度 → 应用

- **2.1 类型定义**：线性表定义、有序性、ADT List 及基本操作、
  **C++ 引用 `&` 传参**（为后续 `&L` 铺垫）、例2-1 集合并、例2-2 有序归并
- **2.2 顺序表示**：`LOC(ai)=LOC(a1)+(i-1)*L`、SqList 结构体
  （elem/length/listsize + INIT_SIZE=100、INCREMENT=10）、
  初始化、插入（均移 n/2）、删除（均移 (n-1)/2）、
  `LocateElem_Sq` 用**函数指针** compare、`MergeList_Sq` O(m+n)
- **2.3 链式表示**（占篇幅最大）：结点 data/next、**头结点**、
  malloc/free、指针操作五式（核心口诀「先右后左」）、
  头插法（逆序）/尾插法（顺序）建表、按序号/按值查找、
  插入、删除、`MergeList_L` O(m+n)、
  **静态链表** SLinkList（`cur` 数组下标代替指针，0 号为头结点，
  Malloc_SL/Free_SL 备用链表）、例2-3 (A-B)U(B-A)、
  循环链表（`head->next==head` 判空）、双向链表（prior/next 对称性，
  `(p->prior)->next = p = (p->next)->prior`，插入/删除算法 2.18/2.19）
- **2.4 一元多项式**：`term{coef, expn}`、CreatePolyn、AddPolyn
  （指数比较三分支：小于则跳过、相等则系数相加、大于则插入；
  和为 0 删结点，非 0 改系数域）
