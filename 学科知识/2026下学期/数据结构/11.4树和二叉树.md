### 4.0 根据后序和中序遍历输出前序遍历（10 分）

本题要求根据给定的一棵二叉树的后序遍历和中序遍历结果，输出该树的前序遍历结果。

**输入格式**：第一行给出正整数 `n`（≤30），是树中结点的个数。随后两行，每行给出 `n` 个整数，分别对应后序遍历和中序遍历结果，数字间以空格分隔。题目保证输入正确对应一棵二叉树。

**输出格式**：在一行中输出 `Preorder: ` 以及该树的前序遍历结果。数字间有 1 个空格，行末不得有多余空格。

**输入样例**
```
7
2 3 1 5 7 6 4
1 2 3 4 5 6 7
```
**输出样例**
```
Preorder: 4 1 3 2 6 5 7
```

## 三、四类遍历：定义与相互还原

| 遍历 | 访问根的位置 | 递归顺序 | 序列特征 |
|---|---|---|---|
| 前序 Preorder | 最先 | 根 → 左 → 右 | 首元素必是根 |
| 中序 Inorder | 中间 | 左 → 根 → 右 | 根把序列劈成左右两半 |
| 后序 Postorder | 最后 | 左 → 右 → 根 | 末元素必是根 |
| 层序 Level | 按层 | BFS + 队列 | 第 k 层连续成段 |

### 3.1 为什么必须"两序 + 中序"才能还原

- 前序 / 后序只给出**根在哪**，给不出**左右子树的分界**；
- 中序给出根的位置，根左边的元素个数 = 左子树规模，右边 = 右子树规模；
- 因此：**前+中、后+中、层+中** 都能唯一还原；**前+后不能**（无法区分单孩子的左右）。

> 关键前提：`4.3` 明确写"键值互不相等"。若键值重复，中序查找根就有歧义，还原不唯一。

### 3.2 后序 + 中序 → 前序（4.0 的模板）

三步固定套路：

1. **定根**：后序的**最后一个**元素 `post[n-1]` 是根；
2. **分家**：在中序里找到根的位置 `k`，则 `in[0..k-1]` 是左子树、`in[k+1..n-1]` 是右子树，左子树规模 `k`，右子树规模 `n-1-k`；
3. **递归**：左子树的后序 = `post[0..k-1]`（前 k 个），右子树的后序 = `post[k..n-2]`（中间那一段，去掉末尾的根）。

```cpp
// post[0..n-1] 后序，in[0..n-1] 中序
void pre(int* post, int* in, int n) {
    if (n <= 0) return;
    int root = post[n - 1];
    int k = 0;
    while (in[k] != root) k++;          // 中序中定位根
    cout << root << ' ';                 // 根最先访问 = 前序
    pre(post,     in,       k);          // 左子树
    pre(post + k, in + k + 1, n - 1 - k);// 右子树
}
```
- 复杂度 O(n²)，n ≤ 30 完全够用；若 n 到 1e5 就得上哈希定位根，O(n)。
- **移位量必须是 `k` 不是 `k+1`**：后序的左子树起点就是 `post+0`，右子树起点是 `post+k`（左子树占掉前 k 个）。这是本题最大的错点。

### 3.3 后序 + 中序 → 层序（4.3）

结构还原逻辑和 4.0 **完全一致**，只是"访问根的时机"不同：
- 4.0 是在递归里直接打印（前序）；
- 4.3 必须**先建树，再 BFS**，因为层序的访问顺序由队列决定，递归天然给不出来。

```cpp
struct Node { int v; Node *l, *r; };

Node* build(int* post, int* in, int n) {
    if (n <= 0) return nullptr;
    int root = post[n - 1], k = 0;
    while (in[k] != root) k++;
    Node* t   = new Node{root, nullptr, nullptr};
    t->l = build(post,     in,       k);
    t->r = build(post + k, in + k + 1, n - 1 - k);
    return t;
}

void level(Node* root) {
    queue<Node*> q; q.push(root);
    bool first = true;
    while (!q.empty()) {
        Node* p = q.front(); q.pop();
        if (!first) cout << ' ';
        first = false;
        cout << p->v;
        if (p->l) q.push(p->l);
        if (p->r) q.push(p->r);
    }
}
```

验证样例：后序 `2 3 1 5 7 6 4` + 中序 `1 2 3 4 5 6 7`
根 = 4，中序 4 左侧 `1 2 3`（左子树）、右侧 `5 6 7`（右子树）
→ 左子树根 = 1，右子树根 = 6 → 层序 `4 | 1 6 | 3 5 7 | 2` ✅ `4 1 6 3 5 7 2`

## 四、层序遍历 = BFS + 队列

**唯一正解**：队列。先把根入队，循环「出队 → 访问 → 左孩子入队 → 右孩子入队」。

| 需求 | 做法 |
|---|---|
| 单纯层序 | 一个队列 |
| 要按层换行 / 分层统计 | 外层循环 + 内层 `for (int i = 0, sz = q.size(); i < sz; i++)`（**先取 size**，别在循环条件里写 `q.size()`） |
| 只要叶子且要层序 | BFS 中判断 `l == nullptr && r == nullptr` 即输出 |
| 每层从左到右、从右到左交替 | 加一个 `bool rev`，或改用双端队列 |

**为什么不能用 DFS 序冒充层序**：先序/后序里同一层的结点会被子树隔开，只有 BFS 保证"层内连续、层间递增"。

## 五、下标即结构：顺序存储的三个公式

顺序存储（数组从 **1** 开始）下，编号 `i` 的结点：

```
父结点   ⌊i / 2⌋
左孩子   2 * i
右孩子   2 * i + 1
```

推论（全部来自这三条）：

1. **祖先链** = 一路 `i /= 2` 直到 1，长度 = ⌊log₂i⌋ + 1；
2. **i 与 j 的 LCA**：谁大谁往上爬，直到相等；
3. **结点 i 所在层** = ⌊log₂i⌋ + 1；**深度**同理。

```cpp
int lca(int i, int j) {
    while (i != j) {
        if (i > j) i /= 2;
        else       j /= 2;
    }
    return i;
}
```

> 这一步的正确性靠"**编号大的结点深度不小于编号小的**"——因为完全二叉树的编号就是层序，父编号恒小于子编号。

### 4.2 的完整判断链

```
1. 读 n、T[1..n]
2. if (T[i] == 0) → 输出 "ERROR: T[i] is NULL" 并结束   // i 先查
3. if (T[j] == 0) → 输出 "ERROR: T[j] is NULL" 并结束
4. 否则 k = lca(i, j)，输出 "k T[k]"
```

样例 2 验证：`i=12, j=8`，`T[12]=0` → 报 `T[12]`，**不是** `T[8]`（`T[8]=2` 是合法的）。所以「先 i 后 j」的顺序不能反。

## 六、完全二叉树：数组下标就是层序

### 6.1 定义拆解（4.4 的题干）

- **完美二叉树**：每层都满，深度 D 有 2^D − 1 个结点；
- **完全二叉树**：编号 1..N 的结点，和"同深度完美二叉树的前 N 个结点"一一对应。

等价说法（更好用）：**把结点按层序编号 1..N 填进数组，中间没有空洞**。
→ 立刻得到两个可编程的结论：
1. 数组下标顺序 = 层序输出顺序，**不需要 BFS**；
2. 叶子编号从 ⌊N/2⌋ + 1 开始（编号 ≤ ⌊N/2⌋ 的一定有孩子）。

### 6.2 后序 → 层序：按后序顺序"填坑"

完全二叉树的后序遍历也满足「左 → 右 → 根」，而它的"左/右/根"在数组里的位置是确定的（`2i` / `2i+1` / `i`）。于是：

**按后序序列的下标递增顺序，依次把值填到 dfs 的"根位置"上**，填完数组即为层序。

```cpp
int N, tree[64], post[64], idx = 0;

void fill(int k) {          // k 是数组下标
    if (k > N) return;
    fill(2 * k);            // 左
    fill(2 * k + 1);        // 右
    tree[k] = post[idx++];  // 根 —— 后序的"根"在最后访问
}
// 调用 fill(1)，然后输出 tree[1..N]
```

样例验证（N=8，后序 `91 71 2 34 10 15 55 18`）：
`tree[8]=91, tree[4]=71, tree[5]=2, tree[2]=34, tree[6]=10, tree[7]=15, tree[3]=55, tree[1]=18`
→ 层序 `18 34 55 71 2 10 15 91` ✅

> **注意与 4.0 的区别**：4.0 是"给两条序列、自己找分割点"；4.4 是"结构已经由 N 定死、只需要把值按访问顺序塞进去"。后者不需要中序，因为完全二叉树的形状唯一确定。

### 6.3 三种遍历的"回填"对照

| 已知 | 回填写法 | 说明 |
|---|---|---|
| 后序 → 层序 | `fill(l); fill(r); tree[k]=post[idx++]` | 根最后赋值 |
| 前序 → 层序 | `tree[k]=pre[idx++]; fill(l); fill(r)` | 根最先赋值 |
| 中序 → 层序 | `fill(l); tree[k]=in[idx++]; fill(r)` | 根中间赋值 |

口诀：**赋值语句的位置 = 该遍历访问根的位置**。

## 七、4.1 专项：静态孩子表示法

这题不用指针，用「孩子编号表」，本质是**静态链表思想**（第 2 章 2.3 节）。

### 7.1 建表 + 找根

```
left[i], right[i]  // -1 表示空
hasParent[]        // 被指向过的置 true
根 = 唯一 hasParent[x] == false 的 x
```

**坑点**：编号是 `0 ~ n-1`，孩子编号可以是 `0`。
→ 绝对不能用 `0` 当"空"的哨兵，必须用 `-1`。这是本题第一大坑。

### 7.2 输出顺序 = 层序

题目要"从上到下、从左到右"，就是 BFS。**不能**用先序/后序，否则同一层的结点会被子树打断。

```
3 → 2 7 → 0 4 6 → 1 5
叶子：4、1、5   （0 有左孩子 1，6 有左孩子 5，都不是叶子）
```

### 7.3 完整骨架

```cpp
int L[15], R[15]; bool son[15] = {false};
// 读入：'-' → -1，否则读编号并 son[编号]=true
int root = 0; while (son[root]) root++;      // 找根

queue<int> q; q.push(root);
bool first = true;
while (!q.empty()) {
    int u = q.front(); q.pop();
    if (L[u] == -1 && R[u] == -1) {          // 叶子
        if (!first) cout << ' ';
        first = false;
        cout << u;
    }
    if (L[u] != -1) q.push(L[u]);
    if (R[u] != -1) q.push(R[u]);
}
```

## 八、坑点清单（按丢分概率排序）

1. **行末空格**：5 道题全部要求"行末不得有多余空格"，用 `first` 标志位或 `if (i) cout << ' '`，别写 `cout << x << ' '`。
2. **4.1 的 0 号结点**：孩子用 `-1` 判空，不能拿 `0`。
3. **4.1 的根不能默认 0**：必须靠入度/`hasParent` 反查。
4. **4.0/4.3 的后序右子树起点是 `post + k`**，不是 `post + k + 1`。同理左子树长度是 `k` 不是 `k + 1`。
5. **4.2 的检查顺序**：先 `T[i]` 后 `T[j]`，样例 2 就是专门测这个的。
6. **4.2 的编号从 1 开始**：`T[0]` 不用，别把输入的第一个数塞进 `T[0]`。
7. **4.4 的 `k > N` 边界**：递归 `fill(2*k)` 会越界到 2N，数组开 64 以上（N ≤ 30，2N ≤ 60）。
8. **4.4 不要真去建树或 BFS**：完全二叉树直接数组输出，写 BFS 反而容易错。
9. **递归深度**：N ≤ 30，链状退化最深 30 层，不会爆栈；若 N 到 1e5 必须改迭代。
10. **多组输入**：这几题都是单组，但 `4.1` 若遇上 `n = 0` 要直接不输出（题目写正整数，兜底即可）。
