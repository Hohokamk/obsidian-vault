## 1. 岗位画像：机器人系统工程师到底考什么

- **定位**：处于「上层算法」与「底层控制」之间的**中间件 / 系统架构层**，打通感知→决策→执行的整条链路。
- **职责关键词**：Linux + ROS2 系统搭建、数据零拷贝、实时性优化（PREEMPT_RT）、传感器时间同步、多进程/多线程通信、DDS 中间件、软硬件接口契约。
- **技能要求**（综合多份 JD）：扎实 C++、Linux 系统编程、ROS2/DDS、并发编程；懂嵌入式/RTOS/通信总线（加分）；了解控制理论（加分）；良好的软件工程能力。
- **常见别名**：机器人系统软件工程师、机器人系统开发工程师、机器人软件工程师、ROS 开发工程师、机器人系统工程师、具身智能系统工程师。
- **面试整体框架**（具身智能方向常考三维度）：**模型能力 + 控制理解 + 系统能力**。

## 3. 高频面试题分类整理

### 3.1 ROS2 / 通信中间件（几乎必考，权重最高）

**ROS1 vs ROS2 核心差异**（小米 ROS 开发岗原题，CSDN）
- ROS1 依赖 roscore（Master）中央节点做名称发现 → **单点故障**、无法跨网络、无安全机制。
- ROS2 改用 **DDS** 做底层通信：分布式发现（无中央节点）、原生支持 QoS、可跨网络、支持安全加密、实时性更好、跨平台（Windows/macOS/RTOS）、launch 从 XML 变 Python。
- 加分点：提到「小米 CyberDog 是国内最早用 ROS2 的团队之一」。

**三种通信方式怎么选**
- **Topic**：发布/订阅，单向异步一对多，适合高频持续数据流（激光雷达点云、IMU、图像）。
- **Service**：请求/响应，双向同步，适合一次性需确认的场景（打开相机、查询电量、急停）。
- **Action**：双向异步带反馈+可取消，适合长耗时任务（导航到 B 点、机械臂抓取）。
- 一句话：**传感器流用 Topic，查询/触发用 Service，长时间任务用 Action。**

**QoS（Quality of Service）怎么配**
- 核心维度：Reliability（RELIABLE vs BEST_EFFORT）、Durability（TRANSIENT_LOCAL vs VOLATILE）、Deadline、Liveliness、History。
- 典型配置（四足机器人）：
  - 激光雷达/深度相机 → BEST_EFFORT + VOLATILE（数据量大、丢帧无妨、要低延迟）
  - 运动控制指令 cmd_vel → RELIABLE + VOLATILE（**绝对不能丢**）
  - 地图 map → RELIABLE + TRANSIENT_LOCAL（建好后不变、晚订阅也要能收到）

**ROS2 其他高频题**
- colcon 编译工具链、节点生命周期状态机、TF2 变换链（现场画变换链）、参数服务器、launch 文件、ros2 topic/service/action 命令行、消息类型与 DDS 映射。
- 参考：ROS2 常见面试题 20 题（CSDN）：https://blog.csdn.net/zwqhlzd/article/details/162953905
- ROS 八股文（CSDN）：https://blog.csdn.net/weixin_62688777/article/details/140261044
- SLAM 面试笔记 · ROS 面试：https://blog.csdn.net/qq_41921826/article/details/130565629

### 3.2 Linux 系统 / 并发 / 内存（CS 背景的护城河，务必吃透）

- 进程 vs 线程；系统调用的完整过程（用户态→内核态→执行例程→返回）。
- 进程间通信 8 种方式及适用场景（管道、消息队列、共享内存、信号量、信号、Socket 等）；为什么分用户空间/内核空间。
- 共享内存的分配位置、读写速度、是否经过内核；零拷贝（DMA-BUF）原理。
- 内存管理：页表/MMU、虚拟地址→物理地址、段页式存储、缺页中断、堆区与栈区之间还有哪些区、mmap 匿名映射、ELF 各段分布。
- Linux 调度：schedule() 原理与调用时机、多级反馈调度、时间片轮转、nice/优先级、上下文切换做了什么。
- 实时性：如何评估 OS 实时性、如何测算中断响应时间、PREEMPT_RT。
- GDB 调试：常用命令、多线程调试、栈回溯（backtrace）、段错误定位。

### 3.3 嵌入式 / RTOS / 硬件总线（大疆、宇树、智元高频）

- RTOS：任务状态与切换、硬实时 vs 软实时、调度策略、优先级反转与优先级继承、信号量/互斥量底层设计、任务栈大小估算、栈溢出检测、FreeRTOS 内存管理、滴答时钟频率、任务抢占机制。
- 锁：自旋锁 vs 互斥锁（高优先级任务频繁抢占选哪个、中断里用自旋锁如何避免死锁）、死锁四必要条件、临界区数据用互斥锁还是条件判断。
- 内存：malloc/free 注意点、malloc(0)、realloc 风险、内存碎片优化、野指针/内存泄漏调试、内存对齐、#pragma pack、代码段/数据段/BSS 段。
- 中断：ISR 设计原则（避免复杂逻辑）、ISR 中的竞争条件、中断产生原理、STM32 中断控制器、中断上下文。
- 硬件外设：SPI 4 种模式/几根线/速率、I2C 读写步骤、UART、DMA 原理与双缓冲、PWM 原理与占空比调节、看门狗故障恢复流程、OTA 升级与固件校验/回滚、设备树 Device Tree、字符设备驱动开发流程。
- 低功耗：时钟树配置、休眠策略、硬件选型。
- C/C++：虚函数机制/虚表指针位置、多态、智能指针（weak_ptr 作用与防崩溃）、const、字节对齐、extern "C"、delete[] vs delete、指针 vs 引用、可重入函数 vs 线程安全、静态变量初始化时机、位操作（置位/清位）。

## 4. 结合你背景的备战建议（RoboMaster + CS，目标：系统工程师）

> 参考你 vault 里「AI解读岗位.md」「深入研究方向.md」的定位：CS 背景最优切入点是**系统/中间件层**，护城河 = Linux 系统编程 + C++ + 并发 + ROS2/DDS。

1. **ROS2/DDS 是最高权重**：把「ROS1 vs ROS2、Topic/Service/Action、QoS 四维度、生命周期状态机、TF2、零拷贝」答到能讲清设计动机 + 现场画图。结合 RoboMaster 载板（RK3588/Jetson）上的节点流转、共享内存 Zero-Copy 讲实战。
2. **项目准备成「可深挖」版本**：大疆式问法会抠到「电机控制频率多少？为什么？弹性构件作用？材料缩水率？」——给每个 RoboMaster/大创项目准备一张「细节表」：选型理由、关键参数来源、性能数据、踩过的坑。
3. **补足系统 + 嵌入式八股**：Linux 调度/内存/进程通信 + RTOS/锁/中断 + C++（虚函数/智能指针）是校招系统岗主战场，按上面 3.2/3.3 清单逐个过。
4. **准备一个「部署/量化」故事**（宇树式追问）：如果简历写跑过视觉模型/端侧部署，务必能答「量化参数怎么来的、推理耗时分布、算力负载对控制环路的影响」。
5. **算法题按机器人映射刷**：BFS/DFS/Dijkstra/A* + 双指针/滑动窗口 + 简单 DP，刷完想清楚和「路径规划/地图连通域/时序处理」的对应关系。
6. **一主一辅**：主攻系统/中间件，辅以电机控制 / 实时总线（CAN/EtherCAT）常识，与「深入研究方向.md」的组合 A/B 保持一致。
