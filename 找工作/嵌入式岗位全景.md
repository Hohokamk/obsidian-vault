## 零、一页速览：怎么用这张图谱

1. **嵌入式岗位按产业位置分 5 层**：IP/指令集 → 芯片/模组 → 板卡/方案 → 整机/终端 → 场景软件（车/机器人/家电/工业/医疗/安防/通信）。你在哪一层，决定你的技术栈和天花板。
2. **投递分层，不平行轰炸**：
   - **冲刺**：华为、大疆、海康、中兴、头部手机厂（小米/OPPO/vivo/荣耀）、头部车企（比亚迪/理想/蔚来/小鹏）
   - **主力**：汇川、芯片厂嵌入式岗（兆易/瑞芯微/全志/地平线等）、理想/蔚来/小鹏、深信服、储能/电源龙头
   - **保底**：家电（美的/格力/海尔/长虹）、工控二线、安防二线、地方龙头
3. **数量策略**：精投 40~80 家，每家按 JD 改 20% 简历关键词，比海投 100 家垃圾简历更值钱。
4. **八股主线**：C 语言 → RTOS/Linux → 驱动/外设/协议 → 1 个能深挖 30 分钟的硬核项目。
5. **信息渠道**：公司官网招聘页 + 学校就业网 + 牛客讨论区 + 校级校招群 + 「嵌入式校招日报」类公众号（先到先筛、人满即停的岗位很多）。

## 三、嵌入式岗位族谱：按岗位类型拆解职责与要求

### 1. MCU 固件 / RTOS 工程师（裸机 + RTOS）
- **职责**：基于 STM32/GD32/NXP/RISC-V MCU 写 C 代码，初始化外设、实现业务逻辑（温控、电机 PID、数据采集上报）、OTA、低功耗。
- **核心技术栈**：C 语言（指针/内存/结构体）、GPIO/定时器/PWM/ADC/DAC/UART/I2C/SPI/CAN、FreeRTOS / RT-Thread / Zephyr / CMSIS-RTOS v2、DMA、低功耗唤醒。
- **代表公司**：兆易创新、乐鑫、泰凌微、长虹、公牛、智岩、九号、家电/IoT 全行业。
- **面试重点**：中断优先级与临界区、为什么中断里不能 printf、FreeRTOS 优先级反转、寄存器位操作、启动流程（复位向量→SystemInit→时钟→中断向量表）。

### 2. 嵌入式 Linux / BSP / 驱动工程师（溢价最高、缺口最大）
- **职责**：让 Linux 在 SoC 上跑起来，U-Boot 移植、设备树、字符设备驱动、DMA、外设驱动（CSI/SPI/I2C/USB）、内核裁剪、PREEMPT_RT 实时化。
- **核心技术栈**：C/C++、Linux 内核（中断上下半部、等待队列、mmap、platform 总线、regmap、设备树）、U-Boot、Buildroot/Yocto、GDB/交叉编译、JTAG/示波器。
- **代表公司**：华为、大疆、小米、海康、瑞芯微、全志、晶晨、地平线、蔚来/理想/小鹏、宇视、锐捷、新华三。
- **面试重点**：一次读写请求怎么走到硬件、DMA 与 CPU 缓存一致性、设备树如何描述中断控制器、内核 panic 定位、sk_buff/Netfilter（网络设备）。

### 3. 底层软件 / 协议栈工程师（通信与网络）
- **职责**：网络协议栈、转发面/控制面、通信中间件、工业总线协议栈（EtherCAT 主/从站、CANopen、TSN）。
- **核心技术栈**：TCP/IP 收发流程、socket、ARP/VLAN/路由协议、Linux 网络子系统；EtherCAT（SOEM/IGH）、CANopen（OD字典/SDO/PDO/SYNC）、TSN（802.1AS/Qbv）。
- **代表公司**：中兴、锐捷、新华三、TP-LINK、烽火、迪普、雷赛、汇川、大疆、智界/奇瑞（车载通信）。
- **面试重点**：sk_buff 是什么、Netfilter 框架、内存池设计、CAN 仲裁/过滤/错误帧、EtherCAT DC 时钟同步精度、总线丢包排查。

### 4. 嵌入式 AI / 算法部署工程师（正在快速放量）
- **职责**：把模型部署到端侧（NPU/DSP/GPU），量化、推理优化、SDK 二次开发。
- **核心技术栈**：ONNX Runtime、OpenVINO、TensorRT、INT8 量化、NPU 内存映射（tiling）、交叉编译、perf/DMA 优化；异构架构（NPU+DSP+CPU）。
- **代表公司**：爱芯元智、寒武纪、地平线、瑞芯微、全志、旷视/商汤、迈瑞、昊一源、海康。
- **面试重点**：模型如何"焊"进硬件（权重映射到 NPU Tile）、量化误差补偿、DDR/NPU buffer 配置、推理延迟优化。

### 5. 嵌入式硬件工程师
- **职责**：原理图、PCB（2-8层+）、电源、EMC/EMI、SI/PI、量产 DFM、整机调试。
- **核心技术栈**：模拟/数字电路、Altium Designer / Cadence / PADS、UART/I2C/SPI/CAN/USB/Ethernet/MIPI/LVDS、示波器/逻辑分析仪/频谱仪。
- **代表公司**：全行业；大疆、华为、海康、京东方、比亚迪、汇川、TP-LINK 等。
- **面试重点**：电源树、晶振/复位/Boot 配置引脚、信号完整性、EMC 设计、车规 AEC-Q100。

### 6. FPGA / SoC / 逻辑工程师（小而精、门槛高）
- **职责**：FPGA 逻辑（Verilog/VHDL）、SoC 验证、时序约束、软硬件协同。
- **核心技术栈**：Verilog、ZYNQ（PL+PS）、Vivado、时序收敛、AXI、DDR/MIPI/PCIe 高速接口。
- **代表公司**：紫光同创、复旦微、迪普、锐捷、雷赛、光迅、特纳飞、京东方。
- **面试重点**：PL 时钟源配置、DC 同步精度、跨时钟域、资源与时序优化。

### 7. 嵌入式测试 / 验证工程师
- **职责**：测试工具开发、量产程序、芯片验证、测试平台搭建。
- **核心技术栈**：C/Python、自动化测试框架、示波器/逻辑分析仪、脚本。
- **代表公司**：长鑫、长江存储、紫光同创、强一、迪普、京东方。
- **特点**：对校招友好，是切入芯片原厂的常见入口。

### 8. 数字电源 / 电机控制工程师（高溢价、稀缺）
- **职责**：开关电源数字控制环路、伺服/电机 FOC 控制、变流器/储能 PCS、BMS。
- **核心技术栈**：SVPWM、Park/Clarke、电流环/速度环/位置环、弱磁、高频注入、EKF、PWM 死区补偿、ADC 中心对齐采样；数字电源环路（PID/双环）。
- **代表公司**：汇川、雷赛、大疆、宇树/智元/傅利叶、比亚迪/蔚来/小鹏/小米汽车、阳光电源、长城电源、图为电气、宁德时代、方正电机。
- **面试重点**：电流环 20-50kHz 中断下 10μs 算完、无感 FOC、环路稳定性、MOS 驱动波形、通信协议（CANopen/EtherCAT）。

### 9. 车载嵌入式（AUTOSAR / 域控 / BMS）
- **职责**：ECU/域控制器软件开发、AUTOSAR CP/AP 配置、BMS、网关、诊断。
- **核心技术栈**：AUTOSAR（BSW/RTE/应用层）、CAN/LIN/FlexRay/车载以太网、UDS 诊断、ISO 26262 功能安全、AUTOSAR CP/AP 双栈（宇通已把双栈列为硬门槛）。
- **代表公司**：整车厂 + Tier1（博世、联合电子、经纬恒润、德赛西威、均胜）+ 华为车BU + 云驰未来。
- **面试重点**：AUTOSAR 分层、CanIf 状态机、功能安全思维、看原理图、实时性经验。

### 10. 嵌入式安全 / 固件安全（Secure Boot / OTA）
- **职责**：安全启动、签名固件、OTA 差分升级、加密、防回滚。
- **核心技术栈**：Secure Boot 流程（RK3588 BL1/BL2/BL31/BL33）、RSA/签名验签、Secure Element、固件逆向。
- **代表公司**：长虹（IHO 系列）、华为、海康、车厂、云驰未来。
- **面试重点**：刷机包结构、boot.img/dtb、验签失败日志定位。

### 11. FAE / 现场应用工程师
- **职责**：芯片/方案的技术支持、客户问题定位、参考设计。
- **核心技术栈**：嵌入式软硬件广度、沟通能力、出差。
- **代表公司**：聚辰、泰晶、飞仕得、芯洲、灵猴、敦泰、慧荣。

- 深圳华为 嵌入式软件工程师：**应届生约 24.3K/月**（职友集）。
- 计算机类公司 嵌入式软件工程师：约 **53.7% 岗位在 20-50K/月（年薪 24-60W）**；应届生均值约 16.8K/月。

- 头部大厂嵌入式校招（华为/大疆/小米/蔚来/理想等）一般 20-30K/月起步，总包随公司/批次浮动，以当年 Offer 为准。

### 影响薪资的 5 个变量
1. **技术栈深度**：会 C 与会 C+汇编+硬件调试是两种人；能看懂原理图、会用示波器/逻辑分析仪定位时序问题，谈判筹码完全不同。
2. **方向溢价**：驱动/BSP、汽车电子功能安全、芯片固件 >> 单片机裸机/应用层。
3. **产业位置**：离"核心物理执行层"越近（电机/总线/安全）越值钱。
4. **公司类型**：芯片原厂、车规、数字电源、机器人关节伺服 > 一般消费电子。
5. **城市**：深圳/上海/北京 > 二线城市（同样 16K 在深圳和长沙是两种生活）。

## 八、与你个人方向的对标（FOC 电机控制 / 实时总线 / Linux BSP）

结合你「深入研究方向」笔记里的三个主攻方向，直接把上面的全景图收敛成你的**可投池**：

### 方向一：高性能电机驱动与数字控制（FOC / 伺服）
- **目标岗位**：电机控制工程师、关节伺服研发、电驱控制、数字电源控制
- **首选公司（技术最对口）**：大疆（云台/动力）、宇树/智元/傅利叶（人形关节）、汇川/雷赛（伺服）、方正电机（驱动电机）、比亚迪/蔚来/小鹏/小米汽车（电驱）、阳光电源/长城电源/图为电气（数字电源）、九号（两轮电控）
- **简历重点**：SVPWM、Park/Clarke、弱磁、无感FOC（HFI/EKF）、电流环 20-50kHz 中断 10μs 内完成、PWM 死区补偿、ADC 中心对齐采样

### 方向二：工业实时总线与通信中间件（CAN / EtherCAT / TSN）
- **目标岗位**：机器人通信架构、车载通信协议、网关/底盘通信、伺服协议栈
- **首选公司**：大疆（整机总线）、智界/奇瑞/蔚来/理想（整车网络）、汇川/雷赛（EtherCAT 从站）、新松/灵猴/仙工（机器人）、锐捷/新华三（网络设备）
- **简历重点**：CAN/CAN-FD 位时序、CANopen（OD/SDO/PDO/SYNC）、EtherCAT（SOEM/IGH/DC 同步）、TSN（802.1AS/Qbv）、心跳超时安全降级方案

### 方向三：嵌入式 Linux BSP / 内核 / 驱动
- **目标岗位**：Linux BSP、驱动工程师、智能底座系统工程师、智驾底软
- **首选公司**：瑞芯微/全志/晶晨（芯片原厂 BSP）、大疆/小米/海康/宇视（终端底软）、蔚来/理想/小鹏（智驾底软）、地平线/黑芝麻/芯驰（车载 SoC）、海思/紫光展锐（芯片软件）
- **简历重点**：U-Boot 移植、设备树、字符设备驱动、中断上下半部、DMA-BUF、CSI 摄像头、PREEMPT_RT 实时性、Buildroot/Yocto

### 推荐组合（与你的笔记一致）
- **组合 A（运控）**：FOC 电机控制（主）+ 实时总线（辅）→ 大疆、宇树、智元、汇川、雷赛、车厂电驱
- **组合 B（系统底软）**：Linux BSP/驱动（主）+ 通信架构（辅）→ 瑞芯微、地平线、智驾域控、机器人计算平台
