---

## ⚠️ 但 OLS 有严重问题

### 问题 1：R²仍然很低

```
R² = 0.084 意味着：
  - 模型只能解释 8.4% 的变异
  - 91.6% 的变异解释不了
  - 预测能力仍然很差
```

**类比**：用这个模型预测 Y 浓度，误差会很大。

### 问题 2：违反独立性假设

看 **Durbin-Watson 统计量**：

```
模型1: DW = 0.818
模型2: DW = 0.815
模型3: DW = 0.815
模型4: DW = 0.844
```

**DW 应该在 2 左右**（表示残差独立）。

```
DW < 1 → 残差正相关（违反独立性假设）
DW = 0.8 → 严重自相关
```

**为什么？** 因为同一孕妇的 4 次测量是相关的，但 OLS 把它们当成 1082 个独立样本！

### 问题 3：可能高估显著性

```
模型4中：
  孕周：p < 0.001 ***
  年龄：p < 0.001 ***
  体重：p = 0.027 *
  怀孕次数：p = 0.002 **
```

这些 p 值**可能过于乐观**，因为：

- 样本量虚高（1082 而非 267）
- 标准误被低估
- 实际显著性可能没那么强
