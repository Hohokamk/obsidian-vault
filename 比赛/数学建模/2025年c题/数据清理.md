### 4.1 孕周转换函数

```
import re  # 正则表达式库

def parse_gestational_week(week_str):
    """
    把孕周字符串转换成小数
    例如："11w+6" → 11.857
    """
    # 1. 检查是否为空
    if pd.isna(week_str):
        return None
    
    # 2. 转成字符串
    week_str = str(week_str)
    
    # 3. 用正则表达式提取数字
    # r'(\d+)w(?:\+(\d+))?' 的含义：
    #   (\d+)    - 匹配一个或多个数字（周数）
    #   w        - 匹配字母w
    #   (?:...)? - 非捕获组，可以出现0次或1次
    #   \+       - 匹配加号
    #   (\d+)    - 匹配数字（天数）
    match = re.match(r'(\d+)w(?:\+(\d+))?', week_str, re.IGNORECASE)
    
    if match:
        groups = match.groups()  # 例如：('11', '6')
        weeks = int(groups[0])   # 11
        days = int(groups[1]) if groups[1] is not None else 0  # 6
        return weeks + days / 7.0  # 11 + 6/7 = 11.857
    else:
        return None

# 应用到整列
df['孕周_数值'] = df['检测孕周'].apply(parse_gestational_week)
```

### 4.2 标准化函数

```
def standardize(series):
    """
    标准化：(x - mean) / std
    返回：标准化后的数组，均值，标准差
    """
    mean = series.mean()
    std = series.std()
    standardized = (series - mean) / std
    return standardized, mean, std

# 使用
df['BMI_标准化'], bmi_mean, bmi_std = standardize(df['孕妇BMI'])
```

**数学原理**：

```
原始值：[28, 32, 35, 40]
均值 = (28+32+35+40)/4 = 33.75
标准差 = sqrt([(28-33.75)² + (32-33.75)² + (35-33.75)² + (40-33.75)²]/4) = 4.27

标准化后：
  28 → (28-33.75)/4.27 = -1.35
  32 → (32-33.75)/4.27 = -0.41
  35 → (35-33.75)/4.27 = 0.29
  40 → (40-33.75)/4.27 = 1.46
```

### 4.3 分类变量编码

```
# 方法1：isin + astype
df['是否辅助生殖'] = df['IVF妊娠'].isin(['IVF（试管婴儿）', 'IUI（人工授精）']).astype(int)

# 分解步骤：
# 1. isin() 返回布尔值
is_aux = df['IVF妊娠'].isin(['IVF（试管婴儿）', 'IUI（人工授精）'])
# 结果：[False, False, True, False, ...]

# 2. astype(int) 布尔值转整数
# False → 0, True → 1
df['是否辅助生殖'] = is_aux.astype(int)
# 结果：[0, 0, 1, 0, ...]

# 方法2：map 字典映射
health_map = {'是': 1, '否': 0}
df['胎儿是否健康'] = df['胎儿是否健康'].map(health_map)
```

### 4.4 缺失值处理

```
# 反推末次月经
df['检测日期_dt'] = pd.to_datetime(df['检测日期'].astype(str), format='mixed')
df['末次月经_推算'] = df['检测日期_dt'] - pd.to_timedelta(df['孕周_数值'] * 7, unit='D')

# 用反推值填补缺失
df['末次月经'] = df['末次月经'].combine_first(df['末次月经_推算'])
```

**解释**：

- `pd.to_datetime()`：把字符串转成日期类型
- `format='mixed'`：自动识别不同格式（"20230429" 或 "2023-03-17"）
- `pd.to_timedelta()`：把天数转成时间间隔
- `combine_first()`：优先用第一个值，如果为空就用第二个值
