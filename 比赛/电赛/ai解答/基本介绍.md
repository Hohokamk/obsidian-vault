# 全国大学生电子设计竞赛（电赛）完整介绍 + 参赛全注意事项

## 一、电赛基础介绍

### 1. 赛事定位

全称**全国大学生电子设计竞赛（NUEDC）**，教育部、工信部联合主办，**全国 A 类顶级学科竞赛**，电子 / 自动化 / 计算机 / 通信专业含金量最高赛事，保研、就业认可度极强。

- ==举办周期== ：  **单数年举办国赛**（2025、2027…），每两年一届；双数年多数省份办省赛选拔赛。 
- 参赛组队：**3 人 1 队**，全日制本科 / 专科在校生，不限年级；无单独指导老师上场操作，全程学生独立完成。
- 比赛时长：**四天三夜（96 小时）** 半封闭集中制作，统一命题、赛区独立评审，优秀队伍推荐国评争夺国一 / 国二全国大学生...。

### 2. 五大赛题方向（每年 6-8 道题，分本科 / 高职组）

1. **电源类**（新手友好、稳拿基础分）：直流稳压、逆变、MPPT、开关电源、宽压供电；硬件为主，算法简单。
2. ==**控制类**==（热门、人数最多）：智能小车、运动控制、云台、伺服、闭环 PID、机械执行机构；软硬结合。
3. **信号与仪器类**（难度高、冲国奖）：波形发生器、微弱信号采集、频谱分析、滤波、音频处理、FPGA 信号处理。
4. **射频 / 通信类**（门槛高）：无线收发、调制解调、测距、射频功放，对模电、电磁兼容要求极高。
5. **综合系统类**：多模块融合，嵌入式 + 传感 + 无线 + 上位机联动。

每道题分**基础要求（必拿分）**、**发挥要求（加分、冲奖）**，评审优先看基础功能是否全部实现。

### 3. 完整赛事流程

1. **赛前报名（5 月底截止）**：校内选拔→学校统一向赛区组委会报备，锁定队员，中途不可换人。
2. **备赛阶段（3-7 月，3-4 个月）**：模块训练、真题模拟、元器件储备、PCB 练习。
3. **正式竞赛（4 天 3 夜）**
    
    Day 1 8:00 统一发题 → 选题、定整体方案、采购缺件
    
    Day 2 硬件焊接、软件底层驱动编写
    
    Day 3 软硬件联调、数据测试、初稿写设计报告
    
    Day 4 全天调试、完善报告、收尾、20:00 准时封箱
1. **赛区评审（赛后 3-7 天）**：作品封存统一测评，现场实测指标、查阅设计报告；评出省一 / 省二 / 省三，省一择优推送全国复评。
2. **国评阶段**：全国专家二次评审，颁发国家一、二等奖证书。

### 4. 评分核心标准（总分 100）

1. **作品功能与实测性能（60 分）**：基础要求全完成拿 40 分；发挥指标达标、精度高、稳定性强拿剩余 20 分，是得分核心。
2. **设计报告（30 分）**：方案论证、原理图、PCB、测试数据、误差分析、创新点，书写规范直接拉开分差。
3. **创新、结构工艺（10 分）**：小型化、低功耗、原创算法、抗干扰设计、整洁模块化硬件。

## 二、赛前备赛核心注意事项

### （一）团队分工（3 人固定，避免内耗）

标准最优分工，赛前长期固定练习：

1. **硬件手**：原理图、PCB、焊接、电源、模拟电路、调试电路故障、元器件管理。
2. **软件手**：STM 32/FPGA 代码、驱动、PID、滤波、数据采集、串口通信、版本管理。
3. **文档测试手**：全程记录调试数据、绘制图表、撰写设计报告、测试所有指标、后勤物资统筹。
    
    禁止三人全都写代码 / 焊板子，会出现大量重复工作、进度混乱。

### （二）技术备赛重点

1. **硬件储备**
    
    - 熟练工具：AD 画 PCB、示波器、万用表、直流电源、信号源、电烙铁、热风枪。
    - 必练模块：稳压电源、运放信号调理、电机驱动、常用传感器（MPU 6050、光电、超声波）、无线模块（蓝牙 / WiFi）。
    - PCB 关键习惯：模拟地数字地单点共地、电源加粗、预留测试点、敷铜接地、分离强弱电，减少干扰玄学问题。
    
2. **软件储备**
    
    - 以 STM 32 为主，掌握 GPIO、ADC、定时器、中断、DMA、串口；PID、均值 / 卡尔曼滤波是控制类必考算法。
    - 代码模块化，驱动与业务逻辑分离；全程 Git 备份，每日存档，防止代码丢失、回滚失效。
    
3. **真题模拟（重中之重）**
    
    冲刺阶段至少完整模拟 1 次 **4 天 3 夜全真赛制**：断网独立完成、限时写报告、封箱自测，复刻赛场压力，暴露短板。

### （三）物资元器件准备（赛场不能网购，缺件直接崩盘）

1. **通用常备件**：0805 全系列电阻电容、电感、二极管、三极管、稳压芯片（AMS 1117、LM 2596）、运放 OP 07/OPA 2340、接插件、排针、洞洞板、铜柱、导线。
2. **主控储备**：STM 32 F 1/F 4 最小系统、FPGA 开发板、下载器、锂电池、升压 / 降压模块。
3. **工具耗材**：烙铁头、焊锡、助焊剂、杜邦线、绝缘胶带、扎带、热熔胶、万用表表笔、备用电源适配器。
4. **赛场禁用**：笔记本、平板、手机不能接入作品；成品工控机、完整成品模块受限，仅允许基础分立元件、通用芯片全国大学生...。

## 三、四天三夜赛场实操红线 & 避坑指南

### 1. Day 1 选题大忌（决定最终上限）

- ✅ 正确逻辑：优先选**团队模块储备最多**的题，不选看起来炫酷但完全没练过的射频 / FPGA 难题。
- ❌ 严禁：跟风抢热门控制题、盲目冲高难度信号题；**开赛第二天后禁止换题**，时间完全不够，大概率无法完成基础要求。
- 审题技巧：逐条标注基础要求指标，先保证全部达标，再规划发挥功能，不要本末倒置。

### 2. 硬件制作避坑（赛场 80% 翻车来自电路）

1. **共地！共地！共地**：主控、传感器、电机电源全部共地，否则 ADC 跳数、无线乱码、电机干扰单片机复位。
2. 电源分层：强电（电机）、弱电（主控）分开供电，加磁珠 / 电容滤波，防止大电流冲击芯片。
3. 焊接检查：上电前万用表测电源对地是否短路，避免一通电直接烧芯片。
4. 不要全靠洞洞板：关键模块赛前打好 PCB，洞洞板长线干扰极大，实测精度不达标扣分严重。

### 3. 软件调试保命规则

1. 每天睡前完整备份全部代码、原理图、PCB，电脑 + U 盘双备份，防止硬盘损坏丢失全部成果。
2. 核心参数全部用宏定义，方便现场快速修改；添加异常判断，传感器失效、电压过低自动报警，避免作品卡死无法完成测试。
3. 最后 12 小时**禁止大幅修改核心算法 / PID 参数**，只微调小参数，防止稳定系统直接失控。

### 4. 设计报告得分要点（极易丢分）

1. 必备章节：摘要、方案对比论证、系统总体框图、完整原理图、PCB 图、硬件电路说明、软件流程图、测试方案、实测数据表、误差分析、创新总结。
2. 实测数据必须真实：分多组不同工况记录，附带示波器截图、波形图，无数据直接扣大量分数。
3. 格式规范：图表编号清晰，公式完整；**全程不能出现学校、队员姓名标识**，封箱前仔细检查，违规取消成绩。

### 5. 时间分配铁律（不要最后一天赶报告）

- Day 1：方案定稿，硬件框架、软件底层搭建完成
- Day 2：硬件焊接完工，所有驱动代码调试通过
- Day 3：系统联调，完成 80% 测试数据，写完报告初稿
- Day 4：上午修复剩余 bug、补全所有指标测试；下午完善报告、排版打印；傍晚整机连续 2 小时稳定性拷机，20 点准时封箱

## 四、纪律、评审测试关键注意事项

### 1. 赛场纪律（违规直接取消资格）

1. 全程独立完成，禁止场外老师、往届学长远程指导、传递代码 / 电路方案；禁止使用手机查阅教程（赛区统一管控电子设备）。
2. 作品、报告、纸箱上不得出现校名、队员姓名、学校 logo 等标识，统一使用组委会发放编号。
3. 禁止携带完整成品整机、工控板、带程序存储的成品模块；程序必须烧录进作品芯片脱机运行，评审现场不能外接电脑下载程序全国大学生...。

### 2. 现场测评高分技巧

1. 拷机：封箱前连续通电运行 2 小时，无死机、无数据漂移，稳定性是评审第一关注点。
2. 提前准备测试演示流程：按题目指标顺序依次展示，主动给评委读出实测数值，配合示波器展示波形。
3. 故障预案：备用芯片、备用电源、备用传感器随身携带，测评现场硬件损坏可快速更换抢救成绩。

## 五、心态与健康提醒（4 天 3 夜体力消耗极大）

1. 前两日保证 6 小时睡眠，不要连续通宵，第三天适度熬夜，最后一天可通宵收尾。
2. 三餐规律，备好饮用水、零食，避免低血糖头晕导致调试失误。
3. 团队矛盾处理：分工明确，出现分歧以**能否完成基础指标**为判断标准，不要纠结花哨创新功能，稳定完成基础要求是拿奖底线。

## 六、获奖与后续价值补充

1. 省三 / 省二：完成基础要求即可拿到；省一需要发挥指标达标、报告完整；国奖要求稳定高性能 + 可落地创新点。
2. 升学：保研综测大幅加分，电子、自动化导师高度认可，复试核心项目；
3. 就业：硬件工程师、嵌入式、电源、测试岗位简历核心竞争力，远超课程项目。
