# 电子设计竞赛完整知识 & 技能清单（国赛 / 省赛通用，分模块）

## 一、硬件基础（核心，所有赛道必学）

### 1. 模电（重中之重）

- 核心电路：运放（同相 / 反相、差分、仪表放大、积分微分、有源滤波）、电源（线性稳压 LM 1117、低压差 LDO、DC-DC 升降压）、整流滤波、三极管 / MOS 管驱动、恒流恒压电路、差分放大、阻抗匹配
- 信号处理：低通 / 高通 / 带通 / 陷波滤波器、交直流耦合、噪声抑制、屏蔽接地、分压偏置
- 功率电路：电机驱动 H 桥、继电器、可控硅、功率 MOS、散热设计
- 测量基础：万用表、示波器看懂波形，会测增益、带宽、纹波、失真

### 2. 数电

- 逻辑门、触发器、时序电路、译码器、计数器、移位寄存器
- AD/DA 原理、采样定理、阻抗匹配
- 电平转换：3.3 V/5 V 互转、上拉下拉电阻、OC 门
- 基础时序：I 2 C、SPI、UART 底层逻辑

### 3. 电路识图与 PCB

- 看懂原理图，能独立画原理图（Altium Designer 立创 EDA）
- PCB 布线规则：电源地分割、模拟数字地单点接地、高频走线短粗、差分等长、安规、去耦电容布局
- 元器件选型：电阻电容封装、功率余量、温漂、耐压、带宽匹配
- 焊接：0402/0603 贴片、QFP 芯片、排针、飞线修复、焊盘补线

## 二、单片机 / 嵌入式编程（所有题目必考）

### 主流主控

1. **STM 32（首选，电赛 90% 队伍用）**
    
    - 外设：GPIO、EXTI 外部中断、定时器（PWM 输出、输入捕获、正交解码）、ADC 多通道采集、DAC 输出
    - 通信：USART 串口、I 2 C（OLED、EEPROM、传感器）、SPI（屏幕、AD、无线模块）、CAN 总线
    - 高级功能：DMA、中断优先级、定时器中断、低功耗、看门狗
    - 开发：标准库 / HAL 库、Keil MDK、调试器 ST-Link、逻辑分析仪抓波形
    
2. 辅助：51 单片机（简单控制题）、MSP 430（低功耗题）、FPGA（高频、数字信号、图像处理赛道）

### 必备编程技能

- C 语言基础：指针、结构体、数组、中断服务函数、定时器调度
- 外设驱动模板：屏幕 LCD/OLED、电机、编码器、各类传感器
- 滤波算法：滑动平均、一阶低通滤波、中值滤波（处理 ADC 噪声）
- PID 闭环控制（电机速度 / 位置、稳压稳流、小车平衡核心）
- 串口通信：上位机数据收发、串口屏交互、蓝牙 WiFi 透传

## 三、传感器与执行器（高频出题器件）

### 传感器

- 距离：红外对管、超声波 HC-SR 04、激光测距、光电编码器
- 姿态：MPU 6050/MPU 9250 陀螺仪加速度计，姿态解算（卡尔曼 / 互补滤波）
- 电学检测：电压电流采集、互感器、铂电阻 / 热敏电阻测温
- 视觉：OV 7670、摄像头灰度识别、线性 CCD（循迹、分拣题）
- 环境：光敏、麦克风声音采集、压力薄膜传感器

### 执行器

- 电机：直流减速电机、步进电机、舵机 SG 90、无刷电机
- 功率器件：电磁继电器、电磁阀、LED 点阵、声光报警
- 无线：蓝牙 HC 05、ESP 8266/ESP 32 WiFi、NRF 24 L 01 无线收发

## 四、算法与控制（拿高分关键）

1. **控制算法**
    
    - PID（位置式 / 增量式、积分限幅、微分先行）
    - 平衡控制：倒立摆、两轮自平衡小车
    - 运动控制：速度闭环、位置闭环、加减速控制
    
2. **信号处理算法**
    
    - FFT 傅里叶变换（频谱分析、波形识别类题目高频）
    - 数字滤波、波形整形、峰值检测、相位检测
    
3. **识别 / 路径算法**
    
    - 灰度阈值分割、边缘检测、简单图像特征提取
    - 小车循迹、避障、最短路径、简单迷宫算法
    
4. 数据处理：多点校准、线性拟合、量程自动切换

## 五、FPGA / 数字信号专项（高频独立赛道：信号类、射频、图像）

- Verilog HDL 基础：时序逻辑、组合逻辑、状态机
- IP 核调用：PLL 锁相环、FIFO 缓存、ADC 驱动、VGA 显示
- 高速信号、DDS 信号发生器、数字滤波、FFT 硬件加速
- 适用题目：波形产生、频谱分析仪、数字示波器、图像处理

## 六、电源与电磁兼容 EMC（扣分重灾区）

- 多路稳压电源设计：±12 V、5 V、3.3 V、可调输出
- 纹波抑制、防反接、过流 / 过压 / 短路保护电路
- 接地分层：模拟地、数字地、功率地单点共地
- 干扰处理：电机加续流二极管、电源磁珠、屏蔽线、电容退耦

## 七、工具实操技能（比赛全程要用）

### 软件工具

1. 电路：立创 EDA/AD 画原理图 PCB
2. 编程：Keil MDK（STM 32）、Vivado（FPGA）、STM 32 CubeMX 图形配置
3. 仿真：Multisim（模电预仿真）、Proteus（简单单片机仿真）
4. 上位机：串口助手、Python 上位机绘图、LabVIEW（部分学校）
5. 文档：Word 写设计报告、Visio 画流程图、Origin 画波形曲线

### 硬件仪器操作（现场调试必备）

- 数字万用表：测电压电流电阻通断
- 示波器：测波形、幅值、频率、纹波、捕捉瞬态信号
- 直流稳压电源：多路输出、限流保护
- 信号发生器：输出正弦方波三角波，测试放大滤波电路
- 逻辑分析仪、电桥（测电容电感）

## 八、报告与工程规范（直接影响评奖）

1. 设计报告标准结构：方案论证、硬件电路、软件流程、测试数据、误差分析、实物照片
2. 数据记录：测试表格、波形截图、误差来源分析、改进方案
3. 文档规范：原理图编号、元器件清单 BOM、代码注释、流程图

## 九、不同赛道侧重区别

1. **控制类（小车、平衡车、倒立摆）**
    
    重点：STM 32、PID、电机驱动、编码器、姿态解算、机械结构
1. **电源类（稳压、逆变、无线充电）**
    
    重点：DC-DC / 开关电源、模电功率电路、EMC、环路补偿
2. **信号与射频类（波形发生器、频谱分析仪）**
    
    重点：运放电路、FPGA、DDS、FFT、阻抗匹配
3. **仪器仪表类（测温、测频、多功能检测）**
    
    重点：高精度 AD 采集、滤波、校准、显示交互
4. **人工智能 / 视觉类**
    
    重点：摄像头、图像二值化、特征识别、ESP 32/STM 32 图像处理

## 十、加分软实力

1. 机械装配：3D 打印简单支架、小车底盘固定、结构减震
2. 故障排查：快速定位虚焊、电源短路、干扰、程序卡死问题
3. 团队分工：硬件、软件、报告三人高效配合
4. 赛前备库：常用模块驱动代码、经典电路模板、PID 通用程序
