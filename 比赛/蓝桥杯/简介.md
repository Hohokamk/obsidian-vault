# 一、蓝桥杯是什么

**全称：蓝桥杯全国大学生软件和信息技术专业人才大赛**

是工信部相关、入选**全国普通高校学科竞赛排行榜**的国家级 IT 类权威竞赛，2010 年创办，面向全日制研究生、本科、高职学生，分**校赛→省赛→国赛**三级选拔，侧重编程、硬件、AI、设计、电子开发实战，获奖对保研、求职、综测加分含金量很高。

## 参赛组别划分（软件 / 电子 / AI 赛道）

1. **研究生组**：仅限硕士、博士
2. **大学 A 组**：985/211 本科
3. **大学 B 组**：普通一本、二本本科
4. **大学 C 组**：民办本科、专科
5. **职业院校组**：高职高专专属

# 二、六大主赛道（第十七届 2026 最新完整赛项）

## 1. 软件赛（计算机学生最热门，个人赛为主）

核心考算法、编程、开发、网络安全

1. C/C++ 程序设计（算法核心赛道，参赛人数最多）
2. Java 软件开发
3. Python 程序设计
4. Web 应用开发（可组队）
5. 软件测试
6. 网络安全

## 2. 电子赛（硬件 / 嵌入式 / 微电子方向）

硬件实物、电路、FPGA、物联网开发

1. 单片机设计与开发（STM 32/51）
2. 嵌入式设计与开发
3. EDA 设计与开发（芯片电路）
4. 物联网设计与开发
5. FPGA 设计与开发
6. 5 G 全网规划与建设

## 3. 人工智能赛（AI 大模型、数据分析新赛道）

1. 人工智能应用
2. 智能体开发（Agent、提示词、RAG 知识库）
3. 数据分析与可视化

## 4. 数字科技创新赛（硬件创新、RISC-V 国产芯片）

1. 数字科技应用创新
2. RISC-V 应用创新（国产开源芯片）
3. 智能装备数字化建模

## 5. 视觉艺术设计赛（美术、数媒、设计类，作品提交）

共 11 个细分方向：

海报设计、文创设计、UI 交互设计、插画设计、信息可视化、视频设计、动画设计、AIGC 微短剧创意、环境艺术设计、工业产品设计、包装设计

## 6. 专项赛（独立附加赛道，免费参赛）

中数杯 AIGC 数字内容创意设计大赛

# 三、简单选赛道建议

- 计算机 / 软件、想冲算法：**C/C++ 程序设计**（性价比最高）
- 喜欢 Python、数据分析：**Python 程序设计 / AI 数据分析**
- 硬件、自动化、电类专业：**单片机 / 嵌入式 / FPGA**
- 网安专业：**网络安全**
- 数媒、设计、美术：**视觉艺术设计赛**
- 想做大模型应用： **智能体开发**
