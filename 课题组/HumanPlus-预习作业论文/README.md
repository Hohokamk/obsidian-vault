## 一、2026 版预习作业原文要点

联系之前建议完成 4 项功课：

1. **阅读 4 篇论文**（团队 2 篇 + 外部 2 篇，见下），并思考：
   - 你觉得这里面最困难的地方是什么？
   - 你希望在什么问题上开展探索？
2. **想一想自己最擅长/最不擅长、最喜欢/最不喜欢的事情**（要求写得具体）。
3. **想一想为什么想来加入实验室**（要有明确期待：出国/读研/高水平论文/完整项目经历……）。
4. **想一想以后要做什么**（本科毕业：保研、考研、出国、参加工作、创业）。

## 三、四篇论文串起来的“团队思路”（招生帖原文）

利用无扰化穿戴式人体动作捕捉（LIP / TIC 解决的正是“宽松衣物 + IMU 漂移/标定”问题）→ 结合第一视角画面（EgoHumanoid 的人到人形机器人同构迁移、Nymeria 的第一视角大规模数据）→ 为具身智能模型训练提供源源不断的真实人类活动数据 → 最终实现具身智能模型的 GPT 突破。
