# ROS2 麦轮 AGV 复刻笔记

相关：[[准备阶段]]、[[注意事项]]、[[元件核查清单]]、[[整车器材清单]]

## 一、这个项目是什么

三层结构：**STM32 下位机**负责电机、编码器、IMU 等实时控制，**RDK X3 上位机**跑 ROS2 做建图导航，中间用串口通信，两者之间是这块自研驱动板。

作者的物料清单（古月居）：

- 主控：STM32F103ZET6（反客科技系统板）、ESP32C3Mini、RDK X3
- 传感器：DHT11、USB 免驱摄像头、电机霍尔编码器、JY62（IMU）、PS2 手柄接收器
- 结构件：四个麦克纳姆轮、3D 打印件、铜柱、MF83ZZ 3×8×3 法兰轴承、M3 平头螺丝若干
- PCB 器件：电阻本、电容本、SS8550、无源直插蜂鸣器、降压芯片（作者写 MPS2315S，BOM 写 MP2225GJ）
- 开发环境：上位机 Ubuntu 22.04 虚拟机，RDK X3 Ubuntu 20.04

## 二、整体路线

阶段按顺序推进，不设时间表，做到哪算哪。

### 阶段 1：核对设计

打开立创EDA 工程看原理图，把四件事定下来：ESP32 到底用 C3 还是 S3、D2 的 TVS 型号、降压芯片型号、电池电压。产出是一份你自己确认过的物料表。

### 阶段 2：备料

元件清单见下方"本地资料"里的采购清单表。工具至少要恒温焊台、热风枪、含铅锡丝、助焊剂、镊子、万用表。结构件也要同时下单，不然焊完只能干等。

### 阶段 3：焊接与点亮

顺序是贴片阻容 → 芯片 → 插件 → 模块。每焊完一段先测短路，再分段验证 5V 和 3.3V。

### 阶段 4：单板功能验证

一个外设一个外设地跑通，不要一起上：先只上电测电压，再烧 LED 闪灯确认下载，然后依次是串口回环、电机 PWM、编码器读数、JY62、PS2 手柄。这一步跑完，硬件就算过关了。

### 阶段 5：机械装配

原项目没给 3D 文件，结构件要自己建模。注意麦轮 45° 辊子方向和左右 AB 型，还有电池配重与走线。

### 阶段 6：上下位机通信

先定串口协议（帧头、长度、校验），下位机上传编码器、IMU、电压，接收速度指令。上位机先写一个能看数据的节点就够，不要一上来做全功能。

### 阶段 7：ROS2 上层

按顺序推进：搭工作空间 → urdf 和 tf → 发布 odom → 雷达 + Cartographer/Gmapping 建图 → Navigation2 导航 → 键盘和手柄遥控节点。

### 阶段 8：联调与演示

整车跑通，录像留存，对照作者的演示视频看差在哪。

## 六、为什么 BOM 里有两个 ESP32C3

不是两个模块，是**一个模块的两排座**。

- BOM 里 U7 / U8 的封装写的是「排母」，元件库符号名是 `排母1x8`，不是 ESP32 模块。
- 板上这两排各 8 个孔，针距 2.54mm，两排之间 15.1mm，合起来正好是一个 2×8 插座。
- 一块 ESP32-C3 mini 是 2×8 = 16 针，所以要用两块 1×8 母座分别接两排。
- U7 / U8 不在嘉立创 SMT 代贴清单里，要自己买两块 1×8 母座；JY62 的 H3 / H4 母座（C124415）已经由嘉立创代贴。
- 作者的项目简介写的是「ESP32C3mini 最小系统」，是单数。
- JY62 也是同一套命名方式：H3 / H4 是两块 1×6 母座，两排相距 13.1mm，插一块 2×6（12 个半孔）的 JY62。

![[esp32_2x8_说明.png|640]]

仍然要注意：板子丝印写的是 `ESP32S3`，BOM 写的是 `ESP32C3`。机械上两种模块可能都能插进这个 2×8 座，但**针脚定义不一定一样**，插之前对照原理图和模块丝印确认 5V / GND / UART 的位置。
