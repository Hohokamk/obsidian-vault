## 九、MG513 与电池：先确认

- [x] 看电机铭牌确认电压：`MG513P30_12V` 这类是 **12V**；如果是 6V 版本，另算
- [x] 12V 电机选 **3S 11.1V** 电池，2S 7.4V 会明显变慢
- [ ] 3S 满电是 12.6V，板子原设计是 2S 7.4V，上 3S 前要改 C2、C16 的耐压
- [ ] C2（10uF，接 VCC+）：10V 换成 25V
- [ ] C16（22uF，接 VCC+）：6.3V 换成 25V；这一颗用 6.3V 连 2S 都危险
- [ ] D2：2S 用 SMAJ12A；3S 建议 SMAJ15A 或 SMAJ18A
- [ ] AMS1117 的 5V 输出主要给 RGB 灯带；3S 时它发热大，RGB 大电流不要走它
- [ ] 15AS 是单路驱动，一个电机一个，4 个；不要两个电机并一个驱动做里程计
- [ ] 15AS 供电 9–36V，3S 正好；2S 7.4V 低于推荐下限，带载容易发热
- [ ] 15AS 控制：PWM + IN1 + IN2，3.3V 兼容；5VO 不要并到板子的 5V
- [ ] P1 的 STBY 对 15AS 不用接（15AS 没有 STBY 脚）
- [ ] 电机回路加 20A 保险丝，正反转切换前先刹车 0.1s 以上

## 十一、电机接口与驱动选型

板上每个电机给 **3 根控制线**：1 路 PWM + 2 路方向（IN1 / IN2）。这是标准 H 桥接口，所以双路、四路驱动都能用。

| 电机  | PWM        | IN1       | IN2       | 编码器              |
| --- | ---------- | --------- | --------- | ---------------- |
| A   | A15（U13-1） | E8（U2-1）  | E9（U2-2）  | A6 / A7（U13-3/4） |
| B   | B3（U13-2）  | E10（U2-3） | E11（U2-4） | C6 / C7（U13-5/6） |
| C   | B6（U14-1）  | E12（U1-1） | E13（U1-2） | A0 / A1（U14-3/4） |
| D   | B7（U14-2）  | E14（U1-3） | E15（U1-4） | C8 / C9（U14-5/6） |
|     |            |           |           |                  |
|     |            |           |           |                  |

编码器分组以固件为准；PWM 和 IN1/IN2 的对应关系按上表接即可。

### 选型要求

- 每路持续电流 ≥5A，峰值 ≥10A（MG513 堵转电流通常 5A 以上）。
- 供电电压覆盖 3S 满电 12.6V（9–16V 范围最稳）。
- 控制逻辑 3.3V 兼容。
- 不要选 TB6612（1.2A 持续 / 3.2A 峰值）或 L298N（2A），带 MG513 容易烧。

### 可选方案

| 方案 | 数量 | 优点 | 缺点 |
| --- | --- | --- | --- |
| 15AS 单路 ×4 | 4 | 你已经了解，15A 余量足 | 体积大，4 块 55×55×25mm |
| AT8236 双路模块 ×2 | 2 | 每块 2 颗 AT8236，共 4 路；体积小、便宜 | 单路 4A 持续 / 6A 峰值，余量比 15AS 小 |
| 双路 ≥10A ×2 | 2 | 走线少、体积小 | 需要确认每路电流 |
| 四路 ≥10A ×1 | 1 | 最紧凑 | 单块损坏要整块换 |

AT8236 单颗芯片是单通道：5.5–36V，4A 持续、6A 峰值，ESOP-8。MG513 12V 堵转约 5A，峰值 6A 能扛住，但余量不大；经常重载或堵转就选更大电流的模块。买模块时确认是“双路 AT8236”（每块两颗芯片），两块才是 4 路。

### 接线注意

- 驱动 VM 接电池 11.1V，GND 与板子共地。
- 驱动的 5V 输出（如果有）不要并到板子 5V。
- 板子的 STBY（P1）在驱动没有 STBY 脚时可以不接；用 TB6612 类驱动时 STBY 要拉高。
- 电机线先接好再上电，正反转切换前先刹车 0.1s。

## 十、供电架构

核心原则：**电池电压进驱动板，5V 不进驱动板。** 板上已经有 MP2225 降压。

```
3S 11.1V 电池
  └─ 总开关 KCD11 + 20A 保险丝
       ├─ 驱动板 VCC+（U17 XH2.54-2P 或 U9 T 型插头）
       │    └─ 板载 MP2225（4.5–18V 输入）→ +5V
       │         └─ STM32 / ESP32 / DHT11 / 蜂鸣器 / 编码器
       ├─ 4× 15AS 电机驱动（VM / GND，9–36V）
       └─ 5V/5A 降压模块 → RDK X3（5V 输入）
            └─ 可选：RGB 灯带 5V
```

- [ ] 驱动板 VCC+ 接电池 11.1V，不要接 5V
- [ ] RDK X3 单独用一个 5V/5A 降压模块，不要从驱动板的 +5V 取电
- [ ] 4 个 15AS 直接接电池电压
- [ ] 所有电源负极（电池、驱动板、15AS、降压模块、RDK X3）共地
- [ ] 15AS 的 5VO 不并入驱动板 5V
- [ ] 5V 降压模块输出加 100uF 以上电解 + 0.1uF 陶瓷
- [ ] 电池输入端加 20A 保险丝和总开关

### 为什么驱动板不能喂 5V

- MP2225 是降压型，5V 进、5V 出没有压差，稳不住 5V。
- AMS1117-5.0 需要至少约 6.5V 输入，5V 进只能输出 3.7V 左右。
- 所以 VCC+ 必须给电池电压，5V 由板上自己产生。

### 为什么 RDK X3 要单独降压

- 板载 MP2225 是 5A，但配套电感只有 3.6A 额定，RDK X3 峰值电流会顶到上限。
- RDK X3 和电机共用一条 5V 会互相干扰，电机启动时电压跌落容易把板子拉重启。
- 单独 5V/5A 降压模块，输入接电池，输出只给 RDK X3。

### 3S 时 AMS1117 的注意

- AMS1117 输入接 VCC+，3S 12.6V 时压差 7.6V，RGB 灯带电流稍大就会很烫。
- RGB 灯带建议直接从 5V 降压模块取电，不走 AMS1117。
