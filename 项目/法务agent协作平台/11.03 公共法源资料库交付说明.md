## 交付范围

- 公共法源 Schema、稳定文档 ID、不可变版本和当前版本指针。
- 法规与案例 Markdown 清单校验、hash 校验、BlobStore 原文保存和 PostgreSQL 元数据入库。
- 7,804 份仓库快照全量导入，导入任务可重放且不会回滚旧版本。
- 只读目录、版本、固定原文、关键词检索和快照统计 API。
- 管理员可读的维护状态 API，返回任务状态、数据量和定时任务，不暴露采集凭据或诊断日志。
- Web “律所知识库 → 法律与案例库”目录浏览、分类筛选、历史版本和固定原文预览。
- Agent `law_search` 只读工具：返回固定版本、来源、元数据和受限片段，不提供采集或写入能力。
- `CASE_RETRY` 和跨平台采集进程树终止修复，纳入当前工作树测试。

### 真实 API

通过 `http://127.0.0.1:5173` 的前端代理登录测试账号后实际调用：

- `GET /api/v1/legal-corpus/stats`：200，返回全量法规和案例计数、`KEYWORD_V1`。
- `GET /api/v1/legal-corpus/search?q=行政许可&corpus=law&limit=5`：200，返回《中华人民共和国行政许可法》等 5 条固定版本结果。
- `GET /api/v1/legal-corpus/maintenance`：管理员返回 200，普通成员路径已有 403 回归测试。
- 返回结果包含 `revisionId`、SHA-256、来源 URL、标题、效力/案例元数据和片段；没有返回原始 front matter、采集路径或凭据。

真实 API 验收第一次发现旧 API 进程仍运行旧代码，统计返回 `NOT_ENABLED` 且新接口 404。重启本项目的 Windows API 进程后，上述接口均通过；这再次说明“数据库已迁移”不等于“运行进程已更新”。
