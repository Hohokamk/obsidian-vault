## 1. 这次复核后的主要修正

上一版总体路线正确，但本次逐条核验后作了以下修正：

1. **STM32CubeG4固定到可复现标签，而不是直接跟随`master`。**  
   当前官方仓库存在`v1.6.3`标签；项目建立基线时应记录所用标签或提交号，避免不同同学下载到滚动更新的不同代码。

2. **确认NUCLEO-G474RE官方确实提供SPI DMA示例。**  
   官方目录包含`SPI_FullDuplex_ComDMA_Master`和`Slave`，学生不必从零猜测DMA初始化与回调。项目只需从“双板全双工”例程抽取SPI TX DMA、回调和错误处理，再改成单向驱动移位寄存器。

3. **KiCad自动化以官方`kicad-cli`为硬基线。**  
   KiCad 10.0文档可直接运行ERC、DRC、Gerber和钻孔导出。KiBot作为第二层便利工具；KiBot 1.9.x支持KiCad 10，但部分原生variant能力仍标注为实验性，项目不应把variant功能作为硬性验收。

4. **修正可重构超表面论文链接。**  
   2019年16×16编码超表面论文的正确链接为`Energies 12(23), 4488`，不是上一版索引中的错误地址。

5. **进一步区分“LED二值导通”与“1 bit相位状态”。**  
   LED只显示控制码。真实1 bit天线状态是两个不同复响应，理想情况下可近似为`+1/-1`，不能把随机开关掩膜直接解释成波束扫描。

6. **TLC6C598作为核心低电流原型器件，TPIC6B595只作对照。**  
   TLC6C598逻辑供电范围覆盖3.3 V；TPIC6B595通常按5 V逻辑工作，直接由3.3 V MCU驱动需要认真核对门限或增加AHCT缓冲。

## 4. 使用原则

每个外部代码资源分为四级：

- **A级：官方、可直接作为配置和API依据**  
  ST、TI、KiCad、Python官方文档和官方仓库。
- **B级：官方示例，可抽取结构后改造**  
  STM32CubeG4 SPI DMA、UART和DMA示例。
- **C级：成熟开源库，可用于工具层**  
  pySerial、pytest、KiBot、DEAP、pymoo。
- **D级：第三方学习示例，只能对照**  
  Arduino TLC5940库、个人阵列代码等。

任何D级代码都不能直接作为硬件额定值、时序或最终正确性的依据。
