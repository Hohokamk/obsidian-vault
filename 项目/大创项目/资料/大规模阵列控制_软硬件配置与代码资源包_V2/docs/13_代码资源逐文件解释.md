## 3. `host/protocol.py`

### 负责

- 命令编号；
- 状态码；
- CRC；
- 帧编码；
- 完整帧解码；
- 串口流增量解析。

### 不负责

- 串口打开；
- 图案；
- 通道映射；
- 重试；
- LED。

### 关键测试

```python
assert crc16_ccitt(b"123456789") == 0x29B1
assert decode_frame(encode_frame(Command.PING, 1)).sequence == 1
```

### 拓展

- 增加设备信息结构；
- 增加批量图案；
- 协议版本兼容；
- 增加时间戳；
- 增加配置CRC。

修改帧格式时必须同步修改：

- Python；
- C；
- 测试；
- 协议文档。

## 4. `host/patterns.py`

### 负责

- 加载YAML；
- 生成空、全亮、单点、棋盘格、边框、随机；
- 逻辑到物理映射；
- bit打包；
- 解包；
- 保存/读取图案。

### `pack_pattern`

流程：

```text
二维逻辑矩阵
→ 拉平
→ 按mapping放入physical
→ 可选逻辑反相
→ 每8位打包
→ bytes
```

### 常见修改

#### 蛇形

不改函数，生成explicit mapping：

```text
第0行左→右
第1行右→左
...
```

#### 模块旋转

由脚本把模块局部坐标旋转后生成256项映射。

#### 字节反序

应增加明确的“wire byte order”层，而不是把mapping和字节顺序混在一起。

当前代码主要完成physical ascending字节顺序；实物证明确需反序时，应新增配置和测试，不直接`payload[::-1]`散落在CLI中。

## 5. `host/device.py`

### 负责

- 打开串口；
- 序列号；
- 写帧；
- 读流；
- 找匹配ACK；
- 重试；
- 超时；
- 往返时间。

### 当前限制

- 单线程事务；
- 每次事务前清空输入；
- 不支持设备主动事件；
- 不支持高速流水线多个未决命令；
- 不支持批量ACK。

适合8/16/64/256基础控制。

### 高速拓展

需要：

- 独立接收线程；
- pending字典；
- 多个sequence并发；
- 批量上传；
- 设备主动错误事件；
- 不随意清空输入缓存。

## 12. `firmware/array_driver.c`

### `latch_pulse`

目前用GPIO和NOP。实际必须测脉冲宽度。

改进方案：

- DWT周期延时；
- 定时器单脉冲；
- LL GPIO；
- 明确纳秒/微秒时间。

### `spi_really_finished`

当前是跨版本骨架：

```c
#ifdef SPI_FLAG_TXC
...
#else
BSY
#endif
```

必须按：

- RM0440；
- 当前HAL；
- 所用SPI实例；
- AN5543；

核对。它是刻意留下的硬件适配点，不是最终可直接提交的实现。

### `array_driver_submit`

检查：

- 指针；
- 长度；
- 状态；
- 启动DMA；
- 失败进入安全错误。

当前使用调用者缓冲指针，调用者必须保证DMA期间数据不变。更安全的做法是驱动拥有front buffer。

### `array_driver_poll`

等待SPI结束后锁存。后续加入：

- 超时；
- readback；
- OE策略；
- 下一帧；
- 多链同步。

## 13. `firmware/protocol.c/h`

实现：

- CRC16；
- 完整帧解码；
- 长度；
- SOF；
- 状态码。

当前不实现串口流缓存和命令分发。

MCU端还需：

```text
UART DMA/中断收字节
→ 环形缓冲
→ 找SOF
→ 等完整长度
→ decode
→ command dispatch
→ ACK encode
```

推荐先写简单定长8/16路，再升级通用流解析。

## 18. 接入STM32工程的最小步骤

1. CubeMX创建NUCLEO-G474RE；
2. 开UART；
3. 开SPI TX DMA；
4. 配LATCH/OE/CLR；
5. 生成；
6. 先运行官方改造的1 B发送；
7. 复制`array_driver.*`；
8. 修改引脚；
9. 初始化结构；
10. 转发HAL回调；
11. 主循环调用`array_driver_poll()`；
12. 8路；
13. 2 B；
14. 8 B；
15. 32 B。

不要在第一次接入时同时加入协议、双缓冲、UART DMA、视觉和1024路。
