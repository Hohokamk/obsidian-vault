# 03 驱动器件、原理图与级联实验

## 1. 主线器件：TLC6C598

产品页：

<https://www.ti.com/product/TLC6C598>

数据手册：

<https://www.ti.com/lit/ds/symlink/tlc6c598.pdf>

官方确认的关键能力：

- 8路串入并出；
- 移位寄存器和存储寄存器分开；
- 3～5.5 V逻辑供电；
- 高电平输入最低2.4 V；
- 低电平输入最高0.7 V；
- 低侧开漏DMOS；
- 40 V输出额定；
- 5 V逻辑下每路50 mA连续能力；
- 10 MHz额定串行时钟测试条件；
- 内置热关断；
- 慢输出边沿有助于降低EMI；
- 16脚TSSOP。

本项目只用3～5 mA/路，远低于绝对驱动能力，但仍要测总功耗、导通电阻和温升。

## 2. 引脚功能

| 引脚 | 作用 | 本项目连接 |
|---|---|---|
| VCC | 逻辑电源 | 3.3 V，旁边0.1 μF |
| GND | 地 | 完整地平面 |
| SER_IN | 串行数据输入 | MCU MOSI或上一级SER_OUT |
| SRCK | 移位时钟 | MCU SPI SCK |
| RCK | 锁存时钟，上升沿 | MCU独立GPIO |
| G | 输出使能，低有效 | MCU GPIO + 外部上拉 |
| CLR | 清零，低有效 | MCU GPIO +安全电阻 |
| SER_OUT | 串行输出 | 下一级SER_IN或测试点 |
| DRAIN0..7 | 低侧输出 | LED阴极或负载接口 |

注意：

- `G=高`时所有输出关闭；
- `CLR=低`清除寄存器；
- LED阳极经限流电阻接VLOAD；
- LED阴极接DRAIN；
- 不可把DRAIN当成高侧电压输出。

## 3. 单路LED计算

电路：

```text
+5V ─ R ─ LED ─ DRAINx
                    │
                 内部DMOS
                    │
                   GND
```

电流近似：

\[
I \approx
\frac{V_{\mathrm{LOAD}}-V_F-I R_{\mathrm{DS(on)}}}{R}
\]

由于\(R_{\mathrm{DS(on)}}\)与电流、VCC和温度有关，最初可以忽略后选680 Ω，再实测。

例：

```text
VLOAD = 5 V
红LED VF = 2.0 V
R = 680 Ω
```

粗略：

\[
I\approx\frac{5-2}{680}\approx4.4\ \mathrm{mA}
\]

在3.3 V逻辑供电下，驱动器导通电阻比5 V供电高一些，但在4 mA时压降仍远小于680 Ω上的压降，适合安全原型。

## 4. 去耦与安全电阻

每颗：

- VCC到GND：0.1 μF X7R，离引脚尽量近；
- 2～4颗一组：1～10 μF；
- 64路板入口：47～220 μF，最终按实测；
- G/OE：10 kΩ上拉到3.3 V，MCU未工作时关闭；
- RCK：10 kΩ下拉，避免浮动锁存；
- SRCK：可10 kΩ下拉；
- CLR：根据希望的上电状态设计，推荐硬件保持清零，再由MCU释放；
- MCU端SCK、MOSI、RCK预留22～100 Ω串联电阻。

## 5. 8路面包板实验

### 5.1 不连接LED前

1. 核对封装1脚；
2. 万用表测VCC-GND无短路；
3. 只上3.3 V；
4. 测VCC；
5. G保持高；
6. CLR拉低再拉高；
7. 逻辑分析仪接SER_IN、SRCK、RCK、G、SER_OUT；
8. 发送`0xA5`；
9. 确认8个时钟；
10. 确认RCK只在发送后上升。

### 5.2 连接一个LED

- 先只接DRAIN0；
- 电源限流设20 mA；
- 发送只有一位为1的图案；
- 若不亮，检查输出逻辑方向和LED极性；
- 测LED电流。

## 6. 16路级联

连接：

```text
MCU MOSI → U1 SER_IN
U1 SER_OUT → U2 SER_IN
U1/U2共用SRCK、RCK、G、CLR
U2 SER_OUT → 测试点
```

发送两字节时，先发送的字节通常被继续推向链末端。必须实测：

```text
[byte0, byte1]
```

最终哪个字节控制U1、哪个控制U2。

测试：

```text
0x0001
0x0080
0x0100
0x8000
0xAAAA
0x5555
```

## 7. SER_OUT回读

### 7.1 逻辑分析仪法

- 在发送新帧时观察末端SER_OUT；
- 末端输出的通常是被推出的旧数据；
- 连续发送已知帧A、B、C；
- 根据链深度分析回读延迟；
- 验证没有漏位和重复位。

### 7.2 MCU回读法

将末端SER_OUT接MISO或GPIO：

- 若使用全双工SPI，发送同时接收；
- 接收数据表示链中被推出的旧帧；
- 延迟一帧后与期望旧帧比较；
- 统计位错误。

这比只看LED更适合长链压力测试。

## 8. 64路模块结构

一块板8颗驱动器：

```text
JIN
 ├─ SER_IN → U1 → U2 → ... → U8 → SER_OUT/JOUT
 ├─ SRCK共同
 ├─ RCK共同
 ├─ G/OE共同
 └─ CLR共同
```

建议连接器分两组：

### 控制级联

```text
GND
SER_IN
SRCK
RCK
G/OE
CLR
SER_OUT
3V3_LOGIC（可选）
```

### 负载供电

```text
VLOAD_5V
GND
```

不要让VLOAD通过细控制排线串过所有模块。

## 10. 对照器件：TPIC6B595

<https://www.ti.com/product/TPIC6B595>

<https://www.ti.com/lit/ds/symlink/tpic6b595.pdf>

用途：

- 比较更高电流驱动；
- 理解5 V逻辑和3.3 V MCU接口；
- 未来较大偏置电流可能使用。

关键风险：

- VCC通常4.5～5.5 V；
- 输入高电平门限必须按数据手册核对；
- 不可想当然直连3.3 V；
- 可使用SN74AHCT125等TTL兼容缓冲；
- 更高电流意味着更严格的热和电源设计。
