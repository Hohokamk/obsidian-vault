# 14 资源下载、本地归档与许可证

## 1. 为什么要本地归档

项目周期超过一年，网页、GitHub默认分支、软件版本和数据手册可能变化。必须保存“用过的版本”，否则后续无法复现。

建议目录：

```text
external/
├── st/
│   ├── STM32CubeG4/
│   ├── UM2505.pdf
│   ├── RM0440.pdf
│   ├── STM32G474RE_datasheet.pdf
│   ├── AN5543.pdf
│   └── AN1709.pdf
├── ti/
│   ├── TLC6C598_datasheet.pdf
│   ├── TPIC6B595_datasheet.pdf
│   └── TLC5940_datasheet.pdf
├── kicad/
│   └── version.txt
├── papers/
│   └── bibliography.md
└── SOURCES.md
```

不要把不允许再分发的整本商业书籍放入公开仓库。

## 2. 克隆官方代码

### STM32CubeG4

```bash
git clone --recursive --shallow-submodules --depth 1 \
  --branch v1.6.3 \
  https://github.com/STMicroelectronics/STM32CubeG4.git \
  external/st/STM32CubeG4
```

保存：

```bash
cd external/st/STM32CubeG4
git rev-parse HEAD > ../STM32CubeG4_commit.txt
git describe --tags --always > ../STM32CubeG4_version.txt
git submodule status > ../STM32CubeG4_submodules.txt
```

若需要查看历史，不用浅克隆：

```bash
git fetch --unshallow
```

### KiBot

本项目不需要修改KiBot源代码，优先安装固定版本或使用固定Action/Docker标签。若克隆：

```bash
git clone https://github.com/INTI-CMNB/KiBot.git external/kicad/KiBot
cd external/kicad/KiBot
git checkout <明确标签>
```

不要直接使用滚动开发分支生产最终制板文件。

## 3. 下载PDF并计算SHA256

Linux：

```bash
sha256sum AN5543.pdf > AN5543.pdf.sha256
```

PowerShell：

```powershell
Get-FileHash .\AN5543.pdf -Algorithm SHA256 |
  Format-List |
  Out-File .\AN5543.pdf.sha256.txt
```

`SOURCES.md`记录：

```text
文件名
原URL
下载日期
文档编号
版本/修订
SHA256
使用章节
```

## 4. 数据手册修订

同一`s ymlink` URL可能随时间指向新修订。报告中引用：

```text
Texas Instruments, TLC6C598 datasheet, revision/date as downloaded.
```

而不是只写一个网址。

关键数据摘录到项目设计决策表时，同时写：

- 表格/章节号；
- 测试条件；
- 典型或最小/最大；
- 温度；
- VCC；
- 修订版。

例如“50 mA”不能脱离VCC、温度和总功耗直接作为设计值。

## 5. 开源许可证

### STM32Cube

遵守仓库和各组件许可证。不要把ST代码的许可证头删除。

### KiBot、SKiDL、DEAP等

查看：

```text
LICENSE
COPYING
pyproject.toml
package metadata
```

使用时：

- 保留版权和许可证；
- 在`THIRD_PARTY_NOTICES.md`记录；
- 不把GPL代码直接复制进不兼容项目后忽略许可；
- 工具调用和代码链接通常比复制大段源码更稳妥。

### 本资源包代码

本包starter_code为教学起点。项目组后续应自行增加学校/团队版权、使用说明和第三方声明。

## 6. 商业书籍

只记录：

- 书名；
- 作者；
- ISBN；
- 图书馆索书号；
- 出版社链接；
- 建议章节。

不得在公开仓库放扫描PDF。

## 7. 论文管理

建议使用Zotero共享组或项目库，分类：

```text
MCU_SPI_DMA
Shift_Registers
Power_SI_EMC
EDA_Automation
RIS_Prototype
PIN_Diode
Array_Factor
Optimization
Testing
```

每篇笔记回答：

1. 它解决什么问题？
2. 用什么硬件？
3. 阵列单元数与控制通道数？
4. 更新速度？
5. 驱动电压和电流？
6. 是否有锁存？
7. 如何供电？
8. 如何测量？
9. 哪些可迁移？
10. 哪些不能照搬？

## 8. 依赖归档

创建Python环境后：

```bash
pip freeze > requirements-lock.txt
python --version > python-version.txt
```

可选下载wheel：

```bash
pip download -r requirements-lock.txt -d external/python_wheels
```

不同操作系统和Python版本的wheel不同，wheel目录要注明平台。

## 10. KiCad工具记录

```bash
kicad-cli version > external/kicad/version.txt
kibot --version > external/kicad/kibot-version.txt
```

最终生产包包含：

- 工具版本；
- 源提交；
- 配置SHA；
- 生成日期；
- ERC/DRC；
- 文件SHA。

## 11. 资源链接复核流程

每学期或关键阶段：

1. 运行链接提取脚本；
2. 优先检查ST、TI、KiCad、GitHub官方链接；
3. 记录失效；
4. 从产品页重新找文档；
5. 更新索引；
6. 不删除旧URL，写迁移记录；
7. 验证代码示例仍存在；
8. 重新运行starter_code测试。

---

## 12. 不建议归档

- 未知来源驱动；
- 破解EDA软件；
- 未授权书籍PDF；
- 未知论坛附件；
- 没有许可证的整仓代码；
- 只保存网页截图而没有URL和版本；
- AI生成但没有来源与验证的器件参数。
