## 技术栈选型建议

**前端**

- Vue 3 + Vite + Element Plus
- ECharts 5 用于数据可视化
- Axios 处理 HTTP 请求
- 响应式设计适配 PC 和移动端

**后端**

- Python FastAPI（轻量、高性能、文档自动生成）
- MQTT 客户端：asyncio-mqtt 或 paho-mqtt
- 数据库 ORM：SQLAlchemy

**数据库**

- PostgreSQL + TimescaleDB 扩展（时序数据存储）
- 或简化方案：PostgreSQL + 按时间分表

**MQTT Broker**

- EMQX（国产、性能强、有中文文档）
- 或 Mosquitto（轻量、易部署）

**数据采集端**

- ESP 32 开发板（支持 WiFi/MQTT、成本低、生态成熟）
- 支持 Modbus RTU/TCP 协议转换

**部署**

- Docker 容器化
- 支持云服务器和本地工控机两种部署模式
