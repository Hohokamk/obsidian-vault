## 一、前端技术

### 1.1 Vue 3 核心概念

#### Composition API

```javascript
// Vue 3 推荐的组合式 API
<script setup>
import { ref, computed, onMounted } from 'vue'

// 响应式数据
const count = ref(0)

// 计算属性
const doubleCount = computed(() => count.value * 2)

// 方法
function increment() {
  count.value++
}

// 生命周期
onMounted(() => {
  console.log('组件已挂载')
})
</script>
```

**核心知识点：**
- `ref()` - 创建响应式基本类型数据
- `reactive()` - 创建响应式对象
- `computed()` - 计算属性，自动缓存
- `watch()` - 监听数据变化
- 生命周期钩子：`onMounted`, `onUpdated`, `onUnmounted`

#### 组件通信

```
父 -> 子: props
子 -> 父: emit
跨层级: provide / inject
全局状态: Pinia
```

## 三、MQTT 协议

### 3.1 核心概念

```
MQTT (Message Queuing Telemetry Transport)
- 轻量级发布/订阅消息协议
- 专为低带宽、高延迟网络设计
- 适用于物联网场景

核心组件:
├── Broker (消息代理) - EMQX, Mosquitto
├── Publisher (发布者) - 设备端
├── Subscriber (订阅者) - 服务端
└── Topic (主题) - 消息分类
```

### 3.2 QoS 等级

| QoS | 名称 | 说明 | 适用场景 |
|-----|------|------|---------|
| 0 | At most once | 最多一次，可能丢失 | 实时数据，允许丢失 |
| 1 | At least once | 至少一次，可能重复 | 重要数据，可去重 |
| 2 | Exactly once | 恰好一次 | 关键数据，不可丢失 |

### 3.3 Topic 设计

```
# 本项目 Topic 规范
factory/{factory_id}/device/{device_code}/data     # 设备数据
factory/{factory_id}/device/{device_code}/status   # 设备状态
factory/{factory_id}/device/{device_code}/alarm    # 设备告警

# 通配符
+  # 单层通配符: factory/+/device/+/data
#  # 多层通配符: factory/#
```

### 3.4 Paho MQTT 客户端

```python
import paho.mqtt.client as mqtt
import json

def on_connect(client, userdata, flags, rc, properties=None):
    print(f"Connected with result code {rc}")
    # 订阅主题
    client.subscribe("factory/+/device/+/data")

def on_message(client, userdata, msg):
    topic = msg.topic
    payload = json.loads(msg.payload.decode())
    print(f"Received: {topic} -> {payload}")

# 创建客户端
client = mqtt.Client(
    client_id="backend_client",
    callback_api_version=mqtt.CallbackAPIVersion.VERSION2
)

# 设置回调
client.on_connect = on_connect
client.on_message = on_message

# 连接 Broker
client.connect("localhost", 1883, 60)

# 启动网络循环
client.loop_start()

# 发布消息
client.publish(
    "factory/FACTORY-A/device/CNC-001/data",
    json.dumps({"temperature": 55.5})
)
```

## 四、数据库

### 4.1 SQLite vs PostgreSQL

| 特性 | SQLite | PostgreSQL |
|-----|--------|-----------|
| 部署 | 单文件，无需服务 | 需要独立服务 |
| 并发 | 单写多读 | 高并发读写 |
| 性能 | 小规模优秀 | 大规模优秀 |
| 扩展 | 有限 | 丰富（TimescaleDB等） |
| 适用 | 开发/小规模 | 生产环境 |

### 4.2 时序数据优化

```sql
-- PostgreSQL + TimescaleDB
-- 创建超表（自动分片）
SELECT create_hypertable('device_data', 'collected_at');

-- 连续聚合（自动汇总）
CREATE MATERIALIZED VIEW device_hourly
WITH (timescaledb.continuous) AS
SELECT
    time_bucket('1 hour', collected_at) AS bucket,
    device_code,
    AVG(temperature) AS avg_temp,
    SUM(production_count) AS total_production
FROM device_data
GROUP BY bucket, device_code;

-- 数据保留策略
SELECT add_retention_policy('device_data', INTERVAL '90 days');
```

### 4.3 索引优化

```sql
-- 常用查询字段加索引
CREATE INDEX idx_device_data_device_time 
ON device_data(device_code, collected_at DESC);

CREATE INDEX idx_alarms_triggered 
ON alarms(triggered_at DESC);

-- 复合索引注意顺序
-- 等值查询字段在前，范围查询字段在后
```

## 六、ESP32 嵌入式开发

### 6.1 基础概念

```
ESP32 特性:
├── 双核 240MHz CPU
├── WiFi + 蓝牙
├── GPIO / ADC / DAC / PWM
├── 低功耗模式
└── 支持 Arduino / ESP-IDF

常用传感器:
├── 温度: DS18B20, DHT11/22
├── 振动: SW-420, ADXL345
├── 电流: ACS712
└── 计数: 光电开关, 霍尔传感器
```

### 6.2 Arduino 代码示例

```cpp
#include <WiFi.h>
#include <PubSubClient.h>
#include <ArduinoJson.h>

const char* ssid = "YOUR_WIFI";
const char* mqtt_server = "192.168.1.100";

WiFiClient espClient;
PubSubClient client(espClient);

void setup() {
  Serial.begin(115200);
  WiFi.begin(ssid, password);
  client.setServer(mqtt_server, 1883);
}

void loop() {
  if (!client.connected()) {
    reconnect();
  }
  client.loop();
  
  // 读取传感器数据
  float temperature = readTemperature();
  int production = countProduction();
  
  // 构建 JSON
  StaticJsonDocument<200> doc;
  doc["temperature"] = temperature;
  doc["production_count"] = production;
  doc["collected_at"] = millis();
  
  char buffer[256];
  serializeJson(doc, buffer);
  
  // 发布到 MQTT
  client.publish("factory/A/device/CNC-001/data", buffer);
  
  delay(5000);  // 5秒采集一次
}
```

### 6.3 Modbus 协议

```
Modbus 通信模式:
├── RTU (串口) - RS485/RS232
├── TCP (以太网)
└── ASCII (串口)

数据模型:
├── Coil (0x) - 读写位
├── Discrete Input (1x) - 只读位
├── Input Register (3x) - 只读字
└── Holding Register (4x) - 读写字

常用功能码:
├── 01 - 读线圈
├── 03 - 读保持寄存器
├── 04 - 读输入寄存器
├── 05 - 写单个线圈
└── 06 - 写单个寄存器
```

## 八、安全与运维

### 8.1 API 安全

```python
# JWT 认证
from fastapi_jwt_auth import AuthJWT

@app.post('/login')
async def login(username: str, password: str, authorize: AuthJWT = Depends()):
    # 验证用户
    user = authenticate(username, password)
    # 生成 token
    access_token = authorize.create_access_token(subject=user.id)
    return {"access_token": access_token}

# 受保护的路由
@app.get('/protected')
async def protected(authorize: AuthJWT = Depends()):
    authorize.jwt_required()
    current_user = authorize.get_jwt_subject()
    return {"user": current_user}
```
