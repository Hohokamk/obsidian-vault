# 软硬件配置与代码资源总索引

## 1. 项目实施基线

```text
NUCLEO-G474RE
→ STM32G474RE SPI TX DMA
→ TLC6C598 8路低侧级联驱动
→ 8颗组成64通道模块
→ 4模块组成256路
→ 16×16 LED负载
→ Python CLI、自动测试和KiCad自动构建
```

核心模式为二值独立保持。PWM、1024路、视觉、阵列算法和真实天线接口均为核心闭环稳定后的拓展。

## 4. 本包代码入口

### 离线测试

```powershell
py -3.12 -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r starter_code\requirements.txt
pytest starter_code\code\tests -q
```

### CLI

```powershell
cd starter_code\code\host
python arrayctl.py --dry-run ping
python arrayctl.py --dry-run one --row 3 --col 5
```

### 映射

```powershell
python starter_code\code\automation\generate_mapping.py `
  starter_code\code\config\array_config.yaml `
  --out generated
```

### 阵列仿真

```powershell
cd starter_code\code\simulation
python demo.py
```

### KiCad检查

```bash
starter_code/code/automation/run_kicad_checks.sh \
  board.kicad_sch \
  board.kicad_pcb \
  production
```

该脚本采用KiCad 10的`sch erc`、`pcb drc`、`pcb export gerbers`、`pcb export drill`和`pcb export step`命令。
