更新 main → 创建 feature 分支 → 开发 → Push → PR → Review → Merge

我建议你固定采用这套流程：

开始新功能

```
git switch main
git pull --ff-only origin main
git switch -c feature/login
```

开发完成，提交并上传

```
git add .
git commit -m "feat: add login"
git push -u origin feature/login
```

创建 PR，审核后合并  
在 GitHub 上把 `feature/login` 合并到 `main`。
