### 1. npm run dev

它根据 `package.json` 中的配置，实际运行了这个程序：

```
node --env-file-if-exists=.env --env-file-if-exists=.env.local --import tsx apps/server/src/http/main.ts
```

不用急着理解这一长串参数。先看最重要的部分：

`apps/server/src/http/main.ts`

这是后端 API 的入口文件。Node.js 运行它，LegalAgent 的后端程序就启动了。

### 3. Worker？它和 API 有什么关系？

API 和 Worker 是同一个应用中的两个不同进程，各自负责不同的工作。

API：前台接待

- 接收浏览器的 HTTP 请求。
    
- 检查用户身份和请求是否合法。
    
- 处理业务逻辑、读取或保存数据。
    
- 必要时创建后台任务。
    

通过数据库、任务记录或项目内部机制协作；具体方式要看代码实现

Worker：后台办事人员

- 持续检查或领取需要处理的任务。
    
- 执行耗时的后台工作。
    
- 保存执行状态和处理结果。

### 4. 全栈
|终端|命令|作用|
|---|---|---|
|终端 1|`npm run dev`|启动 API|
|终端 2|`npm run worker`|启动后台任务处理进程|
|终端 3|`npm run dev --workspace @legalagent/web`|启动 Web 前端|
### 5. 核心概念

- API：处理外部请求。
    
- 端口：程序接收网络请求的入口。
    
- 异步：不必让当前请求一直等待耗时任务。
    
- Worker：专门处理后台任务的独立进程。
    
- 数据库：保存应用的数据和状态。

### 6. 最后记住一句话
你下载的是项目代码；Node.js 负责运行后端代码；API 负责接收和处理请求；Worker 负责后台任务；PostgreSQL 负责存储数据；前端负责给你提供可操作的网页。它们共同组成一个完整的应用。
