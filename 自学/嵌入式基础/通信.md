
总体结构：
应用任务（RTOS 调度）
   ↓
驱动
   ↓
外设控制器
   ↓
片内总线（AXI/APB 协议）
   ↓
CAN 控制器
   ↓
CAN 总线（CAN 协议）
   ↓
其他设备



### 外设

| 外设级总线    | 位置       | 用途           |
| -------- | -------- | ------------ |
| **I2C**  | 芯片外（板级）  | 连接传感器、EEPROM |
| **SPI**  | 芯片外（板级）  | 连接 Flash、显示屏 |
| **CAN**  | 芯片外（设备级） | 汽车、工业多设备网络   |
| **UART** | 芯片外（点对点） | 串口通信         |


### cpu 内部
  

| 总线类型    | 全称                            | 特点            | 挂什么               |

| **AXI** | Advanced eXtensible Interface | 高速、高带宽、支持突发传输 | CPU、内存、GPU、DMA    |
| **AHB** | Advanced High-performance Bus | 中高速           | 高性能外设             |
| **APB** | Advanced Peripheral Bus       | 低速、简单、省功耗     | UART、I2C、GPIO、定时器 |

## 选择时看哪些==指标==

选通信方式，本质是看这几个维度的**优先级**：

### 1. 速度（带宽）

|需求|适合|
|---|---|
|极高速（几百 Mbps ~ 几 Gbps）|SPI、PCIe、USB、MIPI|
|中速（几 Mbps）|SPI、I2C、UART|
|低速（kbps）|I2C、UART、CAN|

**例子**：读 Flash 固件要几百 Mbps → 必须 SPI，I2C 太慢。

### 2. 引脚数

| 需求         | 适合              |     |
| ---------- | --------------- | --- |
| 引脚紧张，挂多个设备 | I2C（2 根线挂 N 个）  |     |
| 引脚充足，追求速度  | SPI（每个从设备一根 CS） |     |
| 点对点        | UART（2 根线）      |     |


**例子**：一个 MCU 要接 8 个传感器，引脚不够 → I2C，2 根线搞定。

### 3. 距离

| 需求        | 适合            |
| --------- | ------------- |
| 芯片内（微米）   | AXI/AHB/APB   |
| 板级（厘米）    | SPI、I2C       |
| 几米        | UART、USB      |
| 几十米 ~ 上千米 | CAN、RS485、以太网 |

**例子**：汽车车身各 ECU 相距几米 → CAN，差分抗干扰。

### 4. 拓扑（几个设备、谁主导）

|需求|适合|
|---|---|
|点对点|UART|
|一主多从|SPI、I2C|
|多主多从|I2C、CAN|
|多节点网络|CAN、以太网|

**例子**：多个 ECU 要互相通信，没有固定主 → CAN（多主广播）。

### 5. 全双工 vs 半双工

|需求|适合|
|---|---|
|同时收发|SPI、UART|
|收发分时|I2C、CAN|

**例子**：音频流要同时收发 → SPI 或 I2S。

### 6. 抗干扰

|需求|适合|
|---|---|
|强干扰环境|CAN（差分）、RS485（差分）|
|一般环境|SPI、I2C（单端）|

**例子**：汽车发动机舱干扰大 → CAN 差分信号。

### 7. 可靠性与开销

| 需求        | 适合                    |
| --------- | --------------------- |
| 需要应答、错误检测 | I2C（ACK）、CAN（CRC+ACK） |
| 简单、无开销    | SPI、UART              |


**例子**：关键控制指令不能丢 → CAN，有 CRC 和重传。

### 8. 成本与复杂度

| 需求    | 适合           |
| ----- | ------------ |
| 极简、便宜 | UART         |
| 中等    | I2C、SPI      |
| 复杂、贵  | USB、PCIe、以太网 |
