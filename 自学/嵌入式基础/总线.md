| 线类型     | 作用            | 例子                 |
| ------- | ------------- | ------------------ |
| **地址线** | 传输"访问哪个位置"    | 32 根，可寻址 4GB       |
| **数据线** | 传输"具体的数据值"    | 32/64 根，一次传 4/8 字节 |
| **控制线** | 传输"读还是写、是否有效" | 读信号、写信号、时钟、就绪信号    |

| 总线类型    | 全称                            | 特点            | 挂什么                 |
| ------- | ----------------------------- | ------------- | ------------------- |
| **AXI** | Advanced eXtensible Interface | 高速、高带宽、支持突发传输 | CPU、内存、GPU、DMA      |
| **AHB** | Advanced High-performance Bus | 中高速           | 高性能外设               |
| **APB** | Advanced Peripheral Bus       | 低速、简单、省功耗     | UART、I 2 C、GPIO、定时器 |
## 总线通信的规则（协议）

总线不是随便发信号，要遵守**协议**（如 AXI 协议）。协议规定：

| 规则                    | 作用             |
| --------------------- | -------------- |
| **谁先发地址，谁后发数据**       | 时序同步           |
| **握手信号**（valid/ready） | 确认双方都准备好了      |
| **突发传输**（burst）       | 一次发一批数据，提高效率   |
| **仲裁**（arbitration）   | 多个主设备竞争总线时，谁先用 |
| **错误响应**              | 访问出错时怎么报告      |

设备树：描述"哪个外设在哪个地址"
   ↓
驱动：通过 ioremap 得到虚拟地址，用 readl/writel 访问
   ↓
CPU：执行 load/store 指令
   ↓
MMU：虚拟地址 → 物理地址
   ↓
总线：传输地址 + 数据 + 控制信号
   ↓
地址译码：找到对应外设
   ↓
寄存器：接收数据，改变状态
   ↓
外设内部电路：执行动作

## 一句话总结

> **总线是 SoC 内部连接 CPU、内存、外设控制器的共享线路系统，传输地址、数据、控制三类信号；CPU 通过总线访问内存和外设寄存器，外设通过总线（DMA）访问内存，外设通过中断线通知 CPU；总线按速度分层（AXI/AHB/APB），按协议（如 AXI 握手）有序通信。寄存器是总线上被访问的终点，总线是 CPU 到寄存器之间的运输通道。**
