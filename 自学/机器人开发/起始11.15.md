### cmake 构建项目：
必要的部分：
1. 建立 CMakeLists.txt 文件
2. configure 配置 与 build 构建
```cpp
cmake_minimum_required(VERSOPN 3.10)//所需要的最低cmake版本要求
project(Example)//工程的名字
add_executable(Example main.cpp)//表示项目需要构建一个可执行文件，由main.cpp编译而成
```
cmake confugure 配置：然后就可以根据这个 cmakelists.cpp 文件生成目标平台下的原生工程，直接选择平台原生的 c++构建工具来配置
cmake build 构建：直接输出可执行文件
命令行工具：
```
配置项目：cmake -S . -B build
构建项目：cmake --build build
```
3. find_package
4. file glob 通配符匹配所有的 c++源文件
5. add_executable 构建可执行文件
6. Link 链接库
7. 用 target_compile_features 打开对 c++版本的适配
8. add_costom_conmand 命令，编译之后要执行的操作，比如说把编译之后的文件放在对应的文件夹
### C++第三方库的管理
1. 直接下载第三方库的源文件然后手动构建并指定 cmake 库的路径，或者直接使用包管理工具安装，包管理固然好，但是每次安装的时候都需要执行很繁琐的步骤 vcpkg 是什么??？不知道怎么用


标准方法：
  
```cmake

cmake_minimum_required(VERSION 3.10)
project(example LANGUAGES CXX)
set(CMAKE_CXX_STANDARD 17)
set(CMAKE_CXX_STANDARD_REQUIRED ON)
# 定义库目标（可选）
add_library(mylib src/foo.cpp src/bar.cpp)
target_include_directories(mylib PUBLIC include)
# 定义可执行目标，显式列源文件
add_executable(example src/main.cpp)
target_link_libraries(example PRIVATE mylib)
# 构建后操作
add_custom_command(TARGET example POST_BUILD
    COMMAND ${CMAKE_COMMAND} -E echo "Build done"
)
# 安装规则（可选）
install(TARGETS example DESTINATION bin)
```
