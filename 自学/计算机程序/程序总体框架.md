**==🟡STM32 常见流程==**

循环执行控制任务

读取传感器、更新电机

下一轮循环，或由中断触发处理

**Tkinter 常见流程**

事件循环等待、分发事件

用户点击按钮

调用对应的回调函数

| 对比     | STM32             | Tkinter        |
| ------ | ----------------- | -------------- |
| 谁管理循环  | 通常由你编写，或由 RTOS 调度 | GUI 框架管理事件循环   |
| 主要关注   | 任务执行时机、控制周期、响应延迟  | 用户操作、界面更新、程序交互 |
| 事件怎么处理 | 主循环轮询、中断、任务通知等    | 框架分发事件，调用回调函数  |
| 实时性    | 常用于严格的实时控制        | 通常不保证严格实时性     |
