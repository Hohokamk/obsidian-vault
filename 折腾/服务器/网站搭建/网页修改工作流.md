# Hexo 博客完整修改 / 更新工作流（适配你当前 SSH+main 分支环境）

## 一、基础日常流程（写新文章 / 修改旧文章，90% 场景）

### 1. 新建一篇博客文章

bash

```
# 格式：hexo new "文章标题"
hexo new "Linux SSH配置教程"
```

执行后自动生成文件：`blog/source/_posts/Linux-SSH配置教程.md`

### 2. 编辑文章内容

用 VS Code 打开 md 文件，书写 Markdown（标题、代码块、图片、列表等），写完**保存文件**。

### 3. 本地预览，确认效果（必做，避免线上出错）

bash

```
hexo s
```

浏览器打开 `http://localhost:4000`，实时查看排版、图片、链接是否正常；修改 md 文件页面会自动刷新。

测试完成后，终端按 `Ctrl + C` 关闭本地服务。

### 4. 一键清理、生成、部署上线（SSH 免密，无需输密码）

bash

```
hexo clean && hexo g && hexo d
```

- `hexo clean`：删除旧静态文件，杜绝缓存错乱
- `hexo g`：根据 md 文章重新生成完整网页
- `hexo d`：推送静态文件到 GitHub 远程 main 分支（你的配置已适配 SSH）

### 5. 线上查看更新

1. 等待 1~3 分钟，GitHub 自动构建 Pages 站点
2. 无痕窗口访问 `https://hohokank.github.io`，`Ctrl+Shift+R` 硬刷新页面

---

## 二、修改旧文章流程

1. 找到 `source/_posts/` 下对应的 `.md` 文件，修改内容并保存
2. 本地预览校验：`hexo s`
3. 完整部署：`hexo clean && hexo g && hexo d`
4. 等待线上生效

---

## 三、修改网站全局配置（标题、导航、侧边栏、主题）

修改文件：博客根目录 `_config.yml`（站点全局配置） / `themes/主题名/_config.yml`（主题配置）

1. 修改对应 yml 文件，保存
2. 本地预览测试：`hexo s`，确认导航、配色、侧边栏改动生效
3. 全套部署推送：`hexo clean && hexo g && hexo d`

---

## 四、更换 / 安装博客主题

1. 进入 themes 目录，git clone 下载主题

bash

```
cd themes
git clone 主题仓库地址 主题文件夹名
```

2. 修改根目录 `_config.yml` 里 `theme: 主题文件夹名`
3. 本地预览：`hexo s` 查看主题效果，按需修改主题配置
4. 部署上线：`hexo clean && hexo g && hexo d`

---

## 五、删除文章操作

1. 直接删除 `source/_posts/` 里对应的 `.md` 文件
2. 本地预览确认文章消失：`hexo s`
3. 执行部署命令同步线上：`hexo clean && hexo g && hexo d`

---

## 六、避坑固定规则（针对你刚才分支踩的坑）

1. **配置文件 `branch` 固定写 `main` **
    
    yaml
    
    ```
    deploy:
      type: git
      repo: git@github.com:Hohokank/Hohokank.github.io.git
      branch: main
    ```
    
    不要再改成 master，避免本地分支和远程分支冲突。
2. 每次部署**必须带 `hexo clean` **，否则旧缓存会导致线上页面不更新。
3. 所有改动**先本地预览，再部署**，不要直接推送，防止语法错误导致网站崩掉。
4. 部署成功后不要立刻刷新网页，给 GitHub Pages 1~3 分钟构建时间。
