> 基于 **RK3588（讯飞超脑板 EA_3588 S）** 打造的便携、低延迟、可离线交互的边缘端 AI 艺术风格化相机。

## 项目简介

本项目利用一块 **讯飞超脑板（EA_3588 S，8 GB RAM + 64 GB eMMC）**，做一台可以独立运作的「智能拍立得 / 艺术相机」，彻底摆脱对电脑的依赖。

核心理念是：**用应用落地驱动嵌入式 Linux 与端侧 AI 学习**。避开单纯看书背命令的枯燥路径，用一个好玩的软硬件实体项目，把串口调试、Linux 系统管理、OpenCV 图像处理、端侧语言模型量化与 RKNN（NPU）工具链全部串联吃透。

## 核心体验

用户拿起相机即可完成一次完整的「自然语言 → 艺术出图」闭环：

```text
USB 摄像头实时取景
        ↓
按下快门截帧
        ↓
输入简要 Prompt（文字 / 语音）
        ↓
边缘端算法极速重绘
        ↓
HDMI 屏幕全屏展示
```

## 特性亮点

- **便携离线**：全程在本机运行，不依赖云端推理。
- **低延迟**：利用 NPU 与纯 CNN 网络，目标在 **1 秒内**完成高质量名画风格重绘。
- **自然语言交互**：端侧小语言模型理解口语化 Prompt，解放固定按键。
- **渐进式演进**：从经典图形学滤镜，逐步过渡到端侧 AI 的开放式风格迁移。

## 技术选型对比

面对「边缘算力有限 + 想要生成式体验」的矛盾，项目对比了三条路线：

| 方案 | 优势 | 代价 | 结论 |
| --- | --- | --- | --- |
| **扩散模型（LCM/Turbo）** | 真正的生成式大模型，理解力深，可凭空增减元素 | 算力严重超标；RK3588 NPU 对 Attention 与高频显存搬运不擅长，快门后有「转圈等待感」 | 放弃 |
| **意图理解路由（SLM + 预设 CNN）** | 速度最快、稳定性最高，端侧小模型 + 纯 CNN，近乎一秒出图 | 本质是「高级多选一」，无法应对极冷门新词 | Phase 2 采用 |
| **CLIP-Styler 类架构** | 兼顾自由度与嵌入式算力，开放文本 + 单次前向，不需迭代去噪 | 只能改变纹理、色彩与表面材质，不能大幅改变形状或语义 | Phase 3 采用 |

## 开发路线图

### Phase 1：骨架搭建与极简闭环

**目标**：不碰复杂的模型转换，1~2 天内跑通「拍照 → 处理 → 屏幕展示」全流程，验证硬件稳定性。

- 使用 `cv2.VideoCapture` 调通 USB 摄像头实时预览。
- 绑定键盘按键或板载 GPIO 轻触微动作为物理快门，按下瞬间截取当前帧。
- 接入 3~4 个 OpenCV 内置极速滤镜：
  - 素描风：`cv2.pencilSketch`
  - 漫画轮廓：Canny 边缘检测 + Bilateral Filter 双边滤波
  - 油画质感：`cv2.xphoto.oilPainting`
- 全屏窗口推流到 HDMI 屏幕，附带 3 秒倒计时与拍照闪烁动效。

**里程碑**：做出一个能即时拍照、按数字键切换 OpenCV 滤镜的基础拍照机。

### Phase 2：意图理解路由方案（SLM + 预编译多风格 CNN）

**目标**：引入端侧大语言模型接管交互，实现「自然语言输入 → 毫秒级 NPU 艺术重绘」。

1. **部署端侧文本大脑**
   - 使用 `llama.cpp` 部署 **Qwen 2.5-0.5B-Instruct (Q4_K_M)**。
   - 设计结构化 System Prompt，约束其只输出预设风格代号：

     > 你是一个相机指令路由器。根据用户的描述，必须只输出以下代号之一：`[VAN_GOGH, UKIYOE, CYBERPUNK, SKETCH, ANIME]`。

2. **准备 RKNN 风格网络**
   - 采用经典 **Fast Neural Style Transfer** 或 **CycleGAN**。
   - 寻找开源预训练 ONNX 权重（梵高星空、浮世绘神奈川冲浪里、波普艺术等），在 PC 上用 `rknn-toolkit2` 量化为 `.rknn` 并部署到板子。

3. **逻辑总控**
   - 用户按住快门并输入文字/语音：「我想拍出浮世绘的感觉」。
   - Qwen 2.5 在约 200 ms 内解析出 `UKIYOE` 标签。
   - 主程序调用 `rknn.load_rknn('ukiyoe.rknn')`，在 NPU 上推导当前画面（约 50~100 ms）。

**里程碑**：实现「你说什么风格，相机一秒内就变出对应名画笔触」的完整离线智能交互。

### Phase 3：CLIP 引导的任意风格迁移

**目标**：摆脱写死预设，支持自由输入冷门艺术词汇。

1. **文本语义提取**：采用轻量级 **CLIP ViT-B/32 文本端**，将任意 Prompt（如「赛博朋克霓虹雨夜」「青铜器锈迹质感」）提取为 512 维文本语义向量。
2. **AdaIN 前馈网络**：通用前馈编码-解码卷积网络，中间层用 AdaIN 将图像均值和方差对齐到 CLIP 文本向量对应的艺术特征分布。
3. **部署优化**：CLIP 文本端走 CPU/NPU，图像前馈网络走 NPU；单次推导无需迭代，板端 1~2 秒完成渲染。

**里程碑**：任意未预置词汇，画面依然能精准渲染对应的色彩基调与表面质感。

### Phase 4：硬件与产品化封装

**目标**：脱离键盘和连线束缚，包装成可握持的完整极客玩具。

- **语音交互**：接入板载麦克风，前置轻量离线语音唤醒/识别（如 Sherpa-NCNN），按住快门说话，松开即出图。
- **按键与状态反馈**：板载 GPIO 接两颗双色 LED（绿色待机、呼吸闪烁表示推理中、常亮表示出图完成）。
- **相册留存**：每次出图自动打时间水印存入板载目录，启动本地 Web 服务（如 Flask），手机连板子热点扫码即可下载照片。

## 目录结构（规划）

```text
Stylized_Camera/
├── camera/          # 摄像头采集与快门控制
├── filters/         # OpenCV 经典滤镜（Phase 1）
├── models/          # RKNN / ONNX 模型与转换脚本
├── router/          # SLM 意图理解与风格路由（Phase 2）
├── clip_styler/     # CLIP + AdaIN 风格迁移（Phase 3）
├── server/          # 相册 Web 服务（Phase 4）
└── main.py          # 总控入口
```
