针对你的 **OPPO K 9 x（天玑 810 / 128 GB）**，想要**流畅运行**且能**在局域网内自由调用标准 OpenAI 兼容 API**，最佳技术路线是：**Termux + llama.cpp 原生编译 (`llama-server`) + Qwen 2.5-1.5 B (4-bit 量化)**。

这个方案兼顾了中文理解能力、吐字速度（CPU 实测约 8~14 tokens/s，阅读感非常流畅），并且对外暴露标准的 RESTful API，电脑端的 VS Code、沉浸式翻译、NextChat 或你自己写的 Python 脚本都可以随时无缝调用。

### 第一步：准备 Termux 基础环境与保活

打开 Termux，先确保系统不杀后台，并安装基础编译工具链：

Bash

```
# 1. 开启手机防休眠唤醒锁
termux-wake-lock

# 2. 更新软件源并安装编译与下载工具
pkg update && pkg upgrade -y
pkg install git cmake clang curl -y
```

> **系统设置防杀后台（重要）：** 在 OPPO 手机设置中：
> 
> - 找到 **应用管理 -> 应用列表 -> Termux**，开启“允许完全后台行为 / 自启动”。
>     
> - 进入 **电池 -> 更多电池设置 -> 耗电异常优化**，把 Termux 设置为“不优化”。
>     

### 第二步：编译高性能推理引擎 `llama.cpp`

`llama.cpp` 原生支持 ARM CPU 的 NEON 指令集加速，直接在手机上编译适配度最高：

Bash

```
# 1. 拉取 llama.cpp 官方仓库
git clone https://github.com/ggerganov/llama.cpp
cd llama.cpp

# 2. 创建编译目录并进行 Release 优化编译（利用多核编译）
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release -j4
```

_编译过程大约需要 2~5 分钟，完成后在 `build/bin/` 目录下会生成 `llama-server` 等二进制文件。_

### 第三步：下载针对天玑 810 优化的 1.5 B 模型

**Qwen 2.5-1.5 B-Instruct-Q 4 _K_M** 是目前中文小参数模型的“天花板”，4-bit 量化后体积仅约 **1.1 GB**，天玑 810 跑起来毫无压力。

从国内 ModelScope（魔搭社区）高速下载：

Bash

```
# 切换回用户根目录并创建 models 文件夹
cd ~
mkdir -p models && cd models

# 从 ModelScope 高速下载 GGUF 权重文件
curl -L -o qwen2.5-1.5b-instruct-q4_k_m.gguf \
"https://modelscope.cn/api/v1/models/Qwen/Qwen2.5-1.5B-Instruct-GGUF/repo?Revision=master&FilePath=qwen2.5-1.5b-instruct-q4_k_m.gguf"
```

### 第四步：一键启动 OpenAI 兼容的 API 服务器

进入 `llama.cpp` 目录启动 `llama-server`：

Bash

```
cd ~/llama.cpp

./build/bin/llama-server \
  -m ~/models/qwen2.5-1.5b-instruct-q4_k_m.gguf \
  --host 0.0.0.0 \
  --port 8080 \
  -c 2048 \
  -t 4 \
  --chat-template qwen2
```

**关键参数解释：**

- `--host 0.0.0.0`：允许局域网内的电脑、平板连接，不局限于手机本机。
    
- `--port 8080`：API 端口号为 8080。
    
- `-c 2048`：上下文窗口大小设为 2048（适合天玑 810 运存，兼顾长文本与低内存占用）。
    
- `-t 4`：使用 4 个 CPU 大核/中核进行并行计算，既保证速度又防止手机过热降频。
    

### 第五步：在电脑/其他设备上调用 API

#### 1. 先查看手机局域网 IP

在 Termux 里新建一个会话窗口输入：

Bash

```
ifconfig
```

找到 `wlan0` 下方的 `inet` 地址，比如：`192.168.1.108`。

#### 2. 在浏览器直接访问 Web 界面

在同一 Wi-Fi 下的电脑浏览器打开 `[http://192.168.1.108:8080](http://192.168.1.108:8080)`，即可看到 `llama.cpp` 内置的网页对话前端，直接开始聊天！

#### 3. 接入第三方工具或代码调用

该服务完全兼容 OpenAI 协议：

- **API 地址（Base URL）：** `[http://192.168.1.108:8080/v1](http://192.168.1.108:8080/v1)`
    
- **API Key：** 留空或随意填（如 `sk-any`）
    
- **模型名称（Model）：** `qwen2.5-1.5b-instruct`
    

**Python 代码调用示例：**

Python

```
from openai import OpenAI

client = OpenAI(
    base_url="http://192.168.1.108:8080/v1",  # 替换成你的手机 IP
    api_key="none",
)

response = client.chat.completions.create(
    model="qwen2.5-1.5b-instruct",
    messages=[{"role": "user", "content": "用一句话介绍你自己"}],
    stream=True,  # 开启打字机流式输出
)

for chunk in response:
    content = chunk.choices[0].delta.content
    if content:
        print(content, end="", flush=True)
```

### 实用体验与日常维护建议

1. **写成启动脚本：** 可以在根目录建一个 `start_ai.sh` 脚本，每次进入 Termux 输入 `bash start_ai.sh` 一键启动。
    
2. **配合 Tailscale 远程调用：** 如果出门在外想让随身笔记本调用家里的备用机 AI，配合 Tailscale 异地组网，将 IP 换成 Tailscale 虚拟 IP 即可实现“全球任意网络调用”。
    
3. **长期插电：** 建议开启 ColorOS 系统中的“夜间充电保护 / 电池健康优化”，插上 5 V-1 A 或 5 V-2 A 的慢充头，即可作为 7×24 小时低功耗微型 AI 节点。
