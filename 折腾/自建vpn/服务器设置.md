### 第二步：开启 BBR 加速 & 添加虚拟内存 (Swap)

登录成功后，逐行复制并运行以下命令，防止 1 GB 内存溢出并优化网络吞吐：

Bash

```
# 1. 开启 BBR
echo "net.core.default_qdisc=fq" >> /etc/sysctl.conf
echo "net.ipv4.tcp_congestion_control=bbr" >> /etc/sysctl.conf
sysctl -p

# 2. 增加 2GB 虚拟内存
fallocate -l 2G /swapfile
chmod 600 /swapfile
mkswap /swapfile
swapon /swapfile
echo '/swapfile none swap sw 0 0' >> /etc/fstab
```

### 第四步：在后台添加 VLESS-Reality 节点

1. 进入 3 X-UI 面板，点击左侧 **入站列表 (Inbounds)** -> **添加添加入站**。
    
2. 配置参数如下：
    
    - **协议 (Protocol)**：`vless`
        
    - **端口 (Port)**：`443`
        
    - **传输协议 (Network)**：`tcp`
        
    - **安全 (Security)**：`reality`
        
    - **Dest & SNI**：
        
        - **目标网站 (Dest)**：`itunes.apple.com:443` 或 `gateway.icloud.com:443`
            
        - **服务器名称 (SNI)**：`itunes.apple.com` 或 `gateway.icloud.com`
            
    - 点击 **获取新密钥 (Get New Cert/Key)** 自动生成公私钥和 Short ID。
        
3. 点击 **保存 (Create)**。
    
4. 在列表中点击操作栏的 **二维码/链接** 复制节点，导入到客户端（如 v 2 rayN / Clash Verge / Shadowrocket）即可直接使用。
