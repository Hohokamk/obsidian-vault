### 一、 服务器选购与系统配置 (HostVDS)

1. **节点选择**：
    
    - 访问 AI 服务首选：**美国（硅谷/洛杉矶）**、**日本（东京）** 或 **新加坡**。这些地区的 Gemini、ChatGPT 功能完整且延迟较低。
        
2. **系统镜像**：
    
    - 建议直接选择 **Ubuntu 22.04 LTS** 或 **Debian 12**（纯净度高、依赖兼容性好）。
        
3. **安全组/防火墙**：
    
    - HostVDS 控制面板中确保开放常用端口，或直接放行全部端口（后期通过系统内部防火墙控制）。
        

### 二、 服务器基础优化（BBR 与内核加速）

SSH 登录 VPS 后，先开启 BBR 加速以降低延迟与丢包影响：

Bash

```
# 更新系统包
apt update && apt upgrade -y

# 启用 BBR 加速
echo "net.core.default_qdisc=fq" >> /etc/sysctl.conf
echo "net.ipv4.tcp_congestion_control=bbr" >> /etc/sysctl.conf
sysctl -p

# 验证是否生效（输出应包含 bbr）
sysctl net.ipv4.tcp_congestion_control
```

### 三、 安装可视化多协议面板（X-UI / 3 X-UI）

推荐使用维护活跃的 **3 X-UI**，支持可视化管理、自建证书及目前最抗封锁的 **VLESS-Reality** 协议。

Bash

```
# 安装 3X-UI 面板
bash <(curl -Ls https://raw.githubusercontent.com/mhsanaei/3x-ui/master/install.sh)
```

- 安装过程中按提示设置**面板访问端口**、**用户名**和**密码**。
    
- 安装完成后，在浏览器输入 `http://<你的VPS_IP>:<端口>` 登录管理后台。
    

### 四、 配置 VLESS-Reality 节点（抗封锁首选）

在 3 X-UI 后台创建入站规则：

- **协议 (Protocol)**：`VLESS`
    
- **传输协议 (Transport)**：`TCP`
    
- **安全性 (Security)**：`Reality`
    
- **目标网站 (Target Domain/SNI)**：填写知名大厂未被屏蔽的域名（如 `[www.yahoo.com:443](https://www.yahoo.com:443)` 或 `itunes.apple.com:443`）
    
- **Dest 端口**：`443`
    
- 点击生成私钥/公钥，保存后即可在客户端直接扫码或导入链接使用。
    

### 五、 配置 Cloudflare WARP 出站分流（解决 Gemini / ChatGPT 风控）

使用开源工具 **WARP-GO** 或 **fscarmen WARP 脚本**，将针对特定 AI 服务的流量通过 WARP 出站。

Bash

```
# 运行 WARP 多功能一键脚本
wget -N https://gitlab.com/fscarmen/warp/-/raw/main/menu.sh && bash menu.sh
```

**分流配置步骤**：

1. 选择安装 **WARP IPv 4 / IPv 6**（推荐选择非全局模式，作为本地 SOCKS 5 代理出站，例如端口 `127.0.0.1:40000`）。
    
2. 在 3 X-UI 面板的 **Xray 设置 -> 路由规则 (Routing Rules)** 中添加出站规则：
    
    - **Outbound Tag**：指向 `warp-out`（对应 SOCKS 5 40000）。
        
    - **Domain 匹配规则**：
        
        Plaintext
        
        ```
        openai.com, chatgpt.com, oaistatic.com, oaiusercontent.com,
        gemini.google.com, bard.google.com, ai.google.dev, googleapis.com
        ```
        
    - 这样日常浏览直接走 VPS 原生网络（保持高速度），只有访问 OpenAI / Google AI 服务时才走 Cloudflare WARP 清洁 IP。
