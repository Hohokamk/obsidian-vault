### 🛠️ 全流程配置教程（5 步建工程）

**1.通过 CubeMX 生成底层代码：**图形化配置芯片和外设。

1. 打开 **STM 32 CubeMX**，新建芯片工程（选择你的芯片，比如 `STM32F103RC`）。
    
2. 配置好时钟（RCC）、调试接口（SYS -> Debug: **Serial Wire**，_千万别忘了选 SW，否则 ST-Link 容易死锁_）和你的外设/FreeRTOS。
    
3. 切换到 **Project Manager** 标签页：
    
    - **Project Name**：填工程名字（如 `Demo_Project`）。
        
    - **Project Location**：选择工程存放目录。
        
    - **Toolchain / IDE**：选择 ** `STM32CubeIDE` **（或者 `CMake`，两者都可以，选择 `STM32CubeIDE` 最稳定）。
        
4. 点击右上角 **GENERATE CODE** 生成代码。
    

**2.在 Visual Studio 中启动 VisualGDB 向导：**新建 VisualGDB 嵌入式项目。

1. 打开 Visual Studio，点击 **创建新项目 (Create a new project)**。
    
2. 搜索并选择 ** `Embedded Project Wizard` **，点击下一步。
    
3. **项目名称**和**位置**填好（**注意：** 路径不要有中文或空格），点击 **创建**。
    

**3.选择构建模式与导入方式：**使用 Advanced CMake 和 CubeMX 导入。

1. 在 **Project Type** 界面：
    
    - 选择第 4 项：** `Automatically import a project in a different format` **。
        
    - 下拉菜单选择：** `Import a project generated by STM32CubeMX` **。
        
    - 下方的 Build system 自动保持为 ** `Advanced CMake` ** 即可。
        
2. 点击 **Next**。
    
3. 在弹出的 **Import Configuration** 界面：
    
    - 浏览点击 ** `STM32CubeMX project file (.ioc)` ** 栏，找到刚才 CubeMX 生成的那个 ** `.ioc` ** 文件。
        
4. 点击 **Next**。
    

**4.选择交叉编译器 (Toolchain)：**指定 ARM-GCC 路径。

1. 在 **Toolchain Selection** 界面：
    
    - 选择 ** `ARM in c:\sysgcc\arm-eabi` **（VisualGDB 自带的 ARM-GCC 编译器）。
        
2. 目标芯片（Target device）系统会自动根据 `.ioc` 文件识别（如 `STM32F103RC`）。
    
3. 点击 **Next**。
    

**5.配置烧录与调试工具 (Debug Method)：**关联 ST-Link / J-Link。

1. **Debug method**：选择 ** `ST-Link` ** 或 ** `OpenOCD` **（取决于你用的下载器）。
    
2. **Interface**：选择 ** `SWD` **。
    
3. 将 ST-Link 插入电脑并连接开发板，点击 **Test** 测试。如果看到绿色弹窗提示检测到芯片，说明链路完全通畅！
    
4. 点击 **Finish**。
