## LinK02 - 完美立方

**思路**：枚举法，四重循环验证 a³ = b³ + c³ + d³，利用 b≤c≤d 和 a≤N 剪枝。

**关键代码**：
```cpp
for (int a = 2; a <= N; a++)
    for (int b = 2; b < a; b++)
        for (int c = b; c < a; c++)
            for (int d = c; d < a; d++)
                if (a*a*a == b*b*b + c*c*c + d*d*d)
                    printf("Cube = %d, Triple = (%d,%d,%d)\n", a, b, c, d);
```

**总结**：枚举时缩小循环范围可以大幅减少计算量。

## LinK06 - 两数之和

**思路**：排序后双指针，左右指针向中间逼近找目标和。

**关键代码**：
```cpp
sort(a, a + n);
int l = 0, r = n - 1;
while (l < r) {
    int sum = a[l] + a[r];
    if (sum == target) break;
    if (sum < target) l++;
    else r--;
}
```

**总结**：双指针将 O(n²) 优化到 O(nlogn)。

## LinK26 - 算24

**思路**：DFS 从 4 个数中选 2 个做运算，递归到只剩 1 个数检查是否为 24。

**关键代码**：
```cpp
bool solve(vector<double>& a) {
    if (a.size() == 1) return abs(a[0] - 24) < 1e-6;
    for (int i = 0; i < a.size(); i++)
        for (int j = 0; j < a.size(); j++) if (i != j) {
            vector<double> r;
            for (int k = 0; k < a.size(); k++) if (k != i && k != j) r.push_back(a[k]);
            r.push_back(a[i] + a[j]); if (solve(r)) return true; r.pop_back();
            r.push_back(a[i] - a[j]); if (solve(r)) return true; r.pop_back();
            r.push_back(a[i] * a[j]); if (solve(r)) return true; r.pop_back();
            if (a[j]) { r.push_back(a[i] / a[j]); if (solve(r)) return true; }
        }
    return false;
}
```

**总结**：DFS 枚举所有运算组合，注意浮点数精度比较。

## LinK28 - 快速选择第k个数

**思路**：QuickSelect，基于快排的 partition 思想，每次只递归一边，平均 O(n)。

**关键代码**：
```cpp
int quickSelect(int l, int r, int k) {
    if (l == r) return a[l];
    int i = l - 1, j = r + 1, p = a[l + rand() % (r - l + 1)];
    while (i < j) {
        do i++; while (a[i] < p);
        do j--; while (a[j] > p);
        if (i < j) swap(a[i], a[j]);
    }
    int leftLen = j - l + 1;
    if (k <= leftLen) return quickSelect(l, j, k);
    return quickSelect(j + 1, r, k - leftLen);
}
```

**总结**：QuickSelect 比排序后再取第 k 个快得多。

## LinK30 - 归并排序

```cpp
void mergeSort(int l, int r) {
    if (l >= r) return;

    int i = l, j = mid + 1, k = 0;
    while (i <= mid && j <= r) tmp[k++] = a[i] <= a[j] ? a[i++] : a[j++];

}
```

**总结**：归并排序是分治法的经典应用。

## LinK41 - 英杰们的蛋糕塔

**思路**：DFS + 剪枝，从大到小枚举半径和高度，利用体积和表面积约束剪枝。

```cpp
void dfs(int layer, int r, int h, int v, int s) {
    if (layer == n) { if (v == V) ans = min(ans, s); return; }
    if (v + (n-layer) * (r-1) * (r-1) * (h-1) < V) return; // 体积剪枝
    if (s + 2 * (V - v) / r >= ans) return; // 表面积剪枝
    for (int nr = r-1; nr >= n-layer; nr--)
        for (int nh = h-1; nh >= n-layer; nh--)
            dfs(layer+1, nr, nh, v+nr*nr*nh, s+2*nr*nh);
}
```

**总结**：DFS + 可行性剪枝 + 最优性剪枝，优秀的剪枝技巧是关键。

```cpp
}
```

## LinK66 - 多重背包问题(2)

**思路**：二进制优化，将 s 拆成 1, 2, 4, ..., 2^k, 剩余，转化为 01 背包。

**关键代码**：
```cpp

    for (int k = 1; k <= s; k *= 2) {
        for (int j = V; j >= k*v; j--)
            dp[j] = max(dp[j], dp[j - k*v] + k*w);
        s -= k;
    }
    if (s) for (int j = V; j >= s*v; j--)
        dp[j] = max(dp[j], dp[j - s*v] + s*w);
}
```

**总结**：二进制优化把多重背包转为 O(V log s) 的 01 背包。
