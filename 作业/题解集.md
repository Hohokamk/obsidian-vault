## LinK06 - 两数之和

**关键代码**：
```cpp

    int sum = a[l] + a[r];
    if (sum == target) break;
    else if (sum < target) l++;

}
```

**总结**：双指针将O(n²)优化到O(nlogn)。

## LinK28 - 快速选择第k个数

**思路**：QuickSelect算法，基于快排思想，平均O(n)。

**关键代码**：
```cpp
int quickSelect(int l, int r, int k) {
    if (l == r) return a[l];
    int pivot = a[l + rand() % (r - l + 1)];
    int i = l - 1, j = r + 1;
    while (i < j) {
        do i++; while (a[i] < pivot);
        do j--; while (a[j] > pivot);
        if (i < j) swap(a[i], a[j]);
    }
    if (k <= j - l + 1) return quickSelect(l, j, k);
    else return quickSelect(j + 1, r, k - (j - l + 1));
}
```

**总结**：QuickSelect比排序更高效。

void mergeSort(int l, int r) {
    if (l >= r) return;
    int mid = (l + r) / 2;
    mergeSort(l, mid);

    int i = l, j = mid + 1, k = 0;
    while (i <= mid && j <= r)
        tmp[k++] = a[i] <= a[j] ? a[i++] : a[j++];
    while (i <= mid) tmp[k++] = a[i++];

}
