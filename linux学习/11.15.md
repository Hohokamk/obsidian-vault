## 第五章：分布式应用
1. 用户组管理，linux 中可以配置多个用户和用户组，针对不同的主体由不同的权限控制、管理命令：创建用户组： groupadd 用户组名    groupdel 用户组名
2. 查看 linux 权限管控信息 ls -l  查看账户和权限的细节，一共十个槽位，不同的槽位代表了不同的权限细节
3. 修改权限信息 chmod 修改权限控制chown
4. Mysql
5. tomcat 网站部署代理软件，是一个 seylet 容器，一个 web应用程序的托管平台 
6. nginx 高性能的流量代理服务器  使用 yum 的仓库直接 用 yum install 安装相应的依赖工具就好了
7. rabbitMQ 是一个开源消息订阅系统，后端分析，yum 程序仓库，所以说要手动构建仓库。直接导入组
8. redis 开源的使用 c 语言编写 支持网络交互可以基于内存存储数据，也可持久化的 kvalue 形的数据库，可以提供快速缓存的能力，使用 yum 程序安装
9. Elasticsearch 全文检索工具，全文搜索引擎，搜索与分析，像维基百科啥的都是基于这个设计的。yum 程序，导入密钥手动导入仓库，通过 ypm 导入密钥
10. 集群化软件安装的前置准备，单机与集群化的工作，平时和学习大数据的相关的软件部署。创建多台虚拟机然后统一构建，通过 vm 的克隆功能，快速构建多台虚拟机。得到虚拟机集群
11. scp 命令：在多台服务器之间协同进行，在多台服务器之间传输数据，通过 ssh 协议高速传输文件，scp -r+参数一+参数二
12. zookeeper 集群化运行的分布式软件，大数据和 hadupu 的，重要的组件，为分布式应用提供一致性服务的软件，采用分布式状态一致性协调服务。一致性场景。分布式集群化软件，分别安装然后集群化连接。构建安装。
13. kafka 消息队列系统，多用于后端系统，多用于 集群化的环境下的。
14.  hadoop 生态，分布式系统的基础架构，hadoophdfa分布式海量数据的存储能力，hadoopyarn 分布式集群的资源管理能力 hadoop hapreduce 分布式海量数据的计算能力
15. HBase 集群部署，分布式，可拓展，支持海量数据存储的 nosql 数据库。
16. 分布式内存计算引擎：spark 综合计算引擎，支持离线计算，最广泛使用的分布式计算引擎。hadoop 是生态的工具 wget 命令
17. Flink 和 spark 分布式内存计算引擎，支持离线计算和实时计算，前者侧重离线，后者实时。依旧 wget 命令安装。
