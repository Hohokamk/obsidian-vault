## 四、推进顺序（4 步，每步都能单独上机）

**第 1 步 · 底盘能动**（只碰 `CHASSIS::Update()`）  
麦轮逆解一般式：`FL = vx - vy - K·ωz`、`FR = vx + vy + K·ωz`、`RL = vx + vy - K·ωz`、`RR = vx - vy + K·ωz`，`K = (半轴距 + 半轮距) / 轮半径`。

⚠️ **这张表的符号一半是错的。**​ 辊子方向决定每个轮子的正方向，网上每一份表的约定都不一样。标准做法是**三项标定**：只给 `vx` 看是不是直着走、只给 `vy` 看是不是纯平移、只给 `ωz` 看是不是原地自转，哪项不对就翻那一项在对应轮子上的符号。**​车架空再测。**

⚠️ 量纲：`RC.cpp:88` 给的是 `rc.ch * 4000/660`（裸数 ±4000），而 `setspeed` 单位是 **rpm**。4000 决定最大轮速，标定时先用 ~1000。（顺带：`:88-89` 硬编码 4000，`:97-129` 用 `para.max_speed = 3000`，两处不一致，先不管但心里有数。）

**第 2 步 · 云台 yaw 能转**  
结构：`yaw_ready` bool 首帧 latch（`mark_yaw = yaw->angle[now]`、`delta_yaw = 0`），之后 `setangle = ClampAngle(mark_yaw + delta_yaw, para.yaw_center, para.yaw_span)`。`delta_yaw` 由 `Control_Pantile()` 累加（记得 Update 是 **5 ms** 周期）。

**第 3 步 · 达妙两轴**  
Pitch（P_S）发 `setPos`（弧度，被钳 ±4π）+ `setSpeed`；Yaw（SPEED）发 `setSpeed`（rad/s，钳 ±10）。  
⚠️ **Pitch 有和 yaw 一样的开机 latch 问题**：`para.dm_initial_pitch = 0.f` 会让它上电就往电机零位转。用 `DMmotor[0].GetPosition()` 取当前角做基准。先 live watch 确认 `can2.jointidata` 里有真反馈，否则 latch 会锁到 0。

**第 4 步 · 射击**  
`shooter_motor[0..1]->setspeed = shoot_speed`（6000 rpm 对摩擦轮偏高，先 3000）+ `supply_motor[0]->setspeed`。  
⚠️ 拨盘走 SPD = **按住就连续转**，不是一格一格拨。`pd` / `spinning` / `need_curcircle` 那三个成员是给 `ACE` 分支的，往后放。

底盘 update:
四个必须注意的点：

1. **必须写 `ctrl.chassis_motor[i]` **。`CHASSIS` 是 `CONTROL` 的嵌套类，裸写 `chassis_motor` 会重演你上次那个 **C 2352**。`speedx/speedy/speedz` 是 `CHASSIS` 自己的成员，裸写没问题。
2. ** `CHASSIS_MOTOR_NUM` 是宏**，别加 `CONTROL::` 前缀。
3. **每轮限幅不能省**。RC 给的是 `±4000`，而 `Motor::getmax()` 里 M 3508 是 ** `maxspeed = 3800` **（`motor.cpp:201-202`）—— 纯 `vx` 就已经超了，三轴叠加能到 12000。`setspeed` 下游**没有任何钳制**（`:168` 只钳 `current`），所以这层得你自己加。
4. `K` 和那些系数**第一版不要动**。先把符号标定对，量纲和手感后面调。
