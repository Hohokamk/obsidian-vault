
# 上位机（NUC）→ 下位机（XUC）
### 字节偏移表

|偏移|长度|字段|类型|单位|说明|
|---|---|---|---|---|---|
|0|1| `header` |uint 8|—|固定 `0xA5` |
|1|4| `pitch` |float|**度**|目标俯仰角|
|5|4| `yaw` |float|**度**|目标偏航角|
|9|4| `yaw_diff` |float|度|偏航角速度/增量|
|13|4| `pitch_diff` |float|度|俯仰角速度/增量|
|17|4| `distance` |float|m|目标距离|
|21|1| `fireadvice` |uint 8|—|bit 0=1 建议开火|
|22|3|**未知/保留**|—|—|偏移 22~24，未解析|
|25|4| `v_y` |float|—|目标 Y 方向速度|
|29|1|**未知/保留**|—|—|偏移 29|
|30|2| `checksum` |uint 16|—|CRC 16 校验|

**合计：1 + 4 + 4 + 4 + 4 + 4 + 1 + 3 + 4 + 1 + 2 = 32 字节** ✅

# 下位机（STM 32）→ 上位机（NUC）发送数据
### 字节偏移表

| 偏移     | 长度     | 字段              | 类型      | 说明        |     |
| ------ | ------ | --------------- | ------- | --------- | --- |
| 0      | 1      | `header`        | uint 8  | 固定 `0x5A` |     |
| 1      | 1      | `detect_color`  | bit 0   | 0=红方，1=蓝方 |     |
| 1      | 1      | `reset_tracker` | bit 1   | 是否复位跟踪器   |     |
| 1      | 1      | `reserved`      | bit 2~7 | 保留，填 0    |     |
| 2      | 4      | `roll`          | float   | 横滚角       |     |
| 6      | 4      | `pitch`         | float   | 俯仰角       |     |
| 10     | 4      | `yaw`           | float   | 偏航角       |     |
| 14     | 4      | `aim_x`         | float   | 瞄准点 X     |     |
| 18     | 4      | `aim_y`         | float   | 瞄准点 Y     |     |
| 22     | 4      | `aim_z`         | float   | 瞄准点 Z     |     |
| 26     | 2      | `checksum`      | uint 16 | CRC 16 校验 |     |
| **合计** | **28** |                 |         |           |     |

**1 + 1 + 24 + 2 = 28 字节** ✅
